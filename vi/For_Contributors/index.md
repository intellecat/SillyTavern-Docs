# Phát triển và Tự động hóa

Gói mặc định của SillyTavern chỉ cung cấp một nền tảng cơ bản có thể được mở rộng theo nhiều cách.

:::callout
**[STscript](st-script)**

STscript là một ngôn ngữ lập trình mạnh mẽ dựa trên các lệnh trò chuyện theo lô có thể tiếp cận mà không cần kiến thức lập trình trước đó.
:::

:::callout
**[Function Calling](Function-Calling)**

Thêm khả năng động hơn bằng cách để LLM sử dụng các nguồn dữ liệu bên ngoài hoặc kích hoạt chức năng cụ thể của extension.
:::

:::callout
**[UI Extensions](Writing-Extensions)**

UI extension chạy trong môi trường trình duyệt và mở rộng chức năng của SillyTavern bằng cách kết nối vào các sự kiện và API của nó.
:::

:::callout
**[Server Plugins](Server-Plugins)**

Server plugin cho phép thêm chức năng như các API endpoint mới bằng cách chạy code trong môi trường NodeJS.
:::

:::callout
**[Internationalization (i18n)](i18n)**

Tìm hiểu cách dịch giao diện người dùng của SillyTavern sang ngôn ngữ của bạn.
:::

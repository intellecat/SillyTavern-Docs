# Internationalization (i18n)

SillyTavern hỗ trợ nhiều ngôn ngữ. Hướng dẫn này giải thích cách thêm và quản lý bản dịch.

Có thể bạn đang ở đây vì một phần văn bản nào đó chưa được dịch sang ngôn ngữ của bạn và nó đang khiến bạn khó chịu. Đầu tiên tôi sẽ
cho bạn thấy cách tôi sửa một số bản dịch bị thiếu trong locale tiếng Trung (Phồn thể). Mỗi cái bị thiếu vì một lý do
khác nhau, vì vậy bạn sẽ có ý tưởng tốt về cách sửa các bản dịch bị thiếu của riêng bạn.

Trong nửa sau, chúng ta xem xét

- [cách i18n hoạt động](#how-translations-work) trong SillyTavern,
- [viết bản dịch](#language-files) và code để sử dụng chúng,
- các hàm gỡ lỗi để [tìm bản dịch bị thiếu](#finding-missing-translations),
- thêm một [ngôn ngữ mới](#adding-a-new-language),
- và [đóng góp thay đổi của bạn](#contributing).

Nếu bạn đang phát triển một extension hoặc sửa đổi code lõi, hãy viết HTML và JavaScript của bạn với i18n trong đầu. Bằng cách này
công việc của bạn đã sẵn sàng để người khác dịch nó sang ngôn ngữ của họ.

Không ai biết 15 ngôn ngữ một mình. Chúng ta làm việc cùng nhau để làm cho SillyTavern có thể truy cập được cho mọi người.

**Mọi người trên thế giới nên có thể sử dụng ngôn ngữ riêng của họ trên điện thoại và máy tính.**

---

## Hãy sửa một số bản dịch bị thiếu!

!!!info
Cả 3 vấn đề này đều yêu cầu thay đổi code để sửa. Nếu bạn đang thêm một bản dịch mới, bạn có thể không cần chạm vào
code nào cả. Chỉ cần thêm bản dịch vào file JSON. Chỉ là tình cờ ai đó gần đây đã thêm một số lượng lớn
bản dịch bị thiếu vào file JSON tiếng Trung (Phồn thể), vì vậy các vấn đề còn lại đều nằm trong code. Trong các locale khác
có nhiều bản dịch bị thiếu mà bạn có thể sửa mà không cần chạm vào code.
!!!

### `Generate Image`

Văn bản "Generate Image" chưa được dịch trong locale tiếng Trung (Phồn thể). Tại sao?

![generate-image-pre.png](../static/i18n/generate-image-pre.png)

Nhấp chuột phải vào phần tử và kiểm tra nó. Bạn sẽ thấy HTML:

```html
<!--rendered HTML-->
<div class="list-group-item flex-container flexGap5 interactable" id="sd_gen" tabindex="0">
    <div data-i18n="[title]Trigger Stable Diffusion" title="觸發 Stable Diffusion"
         class="fa-solid fa-paintbrush extensionsMenuExtensionButton"></div>
    <span>Generate Image</span>
</div>
```

Thuộc tính `data-i18n` của nó ở đâu? Nó bị thiếu! Hãy thêm nó. Chúng ta tìm thấy nó trong mã nguồn:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span>Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

Chúng ta may mắn, chuỗi `Generate Image` đó có trong nhiều file ngôn ngữ, bao gồm cả tiếng Trung (Phồn thể).

![generate-image-lang.png](../static/i18n/generate-image-lang.png)

```json
{
    "Generate Image": "生成图片"
}
```

Tại sao nó không hiển thị? Chúng ta phải kết nối phần tử một cách chính xác:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

Bây giờ nó hoạt động! Tải lại trang và xem.

![generate-image-post.png](../static/i18n/generate-image-post.png)

Nhưng trong khi chúng ta mở HTML, `Stop Image Generation` ngay bên dưới nó thì sao? HTML không đúng.

Nếu chúng ta tạo một hình ảnh và sau đó mở menu wand trong khi nó đang tạo, chúng ta thấy văn bản chưa được dịch.

![stop-generating-image-pre.png](../static/i18n/stop-generating-image-pre.png)

Đầu tiên sửa HTML:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span data-i18n="Stop Image Generation">Stop Image Generation</span>
</div>
```

Điều này không đủ để sửa vấn đề. Không có bản dịch nào cho "Stop Image Generation" trong file tiếng Trung (Phồn thể). Chúng ta có thể thêm nó! Đây là một bản dịch có thể:

```json
{
    "Stop Image Generation": "停止生成图片"
}
```

... mà chúng ta có thể thêm vào file JSON ngay sau bản dịch "Generate Image".

```json
{
    "Generate Image": "生成图片",
    "Stop Image Generation": "停止生成图片"
}
```

Sau một số thảo luận với Claude, chúng tôi thực sự sẽ sử dụng các bản dịch sau:

- Tiếng Trung Phồn thể: "Stop Image Generation": "終止圖片生成"
- Tiếng Trung Giản thể: "Stop Image Generation": "中止图像生成"
- Tiếng Nhật: "Stop Image Generation": "画像生成を停止"

### `Inspect Prompts`

Văn bản "Inspect Prompts" chưa được dịch trong locale tiếng Trung (Phồn thể). Tại sao?
Cái này phức tạp hơn một chút. Văn bản được tạo bởi JavaScript và bản dịch bị thiếu.

```js
// Extension-PromptInspector/index.js
const enabledText = 'Stop Inspecting';
const disabledText = 'Inspect Prompts';
```

À, bạn có biết không... cả hai cụm từ đều không có trong các file i18n. Hãy thêm chúng.

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示"
}
```

Bây giờ chúng ta phải sửa code JavaScript. Nó phải sử dụng hàm `t` để lấy bản dịch.

```js
// Extension-PromptInspector/index.js
import {t} from '../../../i18n.js';

const enabledText = t`Stop Inspecting`;
const disabledText = t`Inspect Prompts`;
```

Chúng tôi nhận được các gợi ý từ Claude. Giữ các chuỗi, bỏ qua code. Chúng phải được thêm vào các file JSON.

```js
// 1. Simplified Chinese (zh-cn):
const enabledText = t`停止检查`;
const disabledText = t`检查提示词`;
// 2. Traditional Chinese (zh-tw):
const enabledText = t`停止檢查`;
const disabledText = t`檢查提示詞`;
// 3. Japanese (ja-jp):
const enabledText = t`検査を停止`;
const disabledText = t`プロンプトを検査`;
```

Chúng ta sẽ hợp nhất chúng vào các file JSON.

```json
{
    "Stop Inspecting": "停止检查",
    "Inspect Prompts": "检查提示词"
}
```

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示詞"
}
```

```json
{
    "Stop Inspecting": "検査を停止",
    "Inspect Prompts": "プロンプトを検査"
}
```

![toggle-prompt-inspection-post-tt.png](../static/i18n/toggle-prompt-inspection-post-tt.png)

Thật đáng tiếc về tooltip đó. Vấn đề là code không sử dụng
hàm `t`.

```js
launchButton.title = 'Toggle prompt inspection';
```

Chúng ta sẽ phải sửa điều đó trong code extension.

```js
launchButton.title = t`Toggle prompt inspection`;
```

Chúng ta cũng cần thêm các bản dịch vào các file JSON.

```json
{
    "Toggle prompt inspection": "切换提示检查"
}
```

```json
{
    "Toggle prompt inspection": "切换提示词检查"
}
```

```json
{
    "Toggle prompt inspection": "プロンプト検査の切り替え"
}
```

Prompt inspector là một extension riêng biệt, vì vậy chúng tôi sẽ PR các sửa code vào repo đó: https://github.com/SillyTavern/Extension-PromptInspector/pull/1

Các bản dịch sẽ được thêm vào repo SillyTavern chính. https://github.com/SillyTavern/SillyTavern/pull/3198

## Các file ngôn ngữ

Mỗi ngôn ngữ có một file JSON trong `public/locales/` được đặt tên với mã ngôn ngữ của nó (ví dụ: `ru-ru.json`).

File chứa các cặp khóa-giá trị trong đó:

- Khóa là văn bản tiếng Anh gốc hoặc các định danh duy nhất
- Giá trị là văn bản đã được dịch

Ví dụ:

```json
{
    "Save": "Сохранить",
    "Cancel": "Отмена",
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

## Cách bản dịch hoạt động

Có hai cách bản dịch được sử dụng trong ứng dụng:

1. **Phần tử HTML**: Sử dụng thuộc tính `data-i18n`
   ```html
   <div data-i18n="some_key">Default Text</div>
   ```
   Văn bản mặc định trong HTML sẽ được thay thế bằng văn bản đã dịch nếu có.

2. **Template String**: Trong code JavaScript sử dụng hàm `t`
   ```javascript
   t`Some text with ${variable}`
   ```
   Các chuỗi này nên được dịch giữ nguyên các placeholder `${0}`, `${1}`, v.v.

SillyTavern sử dụng các phần tử HTML với thuộc tính `data-i18n` để đánh dấu nội dung có thể dịch. Có nhiều cách để sử dụng
điều này:

### 1. Dịch văn bản phần tử

Đối với nội dung văn bản đơn giản:

```html
<span data-i18n="Role:">Role:</span>
```

```json
{
    "Role:": "Роль:"
}
```

Điều này thay thế nội dung văn bản của phần tử bằng bản dịch của "Role:".

### 2. Dịch thuộc tính

Để dịch một thuộc tính như title hoặc placeholder:

```html
<a class="menu_button fa-chain fa-solid fa-fw"
   title="Insert prompt"
   data-i18n="[title]Insert prompt"></a>
```

```json
{
    "Insert prompt": "Вставить промпт"
}
```

Tiền tố `[title]` chỉ ra thuộc tính nào cần dịch. Phần còn lại của giá trị thuộc tính là văn bản sẽ
được sử dụng làm khóa tra cứu trong file JSON. Các lập trình viên thường sử dụng văn bản tiếng Anh làm khóa, nhưng không
bắt buộc. Khóa có thể là bất kỳ định danh duy nhất nào.

Văn bản tiếng Anh gốc phải có trong thuộc tính tương ứng (`title="Insert prompt"`). Nó được sử dụng như
một phương án dự phòng nếu bản dịch bị thiếu. Đáng chú ý nhất, không có file dịch cho tiếng Anh.

Đây là ví dụ về việc sử dụng định danh duy nhất `no_items_text` làm khóa, thay vì văn bản tiếng Anh:

```html
<!--suppress HtmlUnknownAttribute -->
<div class="openai_logit_bias_list" no_items_text="No items"
     data-i18n="[no_items_text]openai_logit_bias_no_items"></div>
```

```json
{
    "openai_logit_bias_no_items": "没有相关产品"
}
```

### 3. Nhiều bản dịch cho mỗi phần tử

Một số phần tử cần cả bản dịch nội dung và thuộc tính, được phân tách bằng dấu chấm phẩy. Mẫu phổ biến nhất là
dịch cả nội dung văn bản của phần tử và thuộc tính title của nó:

```html
<div data-source="openrouter" class="menu_button menu_button_icon openrouter_authorize"
     title="Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai"
     data-i18n="Authorize;[title]Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai">
    Authorize
</div>
```

```json
{
    "Authorize": "Авторизоваться",
    "Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai": "Получите свой OpenRouter API токен используя OAuth. У вас будет открыта вкладка openrouter.ai"
}
```

Điều này dịch:

- Nội dung văn bản của phần tử sử dụng khóa "Authorize"
- Thuộc tính title sử dụng khóa "Get your OpenRouter API token using OAuth flow. You will be redirected to
  openrouter.ai"

Lưu ý rằng cả thuộc tính `title` và nội dung văn bản của phần tử đều được cung cấp bằng tiếng Anh làm phương án dự phòng.

Bạn cũng có thể dịch nhiều thuộc tính:

```html
<!--suppress HtmlUnknownAttribute -->
<textarea id="send_textarea" name="text" class="mdHotkeys"
          data-i18n="[no_connection_text]Not connected to API!;[connected_text]Type a message, or /? for help"
          placeholder="Not connected to API!"
          no_connection_text="Not connected to API!"
          connected_text="Type a message, or /? for help"></textarea>
```

Các bản dịch tương ứng trong file ngôn ngữ của bạn sẽ trông như thế này:

```json
{
    "Not connected to API!": "Нет соединения с API!",
    "Type a message, or /? for help": "Введите сообщение или /? для помощи"
}
```

Khi trang tải, hệ thống:

1. Tìm tất cả các phần tử có thuộc tính `data-i18n`
2. Phân tích cú pháp bất kỳ tiền tố thuộc tính nào như `[title]` hoặc `[placeholder]`
3. Tra cứu mỗi khóa trong file JSON của ngôn ngữ bạn
4. Thay thế nội dung hoặc thuộc tính của phần tử bằng văn bản đã dịch

### Văn bản động

Đối với văn bản động trong code JavaScript, bản dịch sử dụng:

1. Template literal với hàm `t`:
    ```javascript
    toastr.warn(t`Tag ${tagName} not found.`);
    ```
2. Hàm dịch trực tiếp:
    ```javascript
    translate("Some text", "optional_key")
    ```

### Placeholder biến

Một số chuỗi chứa các placeholder cho giá trị động sử dụng `${0}`, `${1}`, v.v.:

```js
toastr.error(t`Could not find proxy with name '${presetName}'`);
```

```json
{
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

Giữ các placeholder giống nhau cho khóa và bản dịch. Hệ thống sẽ thay thế `${0}` bằng giá trị của `presetName`, v.v.

## Tìm bản dịch bị thiếu

Giả sử bạn không chỉ muốn sửa một bản dịch bị thiếu gây khó chịu, bạn muốn tìm tất cả chúng.

Đó là một tham vọng lớn! Ngay cả việc sửa một bản dịch cũng đáng giá. Nhưng nếu bạn muốn bắt tất cả, bạn cần một công cụ.

### SillyTavern-i18n

https://github.com/SillyTavern/SillyTavern-i18n

Công cụ làm việc với các file bản địa hóa frontend.

Tính năng:

- Tự động thêm các khóa mới để dịch từ các file HTML.
- Loại bỏ các khóa bị thiếu khỏi các file bản địa hóa.
- Sử dụng dịch tự động Google để tự động điền các giá trị bị thiếu.
- Sắp xếp các file JSON theo khóa.

### Các hàm gỡ lỗi tích hợp

Chúng nằm dưới <i class="fa-fw fa-solid fa-user-cog"></i> **User Settings** > **Debug Menu**.

#### Get missing translations

Phát hiện dữ liệu bản địa hóa bị thiếu trong locale hiện tại và đổ dữ liệu vào console trình duyệt. Nếu locale hiện tại
là tiếng Anh, tìm kiếm tất cả các locale khác.

Console sẽ hiển thị một bảng các bản dịch bị thiếu với:

- key: Văn bản hoặc định danh cần dịch
- language: Mã ngôn ngữ hiện tại của bạn
- value: Văn bản tiếng Anh cần dịch

#### Apply locale

Áp dụng lại locale hiện đang được chọn cho trang

!!!warning Cả hai công cụ này đều không hoàn hảo

- chúng không bắt được bản dịch bị thiếu trong code JavaScript
- chúng không bắt được thuộc tính data-i18n bị thiếu trong HTML, chúng chỉ bắt các khóa chưa được dịch
- có lỗi trong code cho `getMissingTranslations`: các khóa không nên được tiền tố với `[title]` hoặc `[placeholder]`
  !!!

## Thêm một ngôn ngữ mới

Để thêm hỗ trợ cho một ngôn ngữ mới:

1. Thêm ngôn ngữ của bạn vào `public/locales/lang.json`:

   ```json
   {
     "lang": "xx-xx",
     "display": "Language Name (English Name)"
   }
   ```

2. Tạo `public/locales/xx-xx.json` với các bản dịch của bạn

## Đóng góp

Khi các bản dịch của bạn đã sẵn sàng:

1. Xác minh file JSON của bạn hợp lệ
2. Kiểm tra kỹ lưỡng trong ứng dụng
3. Gửi qua GitHub pull request

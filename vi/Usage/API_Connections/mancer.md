# Mancer

Mancer là một dịch vụ suy luận mô hình ngôn ngữ lớn cho phép bạn chạy bất kỳ prompt nào bạn muốn và không kiểm duyệt phản hồi. Hầu hết các mô hình yêu cầu số dư được nạp trước để bắt đầu trò chuyện, nhưng có một mô hình miễn phí tại thời điểm viết (2024-11-28).

- [Models](https://mancer.tech/models)
- [Pricing](https://mancer.tech/pricing)

## Cách Bắt Đầu

1. Đăng ký tài khoản tại [mancer.tech](https://mancer.tech/).
2. Nhấp vào Dashboard và sao chép API Key của bạn.

    ![Mancer dashboard as of 2/27/2024](/static/mancer-dashboard.png)

3. Trong SillyTavern, chọn Text Completion API, sau đó chọn Mancer trong API Type.
4. Nhập Mancer API Key của bạn và nhấp Connect.

![API Key](/static/mancer-key.png)

Bây giờ bạn có thể trò chuyện với bất kỳ mô hình Mancer nào bạn chọn.

## Anonymous Logging

Nếu bạn không ngại cuộc trò chuyện của mình có thể được sử dụng để đào tạo mô hình, cải thiện dịch vụ của Mancer, xuất bản dataset hoặc *bất cứ điều gì khác* mà họ có thể quyết định làm với nó, bạn có thể tham gia ghi nhật ký ẩn danh để được giảm giá token 25% trên các mô hình được chọn. Chỉ cần vào [Mancer dashboard](https://mancer.tech/dashboard.html) và đánh dấu `Enable Anon. Logging`.

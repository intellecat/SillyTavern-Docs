# Desenvolvimento e Automação

O pacote padrão do SillyTavern fornece apenas uma plataforma básica que pode ser estendida de várias maneiras.

:::callout
**[STscript](st-script)**

STscript é uma linguagem de script poderosa baseada em comandos de chat em lote que pode ser utilizada sem qualquer conhecimento prévio de programação.
:::

:::callout
**[Function Calling](Function-Calling)**

Adicione mais capacidades dinâmicas permitindo que o LLM use fontes externas de dados ou acione funcionalidades específicas da extensão.
:::

:::callout
**[Extensões de UI](Writing-Extensions)**

As extensões de UI são executadas em um ambiente de navegador e expandem a funcionalidade do SillyTavern conectando-se a seus eventos e API.
:::

:::callout
**[Plugins de Servidor](Server-Plugins)**

Os plugins de servidor permitem adicionar funcionalidades como novos endpoints de API executando código no ambiente NodeJS.
:::

:::callout
**[Internacionalização (i18n)](i18n)**

Aprenda como traduzir a interface do SillyTavern para o seu idioma.
:::

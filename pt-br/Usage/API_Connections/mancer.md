# Mancer

Mancer é um serviço de inferência de large language model que permite executar quaisquer prompts que você quiser e não censura respostas. A maioria dos modelos requer um saldo pré-carregado para começar a conversar, mas há um modelo gratuito no momento da escrita (2024-11-28).

- [Models](https://mancer.tech/models)
- [Pricing](https://mancer.tech/pricing)

## Como Começar

1. Inscreva-se para uma conta em [mancer.tech](https://mancer.tech/).
2. Clique em Dashboard e copie sua API Key.

    ![Mancer dashboard as of 2/27/2024](/static/mancer-dashboard.png)

3. No SillyTavern, selecione a API Text Completion e, em seguida, selecione Mancer em API Type.
4. Digite sua Mancer API Key e clique em Connect.

![API Key](/static/mancer-key.png)

Agora você deve ser capaz de conversar com qualquer modelo Mancer de sua escolha.

## Anonymous Logging

Se você não se importa que seus chats sejam potencialmente usados para treinar modelos, melhorar o serviço do Mancer, publicar conjuntos de dados ou *qualquer outra coisa* que eles possam decidir fazer com isso, você pode optar por registro anônimo para um desconto de 25% em tokens em modelos selecionados. Simplesmente vá para o seu [painel Mancer](https://mancer.tech/dashboard.html) e marque `Enable Anon. Logging`.

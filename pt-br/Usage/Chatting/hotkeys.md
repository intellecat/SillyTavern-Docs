# HotKeys

**Para a lista mais atualizada de HotKeys que funcionarão na sua instância do SillyTavern, use o comando slash `/help hotkeys` em qualquer chat.**

**Hotkeys estão desabilitados para dispositivos móveis.**

## Chat Hotkeys

* Up = Editar última mensagem no chat
* Ctrl+Up = Editar última mensagem do USUÁRIO no chat
* Left = swipe para esquerda
* Right = swipe para direita (NOTA: hotkeys de swipe são desabilitados quando a barra de chat tem algo digitado)
* Enter (com barra de chat selecionada) = enviar sua mensagem para a IA
* Ctrl+Enter = Regenerar a última resposta da IA
* Alt+Enter = Continuar a última resposta da IA
* Escape
  * *(enquanto edita mensagem E Message Edit AutoSave está habilitado)* = fechar caixa de edição.
  * *(enquanto uma mensagem da IA está sendo gerada ou em streaming)* = parar a geração imediatamente.

## Markdown Hotkeys

Precisa ser habilitado na aba "User Settings". Funciona na barra de chat e áreas de texto marcadas com o ícone "M↓":

* Ctrl+B = \*\*negrito\*\*
* Ctrl+I = \*itálico\*
* Ctrl+U = \_\_sublinhado\_\_
* Ctrl+K = \`código inline\`
* Ctrl+Shift+~ = \~\~riscado\~\~

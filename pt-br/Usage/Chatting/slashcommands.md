# Slash commands

!!!warning
**Esta não é uma lista exaustiva, pois é atualizada raramente.**

Para a lista mais atualizada de comandos que funcionarão na sua instância, use o comando de chat `/help slash` em qualquer chat do SillyTavern.
!!!

- `/help` – exibe a mensagem de ajuda
- `/api` - alterna para uma API diferente
- `/sys` - envia uma mensagem neutra como narrador do sistema
- `/send` - envia uma mensagem como o usuário sem acionar a geração
- `/sendas` – envia uma mensagem como um personagem específico
- `/comment` - adiciona um comentário ao chat invisível para a IA
- `/impersonate` - pede à IA para escrever como você com um prompt opcional
- `/persona` - define sua persona de usuário
- `/imagine` - gera uma imagem a partir de um prompt de texto
- `/bg` - define uma imagem de fundo pelo nome do arquivo

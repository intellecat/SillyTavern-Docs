# 개발 및 자동화

SillyTavern의 기본 패키지는 다양한 방법으로 확장할 수 있는 기본 플랫폼만 제공합니다.

:::callout
**[STscript](st-script)**

STscript는 사전 코딩 지식 없이 접근할 수 있는 배치된 채팅 명령을 기반으로 한 강력한 스크립팅 언어입니다.
:::

:::callout
**[함수 호출](Function-Calling)**

LLM이 외부 데이터 소스를 사용하거나 익스텐션의 특정 기능을 트리거하도록 하여 더 동적인 기능을 추가합니다.
:::

:::callout
**[UI 익스텐션](Writing-Extensions)**

UI 익스텐션은 브라우저 환경에서 실행되며 이벤트와 API에 연결하여 SillyTavern의 기능을 확장합니다.
:::

:::callout
**[서버 플러그인](Server-Plugins)**

서버 플러그인을 사용하면 NodeJS 환경에서 코드를 실행하여 새 API 엔드포인트와 같은 기능을 추가할 수 있습니다.
:::

:::callout
**[국제화 (i18n)](i18n)**

SillyTavern의 UI를 여러분의 언어로 번역하는 방법을 배웁니다.
:::

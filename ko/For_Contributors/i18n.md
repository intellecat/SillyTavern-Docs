# 국제화 (i18n)

SillyTavern은 여러 언어를 지원합니다. 이 가이드는 번역을 추가하고 관리하는 방법을 설명합니다.

아마도 여러분의 언어에서 번역되지 않은 텍스트가 있어서 이곳에 오셨을 것입니다. 먼저 중국어(번체) 로케일에서 누락된 번역을 수정한 방법을 보여드리겠습니다. 각각 다른 이유로 누락되었으므로, 여러분의 누락된 번역을 수정하는 방법에 대한 좋은 아이디어를 얻을 수 있을 것입니다.

두 번째 부분에서는 다음을 살펴봅니다.

- SillyTavern에서 [i18n이 작동하는 방식](#how-translations-work)
- [번역 작성](#language-files) 및 이를 사용하는 코드
- [누락된 번역을 찾기](#finding-missing-translations) 위한 디버그 함수
- [새 언어 추가](#adding-a-new-language)
- [변경 사항 기여](#contributing)

익스텐션을 개발하거나 핵심 코드를 수정하는 경우, HTML과 JavaScript를 i18n을 염두에 두고 작성하세요. 이렇게 하면 다른 사람들이 여러분의 작업을 자신의 언어로 번역할 준비가 됩니다.

아무도 혼자서 15개 언어를 알지 못합니다. 우리는 함께 협력하여 SillyTavern을 모든 사람이 접근할 수 있도록 만듭니다.

**전 세계 모든 사람이 휴대폰과 컴퓨터에서 자신의 언어를 사용할 수 있어야 합니다.**

---

## 누락된 번역을 수정해 봅시다!

!!!info
이 세 가지 문제는 모두 수정하기 위해 코드 변경이 필요했습니다. 새 번역을 추가하는 경우 코드를 전혀 건드릴 필요가 없을 수도 있습니다. JSON 파일에 번역만 추가하면 됩니다. 최근에 누군가가 중국어(번체) JSON 파일에 많은 누락된 번역을 추가했기 때문에, 남은 문제는 모두 코드에 있었습니다. 다른 로케일에는 코드를 건드리지 않고도 수정할 수 있는 누락된 번역이 많이 있습니다.
!!!

### `Generate Image`

"Generate Image" 텍스트가 중국어(번체) 로케일에서 번역되지 않았습니다. 왜일까요?

![generate-image-pre.png](../static/i18n/generate-image-pre.png)

요소를 마우스 오른쪽 버튼으로 클릭하고 검사합니다. HTML이 보입니다:

```html
<!--rendered HTML-->
<div class="list-group-item flex-container flexGap5 interactable" id="sd_gen" tabindex="0">
    <div data-i18n="[title]Trigger Stable Diffusion" title="觸發 Stable Diffusion"
         class="fa-solid fa-paintbrush extensionsMenuExtensionButton"></div>
    <span>Generate Image</span>
</div>
```

`data-i18n` 속성은 어디에 있습니까? 누락되었습니다! 추가해 봅시다. 소스 코드에서 찾습니다:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span>Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

운이 좋게도 `Generate Image` 문자열이 중국어(번체)를 포함한 많은 언어 파일에 있습니다.

![generate-image-lang.png](../static/i18n/generate-image-lang.png)

```json
{
    "Generate Image": "生成图片"
}
```

왜 표시되지 않을까요? 요소를 올바르게 연결해야 합니다:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

이제 작동합니다! 페이지를 새로고침하여 확인하세요.

![generate-image-post.png](../static/i18n/generate-image-post.png)

그런데 HTML을 열어보니 바로 아래에 있는 `Stop Image Generation`은 무엇인가요? HTML이 올바르지 않아 보입니다.

이미지를 생성한 다음 생성하는 동안 마법봉 메뉴를 열면 번역되지 않은 텍스트가 표시됩니다.

![stop-generating-image-pre.png](../static/i18n/stop-generating-image-pre.png)

먼저 HTML을 수정합니다:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span data-i18n="Stop Image Generation">Stop Image Generation</span>
</div>
```

이것만으로는 문제를 해결하기에 충분하지 않습니다. 중국어(번체) 파일에 "Stop Image Generation"에 대한 번역이 없습니다. 추가할 수 있습니다! 다음은 가능한 번역입니다:

```json
{
    "Stop Image Generation": "停止生成图片"
}
```

... 이것을 "Generate Image" 번역 바로 뒤의 JSON 파일에 추가할 수 있습니다.

```json
{
    "Generate Image": "生成图片",
    "Stop Image Generation": "停止生成图片"
}
```

Claude와의 논의 끝에 실제로는 다음 번역을 사용하기로 했습니다:

- 번체 중국어: "Stop Image Generation": "終止圖片生成"
- 간체 중국어: "Stop Image Generation": "中止图像生成"
- 일본어: "Stop Image Generation": "画像生成を停止"

### `Generate Caption`

"Generate Caption"이 중국어(번체) 로케일에서 번역되지 않았습니다. 수정해 봅시다!

![generate-image-post.png](../static/i18n/generate-image-post.png)

어디에 있습니까? 요소를 검사합니다.

```html
<!--rendered HTML-->
<div id="send_picture" class="list-group-item flex-container flexGap5 interactable" tabindex="0">
    <div class="fa-solid fa-image extensionsMenuExtensionButton"></div>
    Generate Caption
</div>
```

이 HTML은 JavaScript에 의해 생성됩니다. 소스 코드를 찾아봅시다.

```js
// public/scripts/extensions/caption/index.js
const sendButton = $(`
        <div id="send_picture" class="list-group-item flex-container flexGap5">
            <div class="fa-solid fa-image extensionsMenuExtensionButton"></div>
            Generate Caption
        </div>`);
```

먼저 코드를 수정해야 합니다:

```js
// public/scripts/extensions/caption/index.js
const sendButton = $(`
        <div id="send_picture" class="list-group-item flex-container flexGap5">
            <div class="fa-solid fa-image extensionsMenuExtensionButton"></div>
            <span data-i18n="Generate Caption">Generate Caption</span>
        </div>`);
```

중국어(번체) 파일에도 "Generate Caption"에 대한 번역이 없습니다. 추가해 봅시다!

```json
{
    "Generate Caption": "生成圖片說明"
}
```

다음 번역을 사용하겠습니다:

- 번체 중국어: "Generate Caption": "生成圖片說明"
- 간체 중국어: "Generate Caption": "生成图片说明"
- 일본어: "Generate Caption": "画像説明を生成"

### `Inspect Prompts`

"Inspect Prompts" 텍스트가 중국어(번체) 로케일에서 번역되지 않았습니다. 왜일까요?
이것은 좀 더 복잡합니다. 텍스트가 JavaScript로 생성되고 번역이 누락되었습니다.

```js
// Extension-PromptInspector/index.js
const enabledText = 'Stop Inspecting';
const disabledText = 'Inspect Prompts';
```

놀랍게도... 두 문구 모두 i18n 파일에 없습니다. 추가해 봅시다.

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示"
}
```

이제 JavaScript 코드를 수정해야 합니다. 번역을 가져오기 위해 `t` 함수를 사용해야 합니다.

```js
// Extension-PromptInspector/index.js
import {t} from '../../../i18n.js';

const enabledText = t`Stop Inspecting`;
const disabledText = t`Inspect Prompts`;
```

Claude로부터 이러한 제안을 받았습니다. 문자열은 유지하고 코드는 무시하세요. JSON 파일에 추가해야 합니다.

```js
// 1. 간체 중국어 (zh-cn):
const enabledText = t`停止检查`;
const disabledText = t`检查提示词`;
// 2. 번체 중국어 (zh-tw):
const enabledText = t`停止檢查`;
const disabledText = t`檢查提示詞`;
// 3. 일본어 (ja-jp):
const enabledText = t`検査を停止`;
const disabledText = t`プロンプトを検査`;
```

이것들을 JSON 파일에 병합하겠습니다.

```json
{
    "Stop Inspecting": "停止检查",
    "Inspect Prompts": "检查提示词"
}
```

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示詞"
}
```

```json
{
    "Stop Inspecting": "検査を停止",
    "Inspect Prompts": "プロンプトを検査"
}
```

![toggle-prompt-inspection-post-tt.png](../static/i18n/toggle-prompt-inspection-post-tt.png)

그 툴팁은 안타깝습니다. 문제는 코드가 `t` 함수를 사용하지 않는다는 것입니다.

```js
launchButton.title = 'Toggle prompt inspection';
```

익스텐션 코드에서 이를 수정해야 합니다.

```js
launchButton.title = t`Toggle prompt inspection`;
```

또한 JSON 파일에 번역을 추가해야 합니다.

```json
{
    "Toggle prompt inspection": "切换提示检查"
}
```

```json
{
    "Toggle prompt inspection": "切换提示词检查"
}
```

```json
{
    "Toggle prompt inspection": "プロンプト検査の切り替え"
}
```

Prompt inspector는 별도의 익스텐션이므로 코드 수정을 해당 저장소에 PR하겠습니다: https://github.com/SillyTavern/Extension-PromptInspector/pull/1

번역은 메인 SillyTavern 저장소에 추가됩니다. https://github.com/SillyTavern/SillyTavern/pull/3198

## 언어 파일

각 언어에는 `public/locales/`에 언어 코드로 명명된 JSON 파일이 있습니다(예: `ru-ru.json`).

파일에는 키-값 쌍이 포함되어 있습니다:

- 키는 원본 영어 텍스트 또는 고유 식별자입니다
- 값은 번역된 텍스트입니다

예시:

```json
{
    "Save": "Сохранить",
    "Cancel": "Отмена",
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

## 번역이 작동하는 방식

애플리케이션에서 번역이 사용되는 방법은 두 가지입니다:

1. **HTML 요소**: `data-i18n` 속성 사용
   ```html
   <div data-i18n="some_key">Default Text</div>
   ```
   HTML의 기본 텍스트는 번역된 텍스트가 있는 경우 이것으로 대체됩니다.

2. **템플릿 문자열**: JavaScript 코드에서 `t` 함수 사용
   ```javascript
   t`Some text with ${variable}`
   ```
   이러한 문자열은 `${0}`, `${1}` 등의 자리 표시자를 그대로 유지하면서 번역해야 합니다.

SillyTavern은 번역 가능한 콘텐츠를 표시하기 위해 `data-i18n` 속성이 있는 HTML 요소를 사용합니다. 이를 사용하는 몇 가지 방법이 있습니다:

### 1. 요소 텍스트 번역

간단한 텍스트 콘텐츠의 경우:

```html
<span data-i18n="Role:">Role:</span>
```

```json
{
    "Role:": "Роль:"
}
```

이것은 요소의 텍스트 콘텐츠를 "Role:"의 번역으로 대체합니다.

### 2. 속성 번역

title이나 placeholder와 같은 속성을 번역하려면:

```html
<a class="menu_button fa-chain fa-solid fa-fw"
   title="Insert prompt"
   data-i18n="[title]Insert prompt"></a>
```

```json
{
    "Insert prompt": "Вставить промпт"
}
```

`[title]` 접두사는 번역할 속성을 나타냅니다. 속성 값의 나머지 부분은 JSON 파일에서 조회 키로 사용될 텍스트입니다. 코더들이 영어 텍스트를 키로 사용하는 것이 일반적이지만 필수는 아닙니다. 키는 고유 식별자일 수 있습니다.

원본 영어 텍스트는 해당 속성(`title="Insert prompt"`)에 있어야 합니다. 번역이 누락된 경우 대체로 사용됩니다. 가장 주목할 만한 것은 영어를 위한 번역 파일이 없다는 것입니다.

다음은 영어 텍스트가 아닌 고유 식별자 `no_items_text`를 키로 사용하는 예입니다:

```html
<!--suppress HtmlUnknownAttribute -->
<div class="openai_logit_bias_list" no_items_text="No items"
     data-i18n="[no_items_text]openai_logit_bias_no_items"></div>
```

```json
{
    "openai_logit_bias_no_items": "没有相关产品"
}
```

### 3. 요소당 여러 번역

일부 요소는 세미콜론으로 구분된 콘텐츠와 속성 번역이 모두 필요합니다. 가장 일반적인 패턴은 요소의 텍스트 콘텐츠와 title 속성을 모두 번역하는 것입니다:

```html
<div data-source="openrouter" class="menu_button menu_button_icon openrouter_authorize"
     title="Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai"
     data-i18n="Authorize;[title]Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai">
    Authorize
</div>
```

```json
{
    "Authorize": "Авторизоваться",
    "Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai": "Получите свой OpenRouter API токен используя OAuth. У вас будет открыта вкладка openrouter.ai"
}
```

이것은 다음을 번역합니다:

- "Authorize" 키를 사용하여 요소의 텍스트 콘텐츠
- "Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai" 키를 사용하여 title 속성

title 속성과 요소의 텍스트 콘텐츠 모두 대체로 영어로 제공됩니다.

여러 속성을 번역할 수도 있습니다:

```html
<!--suppress HtmlUnknownAttribute -->
<textarea id="send_textarea" name="text" class="mdHotkeys"
          data-i18n="[no_connection_text]Not connected to API!;[connected_text]Type a message, or /? for help"
          placeholder="Not connected to API!"
          no_connection_text="Not connected to API!"
          connected_text="Type a message, or /? for help"></textarea>
```

언어 파일의 해당 번역은 다음과 같습니다:

```json
{
    "Not connected to API!": "Нет соединения с API!",
    "Type a message, or /? for help": "Введите сообщение или /? для помощи"
}
```

페이지가 로드되면 시스템은:

1. `data-i18n` 속성이 있는 모든 요소를 찾습니다
2. `[title]` 또는 `[placeholder]`와 같은 속성 접두사를 파싱합니다
3. 언어의 JSON 파일에서 각 키를 조회합니다
4. 요소의 콘텐츠 또는 속성을 번역된 텍스트로 대체합니다

### 동적 텍스트

JavaScript 코드의 동적 텍스트의 경우 다음 중 하나를 사용합니다:

1. `t` 함수가 있는 템플릿 리터럴:
    ```javascript
    toastr.warn(t`Tag ${tagName} not found.`);
    ```
2. 직접 번역 함수:
    ```javascript
    translate("Some text", "optional_key")
    ```

### 변수 자리 표시자

일부 문자열에는 `${0}`, `${1}` 등을 사용하는 동적 값을 위한 자리 표시자가 포함되어 있습니다:

```js
toastr.error(t`Could not find proxy with name '${presetName}'`);
```

```json
{
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

키와 번역에 대해 자리 표시자를 동일하게 유지하세요. 시스템은 `${0}`을 `presetName`의 값 등으로 대체합니다.

## 누락된 번역 찾기

성가신 누락된 번역 하나만 수정하고 싶지 않고 모두 찾고 싶다고 가정해 봅시다.

큰 야망입니다! 번역 하나만 수정해도 가치가 있습니다. 하지만 모두 잡고 싶다면 도구가 필요합니다.

### SillyTavern-i18n

https://github.com/SillyTavern/SillyTavern-i18n

프론트엔드 로컬라이제이션 파일 작업을 위한 도구입니다.

기능:

- HTML 파일에서 번역할 새 키를 자동으로 추가합니다.
- 로컬라이제이션 파일에서 누락된 키를 정리합니다.
- Google 자동 번역을 사용하여 누락된 값을 자동으로 채웁니다.
- 키로 JSON 파일을 정렬합니다.

### 내장 디버그 함수

<i class="fa-fw fa-solid fa-user-cog"></i> **사용자 설정** > **디버그 메뉴**에 있습니다.

#### 누락된 번역 가져오기

현재 로케일에서 누락된 로컬라이제이션 데이터를 감지하고 데이터를 브라우저 콘솔에 덤프합니다. 현재 로케일이 영어인 경우 다른 모든 로케일을 검색합니다.

콘솔에는 다음과 같은 누락된 번역 테이블이 표시됩니다:

- key: 번역이 필요한 텍스트 또는 식별자
- language: 현재 언어 코드
- value: 번역할 영어 텍스트

#### 로케일 적용

현재 선택된 로케일을 페이지에 다시 적용합니다

!!!warning 이러한 도구는 완벽하지 않습니다

- JavaScript 코드에서 누락된 번역을 잡지 못합니다
- HTML에서 누락된 data-i18n 속성을 잡지 못하고 번역되지 않은 키만 잡습니다
- `getMissingTranslations`의 코드에 버그가 있습니다: 키에 `[title]` 또는 `[placeholder]` 접두사가 붙으면 안 됩니다
!!!

## 새 언어 추가

새 언어에 대한 지원을 추가하려면:

1. `public/locales/lang.json`에 언어를 추가합니다:

   ```json
   {
     "lang": "xx-xx",
     "display": "Language Name (English Name)"
   }
   ```

2. 번역이 포함된 `public/locales/xx-xx.json`을 생성합니다

## 기여

번역이 준비되면:

1. JSON 파일이 유효한지 확인합니다
2. 애플리케이션에서 철저히 테스트합니다
3. GitHub pull request를 통해 제출합니다

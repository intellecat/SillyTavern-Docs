# 슬래시 명령

!!!warning
**이것은 거의 업데이트되지 않아 완전한 목록이 아닙니다.**

인스턴스에서 작동하는 가장 최신 명령 목록을 보려면 SillyTavern 채팅에서 `/help slash` 채팅 명령을 사용하세요.
!!!

- `/help` – 도움말 메시지를 표시합니다
- `/api` - 다른 API로 전환합니다
- `/sys` - 시스템 내레이터로 중립적인 메시지를 보냅니다
- `/send` - 생성을 트리거하지 않고 사용자로 메시지를 보냅니다
- `/sendas` – 특정 캐릭터로 메시지를 보냅니다
- `/comment` - AI에게 보이지 않는 채팅에 주석을 추가합니다
- `/impersonate` - 선택적 프롬프트와 함께 AI가 사용자로 작성하도록 요청합니다
- `/persona` - 사용자 페르소나를 설정합니다
- `/imagine` - 텍스트 프롬프트에서 이미지를 생성합니다
- `/bg` - 파일 이름으로 배경 이미지를 설정합니다

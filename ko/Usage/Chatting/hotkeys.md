# 핫키

**SillyTavern 인스턴스에서 작동하는 가장 최신 핫키 목록을 보려면 채팅에서 `/help hotkeys` 슬래시 명령을 사용하세요.**

**핫키는 모바일 장치에서 비활성화됩니다.**

## 채팅 핫키

* Up = 채팅의 마지막 메시지 편집
* Ctrl+Up = 채팅의 마지막 USER 메시지 편집
* Left = 왼쪽으로 스와이프
* Right = 오른쪽으로 스와이프(참고: 채팅바에 입력된 내용이 있으면 스와이프 핫키가 비활성화됩니다)
* Enter(채팅 바 선택 시) = AI에 메시지 보내기
* Ctrl+Enter = 마지막 AI 응답 재생성
* Alt+Enter = 마지막 AI 응답 계속
* Escape
  * *(메시지 편집 중이고 Message Edit AutoSave가 활성화된 경우)* = 편집 상자 닫기.
  * *(AI 메시지가 생성 중이거나 스트리밍 중일 때)* = 즉시 생성 중지.

## Markdown 핫키

"User Settings" 탭에서 활성화해야 합니다. 채팅바 및 "M↓" 아이콘으로 표시된 텍스트 영역에서 작동합니다:

* Ctrl+B = \*\*굵게\*\*
* Ctrl+I = \*기울임꼴\*
* Ctrl+U = \_\_밑줄\_\_
* Ctrl+K = \`인라인 코드\`
* Ctrl+Shift+~ = \~\~취소선\~\~

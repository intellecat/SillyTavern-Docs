# 사용법

당신만의 방식으로 AI와 상호작용하세요. 세계를 구축하고, 작업하고, 꿈을 실현하세요.

:::callout
## 시작하기

**[빠른 시작](/Usage/quick-start.md)**

AI에 첫 메시지를 보내고 응답을 받아보세요

**[채팅](/Usage/Chatting/index.md)**

AI와 채팅하고 채팅 인터페이스를 사용하는 방법

**[FAQ](/Usage/Common-Settings.md)**

SillyTavern, AI 모델, 캐릭터 만들기, 더 나은 응답 받기 등에 대한 자주 묻는 질문
:::


:::callout
## 기본 사항

**[API 연결](/Usage/API_Connections/index.md)**

텍스트, 이미지 등을 생성하기 위한 AI 모델에 연결

**[캐릭터](/Usage/Characters/index.md)** 및 **[페르소나](/Usage/personas.md)**

AI의 역할을 형성하는 캐릭터를 만들고 사용하며, 당신의 정체성을 정의하는 페르소나를 생성

**[응답 구성](/Usage/Common-Settings.md)** 및 **[프롬프트](/Usage/Prompts/index.md)**

AI에 보내는 요청과 응답 방식을 제어

**[환영 페이지 어시스턴트](/Usage/welcome-assistants.md)**

환영 화면에서 지정된 캐릭터로 인사를 받을 수 있도록 환영 페이지 어시스턴트를 설정하고 사용하는 방법을 알아보세요.
:::

:::callout
## SillyTavern 활용하기

**[World Info](/Usage/worldinfo.md)**

정보를 관리하고 프롬프트에 삽입할 시기를 제어

**[Data Bank](/Usage/Characters/data-bank.md)**

AI 응답에 사용할 정보를 저장하고 검색

**[확장 기능](/extensions/index.md)**

AI 또는 인터페이스에 새로운 기능을 추가

**[개발 및 자동화](/For_Contributors/index.md)**

작업 자동화, AI가 세계와 상호작용하도록 하고, 자체 확장 기능 작성
:::

# 페르소나

## 페르소나란 무엇인가요?

SillyTavern의 페르소나는 채팅에 참여할 때 사용하는 정체성입니다. 본질적으로 표시 이름, 아바타, 선택적 설명 텍스트의 조합입니다. 페르소나를 사용하면 매번 수동으로 사용자 이름/아바타를 업데이트하지 않고도 역할이나 "캐릭터"를 쉽게 전환할 수 있습니다.

!!!
**참고:** 페르소나와 연결되지 않은 레거시 사용자 아바타/이름은 제거되었습니다. 기존 데이터는 페르소나로 마이그레이션됩니다. 이름이 지정되지 않은 경우 페르소나 이름은 "[Unnamed Persona]"가 됩니다.
!!!

## 페르소나를 어떻게 만드나요?

1. **페르소나 관리** 패널을 엽니다(상단 메뉴의 <i class="fa-solid fa-face-smile"></i> 버튼).
2. **생성** 버튼으로 빈 페르소나를 만들고 이름을 지정합니다.
3. 페르소나 목록에서 새로 만든 페르소나를 선택합니다.
4. 오른쪽에서 설명을 입력하고 "페르소나 이미지 변경" 버튼을 통해 아바타를 설정할 수 있습니다. 둘 다 선택 사항입니다.
5. 이제 페르소나를 채팅에서 사용할 준비가 되었습니다.

### 캐릭터를 페르소나로 변환

페르소나는 기존 캐릭터를 변환하여 만들 수도 있습니다. 캐릭터를 열고 "More..."를 선택한 다음 "페르소나로 변환"을 클릭하세요. 동일한 이름과 설명을 가진 페르소나가 생성됩니다. 시나리오나 성격 같은 다른 캐릭터 카드 필드는 사용되지 않습니다. 캐릭터는 삭제되지 않습니다.

!!! Note
`{{user}}`와 `{{char}}` 매크로는 페르소나와 캐릭터 설명에 사용될 때 반대의 의미를 가지므로, 변환된 설명에 이들이 포함되어 있으면 교체할지 묻는 메시지가 표시됩니다.
!!!

## 페르소나 설명

각 페르소나는 사용자 정의 텍스트 설명을 저장할 수 있습니다. 정신적, 신체적 특성, 나이, 직업 또는 개인적 세부 사항 등을 포함할 수 있습니다. `{{char}}` 또는 `{{user}}`와 같은 템플릿 매크로도 포함할 수 있습니다([매크로](/usage/macros.md) 참조).

페르소나 설명이 AI 프롬프트에 삽입되는 위치는 페르소나 관리 패널의 **위치** 설정에 따라 다릅니다:

- **None (비활성화)**
- **In Story String / Prompt Manager** (기본값)
- **Top of Author's Note** / **Bottom of Author's Note** (작성자 노트가 있을 때만 추가됨)
- **In Chat @ Depth** (깊이와 역할을 설정할 수 있는 구성 옵션이 열림)

위치는 **페르소나별로** 저장됩니다.

## 페르소나 제목

제목은 페르소나에 대한 추가 정보를 저장하는 데 사용할 수 있는 선택적 텍스트 필드이며 프롬프트에는 사용되지 않지만 페르소나 관리 패널에 표시됩니다.

제목을 설정하려면 페르소나 관리 패널에서 **<i class="fa-solid fa-pencil"></i> 페르소나 이름 바꾸기** 버튼을 클릭하고 "페르소나 제목" 필드에 제목을 입력하거나 페르소나 생성 중에 지정합니다. 제목이 이미 있을 때 빈 값을 설정하면 제거됩니다.

## 페르소나 연결 / 잠금

페르소나 연결은 특정 상황에서 지정된 페르소나가 자동으로 선택되도록 합니다. 페르소나가 연결되지 않은 경우 현재 선택한 페르소나가 유지됩니다.

세 가지 유형의 잠금이 있습니다:

1. **<i class="fa-solid fa-unlock"></i> 채팅 잠금** – 페르소나가 현재 채팅에 잠깁니다.
2. **<i class="fa-solid fa-unlock"></i> 캐릭터 잠금** – 페르소나가 특정 캐릭터에 잠깁니다.
3. **<i class="fa-solid fa-crown"></i> 기본 페르소나** – 다른 잠금이 적용되지 않을 때 사용되는 하나의 페르소나.

### 1. 채팅에 잠금

페르소나가 채팅에 잠긴 경우, 나중에 해당 채팅을 열면 활성 페르소나가 자동으로 잠긴 페르소나로 전환됩니다.

- **잠금하려면**: 원하는 페르소나를 선택한 다음 "연결" 섹션 아래의 **<i class="fa-solid fa-unlock"></i> Chat** 버튼을 클릭합니다(또는 `/persona-lock type=chat on` 사용).
- **잠금 해제하려면**: 버튼을 다시 클릭합니다(또는 `/persona-lock type=chat off` 사용).

### 2. 캐릭터에 잠금

페르소나를 특정 캐릭터에 연결할 수도 있습니다. 해당 캐릭터와의 채팅을 열면 자동으로 잠긴 페르소나가 선택됩니다.

- **잠금하려면**: 원하는 페르소나를 선택한 다음 "연결" 섹션 아래의 **<i class="fa-solid fa-unlock"></i> Character** 버튼을 클릭합니다(또는 `/persona-lock type=character on` 사용).
- **잠금 해제하려면**: 버튼을 다시 클릭합니다(또는 `/persona-lock type=character off` 사용).

페르소나 관리 패널에는 해당 페르소나에 연결된 캐릭터가 표시됩니다(작은 아바타로 표시). 클릭하면 해당 캐릭터의 채팅으로 직접 이동합니다.

#### 동일한 캐릭터에 여러 페르소나 잠금

다른 페르소나가 이미 해당 캐릭터와 연결되어 있는 경우 기본적으로 자동으로 연결이 해제됩니다.

한 번에 여러 페르소나를 연결하려면 전역 설정 **캐릭터당 여러 페르소나 연결 허용**을 사용할 수 있습니다.
여러 페르소나가 동일한 캐릭터에 연결된 경우 해당 캐릭터와 새 채팅을 열거나 시작할 때마다 사용할 페르소나를 묻는 팝업이 표시됩니다(페르소나가 채팅에 바인딩되지 않은 경우).

### 3. 기본 페르소나

**기본 페르소나**는 다른 관련 잠금이 없을 때 사용됩니다. 기본 페르소나는 아바타 주위에 노란색 테두리로 식별할 수 있습니다.

- **기본 설정/해제하려면**: 원하는 페르소나를 선택한 다음 "연결" 섹션 아래의 **<i class="fa-solid fa-crown"></i> Default** 버튼을 클릭합니다(또는 `/persona-lock type=default` 사용).

하나의 페르소나만 기본 페르소나로 선택할 수 있습니다.

### 임시 페르소나

세 가지 연결 옵션 중 하나가 현재 캐릭터/채팅에 페르소나를 연결하는 경우에도 다른 페르소나를 사용하도록 선택할 수 있습니다. 이 페르소나는 페르소나 패널에서 "임시 페르소나"로 표시됩니다. 브라우저 창을 다시 로드하거나 다른 채팅으로 전환했다가 돌아오면 연결된 페르소나로 재설정됩니다.

임시 페르소나를 채팅에 연결하여 수동으로 영구적으로 연결되도록 *변환*할 수 있습니다.

## 전역 페르소나 설정

**현재 페르소나** 아래의 모든 설정은 페르소나별로 저장됩니다. 몇 가지 전역 설정도 있으며 페르소나 관리 패널의 **전역 페르소나 설정**에서 찾을 수 있습니다.

1. **페르소나 전환 시 알림 표시**
   - 페르소나 관련 토스트 메시지를 활성화합니다(예: "페르소나 자동 선택", "임시 페르소나").

2. **캐릭터당 여러 페르소나 연결 허용**
   - **활성화**하면 단일 캐릭터에 여러 페르소나를 연결할 수 있습니다. 해당 캐릭터의 채팅을 열면 사용할 페르소나를 묻는 메시지가 표시됩니다. 비활성화하면 한 번에 하나의 페르소나만 캐릭터에 연결할 수 있습니다.

3. **선택한 페르소나를 채팅에 자동 잠금**
   - **활성화**하면 페르소나를 선택하거나(수동 또는 자동 선택) 새 채팅을 만들 때마다 해당 페르소나가 채팅에 잠깁니다.
   이것을 "여러 개 허용"과 결합하면 캐릭터당 페르소나 선택 옵션이 제공되지만 채팅에 대해 선택하면 바인딩된 상태로 유지됩니다.

## 페르소나용 슬래시 커맨드

### `/persona-lock type=<type?>`

- `chat`은 현재 페르소나를 활성 채팅에 잠급니다.
- `character`는 현재 페르소나를 사용 중인 캐릭터에 잠급니다.
- `none`(또는 인수 없음)은 현재 컨텍스트에 대한 페르소나 잠금을 해제/지웁니다.
- 인수 없이 사용하면 현재 잠금 상태를 반환합니다(설정되지 않은 경우 오류).
- 잠금 상태는 `on`, `off` 또는 `toggle`을 통해 선택할 수 있습니다. 기본값은 토글입니다.

### `/persona <name>`

- 페르소나 관리 패널을 열지 않고 이름으로 활성 페르소나를 빠르게 전환합니다.
- 예: `/persona Blaze`.
- `mode=temp`를 사용하면 동일한 이름의 페르소나가 이미 존재하더라도 **현재** 페르소나의 이름을 임시로 설정할 수 있습니다(현재 아바타와 설명 유지).

### `/persona-sync`

- 활성 채팅의 모든 사용자 메시지를 **현재** 페르소나와 그 이름으로 다시 할당합니다.

> **참고:** 이전 `/lock` 및 `/unlock` 명령은 이전 버전과의 호환성을 위해 유지되지만 향후 제거될 수 있습니다. 대신 `/persona-lock`을 사용하세요.

## 프로 팁

1. **채팅 중 페르소나 전환**은 과거 사용자 메시지를 새 페르소나로 다시 할당하지 않습니다. 해당 메시지는 당시 사용하던 페르소나에 할당된 상태로 유지됩니다.
2. **일괄 재할당**: 이전 메시지를 모두 새 페르소나와 일치시켜야 하는 경우 **sync** 버튼을 누르거나 `/persona-sync`를 사용하세요.
3. **페르소나 이미지 교체**는 설명이나 잠금을 잃지 않고 페르소나를 선택하고 **<i class="fa-solid fa-images"></i> 페르소나 이미지 변경** 버튼을 클릭하면 됩니다.
4. **캐릭터 연결 팝업**: 여러 페르소나가 동일한 캐릭터에 연결된 경우 채팅을 열 때마다 페르소나를 선택하라는 팝업이 표시됩니다. 특정 캐릭터에 대해 선택할 수 있는 작은 페르소나 선택 항목을 갖는 편리한 방법입니다.
5. **백업**: 페르소나 관리의 **백업** 버튼을 사용하여 전체 페르소나 목록(이름, 캐릭터 연결, 설명)을 백업하고 나중에 필요한 경우 복원할 수 있습니다.

!!!tip 백업 참고사항

- 이미지와 채팅 연결은 페르소나와 함께 저장되지 않으며 이를 통해 백업되지 않습니다.
- 이러한 백업은 내부 링크를 포함하므로 공유하도록 설계되지 않았습니다.

!!!

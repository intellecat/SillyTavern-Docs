# Mancer

Mancer는 원하는 프롬프트를 실행하고 응답을 검열하지 않는 대형 언어 모델 추론 서비스입니다. 대부분의 모델은 채팅을 시작하기 위해 사전 충전된 잔액이 필요하지만 작성 시점(2024-11-28) 기준으로 무료 모델이 있습니다.

- [모델](https://mancer.tech/models)
- [가격](https://mancer.tech/pricing)

## 시작하는 방법

1. [mancer.tech](https://mancer.tech/)에서 계정을 등록합니다.
2. Dashboard를 클릭하고 API Key를 복사합니다.

    ![Mancer dashboard as of 2/27/2024](/static/mancer-dashboard.png)

3. SillyTavern에서 Text Completion API를 선택한 다음 API Type에서 Mancer를 선택합니다.
4. Mancer API Key를 입력하고 Connect를 클릭합니다.

![API Key](/static/mancer-key.png)

이제 선택한 Mancer 모델과 채팅할 수 있습니다.

## 익명 로깅

채팅이 모델 훈련, Mancer 서비스 개선, 데이터 세트 게시 또는 *그들이 결정할 수 있는 다른 모든 것*에 사용될 가능성이 있어도 괜찮다면 선택 모델에서 25% 토큰 할인을 받기 위해 익명 로깅에 옵트인할 수 있습니다. [Mancer 대시보드](https://mancer.tech/dashboard.html)로 이동하여 `Enable Anon. Logging`을 선택하기만 하면 됩니다.

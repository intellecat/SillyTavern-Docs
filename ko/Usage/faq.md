# FAQ

## SillyTavern이 무엇인지 설명해주세요

ChatGPT와 같은 최신 AI 언어 모델은 매우 강력해져서 일부는 이제 사용자가 만든 캐릭터를 설득력 있게 시뮬레이션하고 채팅하거나 소설을 쓸 수 있습니다. 예를 들어 AI에게 중세 일본의 Jubei라는 바둑 강사인 척하라고 말하면 그에 따라 행동하고 응답합니다. Jubei와 긴 채팅을 하고 술집에 가고 사무라이와 싸우기로 결정할 수 있습니다. 상상할 수 있는 모든 것을 할 수 있으며 AI는 이 콘텐츠에 따라 플레이하고 쓰고/반응하며 상대와 던전 마스터 역할을 합니다. 상상력이 한계입니다. AI에게 Wonder Woman인 척하라고 말할 수 있습니다. 시나리오("Wonder Woman과 나는 은행을 털고 있다"), 글쓰기 스타일("Wonder Woman은 흑인 영어로 말한다") 또는 생각할 수 있는 다른 것을 지정할 수도 있습니다.

SillyTavern은 이러한 용도를 용이하게 하는 앱입니다:

* AI 언어 모델과의 통신을 처리하는 사용자 인터페이스입니다.
* 새 캐릭터 카드(프롬프트)를 만들고 쉽게 전환할 수 있습니다.
* 다른 사람이 만든 캐릭터를 가져올 수 있습니다.
* 캐릭터와의 채팅 기록을 유지하여 언제든지 다시 시작하거나 새 채팅을 시작하거나 이전 채팅을 검토할 수 있습니다.
* 백그라운드에서 AI 프롬프트를 준비하는 데 필요한 작업을 수행합니다. 특히 응답 정확도를 향상시키기 위해 특정 규칙을 따르도록 AI를 준비하는 시스템 프롬프트(AI에 대한 지침)를 보냅니다.

## AI 모델 옵션에 대한 개요를 알려주세요

SillyTavern은 두 가지 유형의 AI와 상호 작용할 수 있습니다:

1. [웹 서비스](/Usage/API_Connections/openai.md) (클라우드 기반, 일반적으로 유료, 독점, 폐쇄)
2. [자체 호스팅](/Usage/API_Connections/self-hosted.md) (로컬, 무료, 오픈 소스)

### 유료 웹 서비스 AI

유료 웹 모델은 블랙박스입니다. 회사에 비용을 지불하여 AI 서비스를 사용합니다. SillyTavern에 계정 정보를 입력하면 대신 AI를 사용하기 위해 제공업체에 연결됩니다.

장점:

* 시작하기가 정말 쉽습니다.
* 최고 품질의 AI 쓰기.

단점:

* 사용하는 데 비용이 듭니다.
* 모든 것이 서버에 로그됩니다. 개인 정보 보호 문제.
* 종종 검열되며 특정 주제에 대해 채팅하는 것을 거부합니다.

### 자체 호스팅 AI

자체 호스팅 모델은 PC에서 실행할 수 있는 무료 모델이지만 강력한 PC와 설정하는 데 더 많은 작업이 필요합니다.

장점:

* 설정하면 인터넷 액세스 없이도 무료로 사용할 수 있습니다.
* 완전한 개인 정보 보호. 작성하는 모든 것이 자신의 PC에 남습니다.
* 다양한 모델이 있습니다. 커뮤니티 기반 기술로서 원하는 특정 작업이나 동작에 맞는 모델을 찾을 수 있습니다.

단점:

* <abbr title="State of the art">SOTA</abbr> 모델만큼 유능하지 않습니다(즉, 대화를 더 나쁘게 쓰고 덜 창의적입니다).
* 로컬 모델을 실행하려면 최소 6GB VRAM이 있는 GPU가 필요합니다.

이를 사용하는 데 관심이 있다면 여기에서 전용 가이드를 참조하세요: [자체 호스팅 모델 사용 방법](/Usage/API_Connections/self-hosted.md).

## 휴대폰이나 태블릿에서 SillyTavern을 사용할 수 있나요?

iPhone과 iPad는 전체 SillyTavern 앱을 실행할 수 없지만 웹 인터페이스일 뿐이므로 홈 Wi-Fi의 다른 컴퓨터에서 실행한 다음 모바일 브라우저에서 액세스할 수 있습니다. 자세한 내용은 [원격 연결](/Administration/remote-connections.md)을 참조하세요.

Android 사용자의 경우 위의 내용 외에도 Termux 앱을 사용하여 PC 없이 전체 SillyTavern을 휴대폰에서 직접 실행할 수 있습니다. [설치(Android)](/Installation/Android.md)를 참조하세요. (참고: Termux 설치는 공식적으로 지원되지 않으며 작동을 보장할 수 없습니다.)

## PNG 캐릭터 카드를 가져오려고 했지만 유효하지 않다는 오류가 발생했습니다. 왜인가요?

두 가지 가능성이 있습니다:

1. 카드에 정의가 포함되어 있지 않고 일반 이미지 파일이었습니다. 일부 프로그램이나 파일 관리자는 저장할 때 카드에서 포함된 정의를 제거합니다. 공유한 사람이 게시한 대로 원시 PNG 파일을 사용하고 있는지 확인하세요.
2. PNG 파일이 실제로 `.png` 파일 이름을 가진 WEBP 파일이었습니다. 가져오기 전에 카드 이름을 `.webp`로 바꾸거나 이미지의 적절한 PNG 버전을 찾아보세요.

## 자체 AI 캐릭터를 어떻게 만들 수 있나요?

1. 캐릭터 관리 버튼을 클릭합니다
2. 새 캐릭터 만들기를 클릭합니다
3. 캐릭터 이름 아래에 Amanda와 같은 이름을 지정합니다
4. 선택적으로 아바타 선택 버튼을 클릭하여 이 캐릭터의 이미지 초상화를 선택합니다
5. 설명 아래에 캐릭터를 설명하고 채팅과 관련이 있다고 생각하는 정보를 포함합니다. 예: ```Amanda는 갭 이어 동안 여행하는 학생입니다. 키는 6피트이고 배구 선수입니다. 운동 체형을 가지고 있습니다. 긴 갈색 머리를 가지고 있습니다. 빅토리아 시대 영국 시대를 좋아하고 해당 시대와 관련된 TV를 보고 소설을 읽습니다.```
예를 들어 Amanda가 친근하기를 원한다면 다음을 추가합니다: ```Amanda는 매우 쾌활하고 외향적입니다.```
6. 첫 번째 메시지 아래에 새 채팅을 시작할 때 캐릭터의 인사말을 작성합니다. 예: ```*Amanda가 손을 흔듭니다* 안녕! 당신도 배낭여행객인가요?```
7. 캐릭터 만들기 버튼을 클릭합니다

이제 채팅할 수 있는 기본 캐릭터가 생겼습니다. 캐릭터 목록에서 Amanda를 선택하면 새 채팅이 시작됩니다.

설명 및/또는 첫 번째 메시지를 사용하여 더 구체적인 시나리오를 만들고/또는 자신을 설명에 포함할 수 있습니다. 예:

```txt
설명:
Amanda는 갭 이어 동안 여행하는 학생입니다. 키는 6피트이고 배구 선수입니다. 운동 체형을 가지고 있습니다. 긴 갈색 머리를 가지고 있습니다. 빅토리아 시대 영국 시대를 좋아하고 해당 시대와 관련된 TV를 보고 소설을 읽습니다. 그녀의 영혼을 무겁게 짓누르는 비밀을 간직하고 있습니다. 털어놓을 적절한 사람을 기다리고 있지만 이는 강력한 비밀 조직과의 고양이와 쥐 게임으로 이어질 수 있습니다. 최근 캘커타에 도착했습니다.

당신은 세계적으로 유명한 인도 배구 슈퍼스타 Rajesh Nahasmapetilon입니다. 캘커타를 산책하고 있습니다. Amanda가 당신을 발견하고 흥분하여 비명을 지릅니다.

첫 번째 메시지:
*Amanda가 당신에게 달려와 환하게 웃습니다.* Rajesh! 믿을 수 없어요! 정말 큰 팬이에요. 침실에 당신 포스터가 있어요.
```

포함하는 모든 관련 정보를 사용할 수 있습니다. 얼마나 잘 사용되는지는 AI 모델의 성능 수준에 따라 다릅니다.

참고: 캐릭터가 생성된 후 이름을 제외한 이 정보를 모두 돌아가서 편집할 수 있습니다.

## API 키는 어디에 저장되나요? 왜 볼 수 없나요?

SillyTavern은 API 키를 사용자 데이터 디렉터리의 `secrets.json` 파일에 저장합니다(`/data/default-user/secrets.json`이 기본 경로).

기본적으로 API 키는 저장하고 페이지를 새로 고친 후 인터페이스에서 볼 수 없습니다.

키를 볼 수 있으려면:

1. `config.yaml` 파일에서 `allowKeysExposure` 값을 `true`로 설정합니다.
2. SillyTavern 서버를 다시 시작합니다.
3. API 연결 패널의 오른쪽 하단에 있는 '숨겨진 API 키 보기' 링크를 클릭합니다.

## 성능 팁

### UI가 왜 이렇게 느리거나 버벅거리나요?

* 사용자 설정 패널에서 흐림 효과 없음(빠른 UI) 모드를 활성화해 보세요.
* UI 테마 설정에서 모션 감소를 활성화하여 장식 애니메이션을 제거합니다.
* 브라우저가 하드웨어 가속을 사용하고 있는지 확인하세요.
* 응답 스트리밍을 사용하는 경우 스트리밍 FPS를 더 낮은 값으로 설정하세요(10-15 FPS 권장).

### 입력 지연이 발생합니다. 무엇을 할 수 있나요?

성능 저하, 특히 입력 지연은 브라우저 확장 프로그램에 가장 일반적으로 기인합니다. 알려진 문제가 있는 확장 프로그램은 다음과 같습니다:

* iCloud Password Manager
* DeepL Translation
* AI 기반 문법 수정 도구
* 다양한 광고 차단 확장 프로그램

성능 문제가 발생하고 원인을 식별할 수 없거나 SillyTavern 자체에 문제가 있다고 의심하는 경우:

1. [성능 프로필 기록](https://developer.chrome.com/docs/devtools/performance/reference)
2. 프로필을 JSON 파일로 내보내기
3. 분석을 위해 개발 팀에 제출

모든 브라우저 확장 프로그램과 타사 SillyTavern 확장 프로그램을 비활성화한 상태에서 먼저 테스트하여 성능 저하의 원인을 격리하는 것이 좋습니다.

### 많은 캐릭터를 가져오면 앱이 느려집니다. 왜인가요?

안타깝게도 SillyTavern은 대규모 캐릭터 라이브러리를 처리하도록 설계되지 않았습니다. 더 많이 가질수록 캐릭터 목록을 로드하는 데 더 오래 걸립니다. 증거 데이터에 따르면 1000개 이상의 캐릭터가 있을 때 성능 저하가 눈에 띄기 시작합니다.

그러나 문제를 완화하기 위해 할 수 있는 몇 가지 방법이 있습니다:

**1. 지연 로드 사용.**

`config.yaml` 파일에서 `performance.lazyLoadCharacters` 값을 true로 설정하여 캐릭터의 지연 로드를 활성화합니다. 다음 서버 재시작 후 캐릭터 목록은 상호 작용하는 캐릭터의 전체 데이터만 로드합니다. 일부 타사 확장 프로그램은 지원하도록 업데이트되지 않은 경우 이 설정이 활성화된 상태에서 올바르게 작동하지 않을 수 있습니다(자세한 내용은 확장 프로그램 개발자에게 문의하세요).

**2. 메모리 캐시 사용.**

여유 RAM이 있는 경우 메모리 캐시 용량을 늘립니다. 이를 통해 서버가 더 많은 캐릭터를 메모리에 보관하여 로드하는 데 걸리는 시간을 줄일 수 있습니다. `config.yaml` 파일에서 `performance.memoryCacheCapacity` 값을 더 높은 숫자로 조정하면 됩니다. 기본값은 `100mb`입니다. 대략적인 경험 법칙: 보유한 캐릭터 3000개당 100mb씩 값을 증가시킵니다.

**제한 사항:**

1. 고급(퍼지) 캐릭터 검색은 지연 로드가 활성화된 상태에서 작동하지 않습니다. 캐릭터 이름만 검색됩니다.
2. 메모리 캐시는 사용 가능한 메모리가 제한되어 있어 Android 기기에서 비활성화됩니다.

## AI가 더 많이 쓰도록 하려면 어떻게 해야 하나요?

때때로 AI는 더 장황하게 하고 싶을 때 단일 문장으로만 응답합니다.
이것은 일반적으로 로컬로 실행되는 모델의 문제입니다.

봇이 가장 최근 응답의 끝에서 중단한 곳에서 계속 쓰도록 하려면 입력 바에 아무것도 입력하지 않고 전송을 클릭하여 빈 사용자 메시지를 보낼 수 있습니다. 이렇게 하면 봇이 스토리를 계속하도록 강제합니다.

이 문제를 해결하기 위한 전략:

* `응답 길이` 설정 값을 늘립니다
* 캐릭터에 대한 좋은 `첫 번째 메시지`를 디자인하여 장황한 방식으로 말하는 것을 보여줍니다. AI 모델은 기대하는 글쓰기 스타일에 대한 지침이 주어지면 많이 향상될 수 있습니다.
* 캐릭터의 설명 상자에 "말을 많이 하는 것을 좋아한다" 또는 "매우 장황한 화자"와 같은 문구를 추가합니다
* `작성자 노트` 또는 `Post-History Instruction Prompt`에 대해 동일한 작업을 수행합니다
* 최후의 수단으로 `Auto-Continue`를 켤 수 있습니다(사용자 설정 패널에서). 그러나 AI가 작은 응답을 연속으로 생성한 다음 모두 하나의 큰 응답으로 결합하기 때문에 응답이 더 느리게 나옵니다. 또한 일부 API 옵션과 호환되지 않을 수 있습니다.

## AI가 더 적게 쓰도록 하려면 어떻게 해야 하나요?

이것은 대부분 ChatGPT 또는 Claude와 같은 모델의 문제입니다. 동일한 전략을 역으로 적용할 수 있습니다.

* `응답 길이` 설정 값을 줄입니다
* 캐릭터에게 설명에 '짧게 말하는' 또는 '말을 많이 하지 않는' 줄을 제공합니다.
* 캐릭터에게 간단한 첫 번째 메시지를 제공하여 채팅의 톤과 기대치를 설정합니다.
* `Auto-Continue`가 꺼져 있는지 확인합니다.

## AI가 내 캐릭터의 행동을 쓰고 플롯을 혼자서 주도하는 것을 멈추게 하려면 어떻게 해야 하나요?

이것은 다음과 같은 문구의 조합으로 `작성자 노트`에서 처리되어야 합니다:

* \{\{char\}\}의 응답은 \{\{user\}\}의 행동에 대해 수동적이고 반응적이어야 합니다.
* 다음 응답은 \{\{char\}\}의 POV에서만 작성되어야 합니다.
* \{\{user\}\}에 대한 행동이나 말을 지시하는 것은 절대 허용되지 않습니다

# 환영 페이지 어시스턴트

SillyTavern은 지정된 "어시스턴트" 캐릭터로 인사할 수 있는 환영 화면 기능을 제공합니다. 이 화면은 활성 채팅 없이 SillyTavern을 시작하거나 마지막 채팅 세션을 닫은 후에 나타납니다.

!!! Note
앱 시작 시 환영 화면이 표시되지 않으면 **<i class="fa-solid fa-user-cog"></i> 사용자 설정** 패널의 "채팅/메시지 처리" 섹션에서 "마지막 채팅 자동 로드" 옵션이 비활성화되어 있는지 확인하세요. 이 옵션이 활성화되어 있으면 SillyTavern은 환영 화면을 표시하는 대신 마지막 채팅을 자동으로 로드합니다.
!!!

## 환영 화면

채팅이 활성화되지 않은 경우 환영 화면에서는 여러 유용한 요소를 제공합니다:

* **SillyTavern 버전:** 애플리케이션의 로고와 현재 버전을 표시합니다.
* **빠른 링크:** 다음에 쉽게 액세스할 수 있습니다:
  * **Docs:** 공식 SillyTavern 문서를 엽니다(여기 있습니다!).
  * **GitHub:** SillyTavern GitHub 저장소(<https://github.com/SillyTavern/SillyTavern>)로 이동합니다.
  * **Discord:** 공식 SillyTavern Discord 서버(<https://discord.gg/sillytavern>)에 대한 링크를 제공합니다.
* **임시 채팅 버튼:** 명시적으로 저장하지 않는 한 채팅 기록에 저장되지 않는 기본 중립 어시스턴트와 새 임시 채팅 세션을 빠르게 시작할 수 있습니다.
* **최근 채팅 섹션:** 빠른 액세스를 위해 최근 대화를 나열합니다. 다음을 수행할 수 있습니다:
  * 이 섹션을 표시하거나 숨깁니다.
  * 3개 이상의 채팅을 사용할 수 있는 경우 목록을 확장합니다(최대 15개의 최근 채팅).

## 임시 채팅

!!! Note
기술적 제한으로 인해 임시 채팅 기능은 사용자 정의 환영 페이지 어시스턴트를 사용하지 않습니다. 항상 추가 프롬프트나 캐릭터 정보 없이 빈 채팅을 시작합니다.
!!!

임시 채팅 버튼을 사용하면 채팅 기록에 저장하지 않고 새 채팅 세션을 빠르게 시작할 수 있습니다. 이는 저장된 채팅을 어지럽히지 않고 테스트나 일상적인 대화에 유용합니다. 이 채팅은 닫거나 다른 채팅으로 전환하는 즉시 삭제됩니다.

* **저장** 버튼을 사용하면 임시 채팅을 JSONL 파일로 내보낼 수 있으며 나중에 가져올 수 있습니다.
* **로드** 버튼을 사용하면 이전에 저장한 임시 채팅 파일을 복원할 수 있습니다.

## 환영 페이지 어시스턴트란 무엇인가요?

환영 페이지 어시스턴트는 환영 화면에 표시되도록 선택한 캐릭터입니다. 이를 통해 개인화된 인사와 처음부터 친숙한 캐릭터와 채팅을 시작할 수 있는 빠른 방법을 제공합니다.

### 어시스턴트 설정 및 해제

캐릭터 중 하나를 환영 페이지 어시스턴트로 선택할 수 있습니다.

**어시스턴트를 설정하려면:**

1. **캐릭터 관리** 패널로 이동합니다(일반적으로 오른쪽 사이드바의 <i class="fa-solid fa-address-card"></i> 아이콘을 통해 찾을 수 있음).
2. 목록에서 어시스턴트로 설정하려는 캐릭터를 찾습니다.
3. "More..."를 클릭하고 드롭다운 메뉴에서 **"환영 페이지 어시스턴트로 설정/해제"**를 선택합니다.
4. 캐릭터 이름 옆에 작은 아이콘(<i class="fa-solid fa-user-graduate"></i>)이 나타나며 이제 활성 환영 페이지 어시스턴트임을 나타냅니다.

**어시스턴트를 해제하려면:**

1. 캐릭터 관리 패널로 이동합니다.
2. 현재 환영 페이지 어시스턴트를 찾습니다(<i class="fa-solid fa-user-graduate"></i> 아이콘이 있음).
3. "More..."를 클릭하고 **"환영 페이지 어시스턴트로 설정/해제"**를 다시 선택합니다.
4. 캐릭터는 더 이상 어시스턴트가 아니며 <i class="fa-solid fa-user-graduate"></i> 아이콘이 사라집니다.
5. SillyTavern은 기본 어시스턴트를 사용하도록 되돌아갑니다(아래 참조).

### 어시스턴트와 상호작용

선택한 어시스턴트와 함께 환영 화면이 표시되면 화면 하단의 채팅 입력 바에 메시지를 입력하고 Enter를 누르거나 전송 버튼을 클릭하기만 하면 됩니다. 환영 페이지 어시스턴트와 새 채팅 세션이 시작됩니다.

어시스턴트와 이전 채팅을 열려면 최근 채팅 섹션을 사용하거나 **<i class="fa-solid fa-bars"></i> 옵션** 메뉴를 통해 액세스할 수 있는 **채팅 파일 관리** 대화 상자에서 채팅을 찾으세요.

## 기본 어시스턴트

SillyTavern은 환영 화면과 처음 상호작용할 때 "Assistant"라는 기본 캐릭터를 자동으로 생성합니다. 이 캐릭터는 특정 캐릭터를 환영 페이지 어시스턴트로 설정하지 않은 경우 대체 옵션으로 사용됩니다.

기본 어시스턴트에는 특정 프롬프트가 첨부되어 있지 않으며 원하는 대로 자유롭게 사용자 정의할 수 있습니다(예: 이름 바꾸기, 사진 추가 또는 성격 설정).

* 환영 페이지 어시스턴트로 명시적으로 캐릭터를 설정하지 않은 경우 이 기본 어시스턴트가 사용됩니다.
* 선택한 어시스턴트를 해제하면 시스템이 이 기본 어시스턴트로 되돌아갑니다.
* 어시스턴트로 설정한 캐릭터가 삭제되면 시스템도 기본 어시스턴트로 되돌아갑니다.

**참고:** 선택한 캐릭터를 해제하는 것과 같은 방식으로 기본 시스템 어시스턴트를 "해제"할 수 없습니다. 기본 어시스턴트를 변경하려면 다른 캐릭터 중 하나를 어시스턴트로 설정해야 합니다.

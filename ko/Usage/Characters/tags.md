# 태그

캐릭터 카드와 그룹에는 0개 이상의 태그를 할당할 수 있습니다. 주제, 품질, 출처 또는 원하는 대로 빠르게 증가하는 컬렉션을 구성하는 데 유용합니다.

## 태그 지정

캐릭터 카드에 태그를 추가하거나 제거하는 방법은 여러 가지가 있습니다:

- 가져오기 중에 내장된 태그를 가져옵니다.
- 캐릭터 관리 패널에서 카드를 엽니다. 거기에서 캐릭터 카드에 태그를 할당할 수 있습니다.
- 대량 태그 지정.

대량 태그 지정을 하려면 "Bulk edit characters" 버튼(연필 아이콘)을 클릭하고, 태그를 지정할 카드를 선택한 다음, 그 중 하나를 마우스 오른쪽 버튼으로 클릭하고 컨텍스트 메뉴에서 "Tag"를 클릭합니다.

!!!info 참고
그룹은 대량 태그 지정할 수 없습니다.
!!!

이 화면에서 다음을 수행할 수 있습니다:

- 콤보 상자를 사용하여 태그를 추가하거나 제거합니다.
- 선택한 카드에서 모든 태그를 제거합니다("All").
- 선택한 모든 카드 간의 태그 교집합을 해당 카드에서 제거합니다("Mutual").
- 캐릭터 카드에 저장된 모든 태그를 로컬로 가져옵니다(생성), 가져온 경우("Import All").
- 일치하는 이름으로 로컬에 존재하는 캐릭터 카드에 저장된 태그를 가져옵니다(생성)("Import Existing").

## 관리

기존의 모든 태그를 보고 관리하려면 캐릭터 관리 패널을 연 다음 "Manage tags" 버튼(톱니바퀴 아이콘)을 클릭합니다.

오른쪽 상단의 버튼을 사용하여 여기의 모든 정보(태그 목록, 카드에 대한 태그 할당, 색상, 폴더 설정 등)를 백업하고 복원할 수 있습니다.

왼쪽의 그립 버튼을 사용하여 캐릭터 관리에서 태그 필터에 나타나는 대로 태그를 재정렬할 수 있습니다.

!!!warning 경고
태그 백업 JSON 파일은 내부 엔티티 이름과 같은 인스턴스별 정보를 포함하므로 다른 사람과 공유하기 위한 것이 아닙니다!
!!!

## 캐릭터 카드를 가져올 때 태그 가져오기

다운로드한 이미지에서 외부 캐릭터 카드를 가져올 때(또는 "Import content from external URL" 버튼에서), 포함된 태그를 선택적으로 가져오라는 메시지가 표시됩니다. 태그는 카드가 작동하는 데 필요하지 않습니다. 태그는 단순히 구성용입니다.

내장된 카드 태그는 캐릭터 편집기의 "Advanced Definitions" 메뉴의 "Creator's Metadata" 섹션에 저장됩니다. 해당 캐릭터를 가져올 다른 사용자에게 일부 태그를 제안하려면 "Tags to Embed" 필드를 쉼표로 구분된 태그 목록으로 채웁니다.

!!!info 참고
이 팝업은 User Settings 옵션 "Import Card Tags"가 "Ask"로 설정된 경우에만 나타납니다.
!!!

열리는 "Import tags for CHARACTER NAME" 팝업에서 기존 태그(일치하는 이름으로 로컬에 이미 있던 태그) 및 새 태그(로컬에 없던 태그) 목록이 표시됩니다.

다음 중 하나를 수행할 수 있습니다:

- 필요에 따라 목록을 편집한 다음 "Import"를 누릅니다 - 남아있는 기존 태그는 가져온 캐릭터 카드에 추가되고, 남아있는 새 태그는 로컬로 생성된 다음 카드에 추가됩니다.
- 또는 단순히 "Import none"을 눌러 캐릭터 카드에 포함된 태그를 무시하고 카드만 가져옵니다.
- 또는 "Import All"을 눌러 캐릭터 카드에서 발견된 모든 태그를 가져오기 위한 바로가기로 사용합니다(참고: 위에서 편집한 것도 포함됨; 편집한 경우 "Import" 버튼을 사용하세요).
- 또는 "Import Existing"을 눌러 일치하는 이름으로 로컬에 존재했던 태그만 가져오기 위한 바로가기로 사용합니다.

## 캐릭터 카드 필터링

태그를 만든 후 캐릭터 관리 패널의 행에 태그가 표시됩니다. 이것들을 클릭하여 태그 필터링 상태를 전환할 수 있습니다. 순서대로:

- 한 번 클릭하면 이 태그로 태그가 지정된 카드가 표시됩니다.
- 다시 클릭하면 이 태그로 태그가 지정되지 않은 카드만 표시됩니다.
- 다시 클릭하면 이 태그에 의한 필터링을 재설정합니다.

동시에 원하는 수의 태그로 필터링할 수 있습니다.

## 폴더로서의 태그

!!!info 참고
이 기능을 사용하려면 먼저 User Settings의 UI Theme 열에서 활성화해야 합니다. 이 토글의 상태는 UI 테마와 함께 저장됩니다.
!!!

"Manage tags" 버튼(톱니바퀴 아이콘)에서 각 태그 항목에는 이러한 태그-폴더 모드(코드에서 "bogus folder"라고 함) 사이를 순환하는 다중 상태 토글 버튼이 있습니다:

- 한 번 클릭하면 이 태그를 "열린 폴더"로 만듭니다. 카드 목록에 가상 항목으로 나타나며, 클릭하면 해당 태그가 있는 카드만 표시됩니다
- 다시 클릭하면 이 태그를 "닫힌 폴더"로 만듭니다. 위와 같지만 이 태그로 태그가 지정된 카드는 기본적으로 나타나지 않습니다 - 폴더를 클릭하여 표시해야 합니다.
- 다시 클릭하면 이 태그에 대한 태그-폴더 상태를 재설정합니다.

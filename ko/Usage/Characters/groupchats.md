# 그룹 채팅

## 응답 순서 전략

그룹 채팅에서 캐릭터가 응답을 위해 선발되는 방법을 결정합니다.

### Manual

메뉴 또는 `/trigger` 명령으로 응답할 캐릭터를 수동으로 선택할 수 있습니다. 선택한 그룹 멤버만 응답합니다. 사용자 메시지는 자동으로 응답을 트리거하지 않습니다. 빈 사용자 입력으로 생성을 트리거하면 음소거되지 않은 무작위 그룹 멤버가 응답하도록 트리거됩니다.

### Natural Order

실제 인간 대화의 흐름을 시뮬레이션하려고 시도합니다. 알고리즘은 다음과 같습니다:

1. 채팅의 마지막 메시지에서 그룹 멤버 이름의 언급이 추출됩니다.

    전체 단어만 언급으로 인식됩니다! 캐릭터 이름이 "Misaka Mikoto"인 경우 "Misaka" 또는 "Mikoto"에만 활성화되지만 "Misa", "Railgun" 등에는 절대 활성화되지 않습니다.

    "Allow Self Responses" 설정이 활성화되지 않는 한 캐릭터는 자신의 메시지에서 자신의 이름 언급에 응답하지 않습니다!

2. 캐릭터는 "Talkativeness" 요인에 의해 활성화됩니다.

    Talkativeness는 언급되지 않은 경우 캐릭터가 얼마나 자주 말하는지를 정의합니다. 캐릭터 편집기의 "Advanced Definitions" 화면에서 이 값을 조정하세요. 슬라이더 값은 **0% / Shy**(캐릭터는 언급되지 않는 한 절대 말하지 않음)에서 **100% / Chatty**(캐릭터는 항상 응답함)까지의 선형 척도입니다. 새 캐릭터의 기본값은 50% 확률입니다.

3. 무작위 캐릭터가 선택됩니다.

    이전 단계에서 활성화된 캐릭터가 없으면 다른 모든 조건을 무시하고 한 화자가 무작위로 선택됩니다.

### List Order

캐릭터는 그룹 멤버 목록에 표시된 순서대로 선발됩니다. 다른 규칙은 적용되지 않습니다.

### Pooled Order

마지막 사용자 메시지 이후 아직 말하지 않은 무작위 캐릭터 한 명을 활성화합니다. 모든 캐릭터가 말한 경우 다음 사용자 메시지까지 무작위로 한 명을 선택합니다.

## 그룹 생성 처리 모드

이 설정은 그룹 채팅 멤버의 캐릭터 정보를 처리하는 방법을 결정합니다. 선택에 관계없이 그룹 채팅 기록은 항상 모든 멤버 간에 공유됩니다.

### Swap character cards

기본 모드입니다. 메시지가 생성될 때마다 활성 화자의 캐릭터 카드 정보만 컨텍스트에 포함됩니다.

### Join character cards

모든 그룹 멤버의 정보가 목록 순서대로 하나의 공동 프롬프트로 결합됩니다. 이것은 llama.cpp 프롬프트 캐싱과 같이 컨텍스트의 큰 청크를 변경하는 것이 바람직하지 않은 경우에 도움이 될 수 있습니다.

이 모드에는 두 가지 하위 모드가 있습니다(하나를 선택해야 함):

* Include muted - 음소거된 캐릭터가 항상 공동 프롬프트에 포함됩니다.
* Exclude muted - 음소거된 캐릭터가 현재 화자가 아닌 경우 포함되지 않습니다.

다음 필드가 결합됩니다:

1. Description
2. Scenario, 채팅에 대해 재정의되지 않은 경우
3. Personality
4. Message examples
5. Character notes / Depth prompts

**중요!** 일반적인 캐릭터 카드가 구성되는 방식으로 인해 이 모드를 사용하면 캐릭터가 자신에 대해 혼란스러워하거나 병합된 성격, 불확실한 특성 등을 포함하는 예상치 못한 동작이 발생할 수 있습니다.

### Join Prefix 및 Suffix

'Join character cards'가 선택되면 캐릭터의 모든 각 필드가 함께 결합됩니다. 이는 결과 프롬프트에서 모든 캐릭터 설명이 하나의 큰 텍스트 덩어리로 결합된다는 것을 의미합니다. 이러한 필드를 분리하려면 접두사 및/또는 접미사를 정의할 수 있습니다.

이러한 옵션은 일반 매크로를 지원하며 \{\{char\}\}를 관련 캐릭터의 이름으로, \<FIELDNAME\>을 부분의 이름(예: description, personality, scenario 등)으로 대체합니다.

## 기타 그룹 채팅 메뉴 옵션

### Mute Character

그룹 채팅 메뉴의 캐릭터 아바타 옆에 있는 취소선이 그어진 말풍선 아이콘은 채팅에서 특정 캐릭터의 응답을 비활성화하거나 활성화할 수 있습니다.

### Force Talk

그룹 채팅 메뉴의 캐릭터 아바타 옆에 있는 말풍선 아이콘은 응답 순서 전략을 우회하여 특정 캐릭터의 응답만 트리거합니다. 그룹 멤버가 음소거된 경우에도 작동합니다.

### Auto-mode

자동 모드가 활성화되면 그룹 채팅은 응답 순서를 따르고 사용자 상호작용 없이 메시지 생성을 트리거합니다. 다음 자동 모드 턴은 마지막으로 선발된 캐릭터가 메시지를 보낸 후 5초 지연 후에 트리거됩니다. 사용자가 메시지 보내기 텍스트 영역에 입력을 시작하면 자동 모드가 비활성화되지만 이미 대기열에 있는 생성은 자동으로 중지되지 않습니다.

### Allow Self Responses

Natural Order가 선택된 경우 각 턴의 최신 메시지를 보낸 캐릭터가 자기 언급으로 인해 트리거된 경우 연속 응답을 허용합니다. List order에는 영향을 미치지 않습니다.

### Group Chat Scenario Override

모든 그룹 멤버는 캐릭터 카드에 지정된 것 대신 입력된 시나리오 텍스트를 사용합니다. 분기된 채팅은 부모로부터 시나리오 재정의를 상속하며 그 후에 개별적으로 변경할 수 있습니다.

### Peek Character Definitions

그룹 채팅 메뉴의 아바타 옆에 있는 캐릭터 카드 아이콘을 클릭하면 일반적인 캐릭터 정의 화면으로 빠르게 이동합니다. 여기에서 변경한 내용은 카드 자체에 저장됩니다.

그룹 채팅으로 돌아가려면 Group Name 제목 링크를 클릭합니다.

### Member Management

기존 캐릭터 중 하나를 그룹 채팅에 추가, 제거, 음소거 또는 재정렬할 수 있습니다. 기본적으로 새 멤버는 그룹 멤버 목록의 맨 위에 추가된 다음 화살표 아이콘을 사용하여 재정렬할 수 있습니다.

### Group Chat pop-out

그룹 채팅 메뉴 팝아웃은 "Current Members" 필드 옆의 아이콘을 클릭하여 활성화할 수 있습니다. 이것은 그룹 채팅 메뉴의 팝아웃을 만듭니다. 사용자 설정에서 MovingUI를 활성화하면 이 메뉴의 크기를 조정하고 인터페이스 내의 모든 위치로 드래그할 수 있으며 일반 그룹 채팅 메뉴처럼 작동합니다.

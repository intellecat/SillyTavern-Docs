# EmulatorJS

이 확장 기능을 사용하면 SillyTavern 채팅에서 바로 레트로 콘솔 게임을 플레이할 수 있습니다.

## 설치

**사전 요구 사항:**

- SillyTavern의 최신 릴리스 버전.
- 인터넷에서 다운로드한 ROM 파일. [어디서든](https://archive.org/details/ni-romsets) 찾을 수 있습니다.

**설치 방법:**

1. SillyTavern의 확장 다운로더를 사용하여 설치하세요.
2. 또는 이 링크를 사용하세요: `https://github.com/SillyTavern/SillyTavern-EmulatorJS`

## 사용법

- "EmulatorJS" 확장 메뉴를 엽니다.
- "Add ROM file"을 클릭하세요. ROM은 브라우저 저장소에 저장되며 서버에 저장되지 않습니다.
- 추가할 게임 파일을 선택하세요. 이름과 코어를 입력하세요(자동 감지되지 않은 경우). 코어에 BIOS 파일이 필요한 경우 해당 파일도 추가하세요.
- 목록에서 "Play" 버튼을 클릭하거나 마법 지팡이 메뉴를 통해 실행하세요.
- 게임을 시작한 후 에뮬레이터 프레임에서 컨트롤 및 기타 설정을 사용자 정의할 수 있습니다.
- 휴식이 필요하면 저장/로드 상태 기능을 사용하세요.

사용 가능한 코어 및 요구 사항 목록을 보려면 EmulatorJS 문서를 확인하세요: [Cores](https://emulatorjs.org/docs4devs/cores).

## 코멘트 모드

멀티모달 모델의 힘으로 AI 봇은 게임 플레이를 보고 캐릭터에 맞는 재치 있는 코멘트를 제공할 수 있습니다.

### 요구 사항

1. [ImageCapture](https://developer.mozilla.org/en-US/docs/Web/API/ImageCapture#browser_compatibility)를 지원하는 브라우저. 데스크톱 Chrome에서 테스트되었습니다. Firefox는 config로 활성화해야 합니다. Safari는 작동하지 않습니다.
2. 이미지 인라인 모드가 있는 Chat Completion API를 권장합니다. 선택한 모델이 멀티모달 프롬프트를 지원하는지 API 문서를 확인하세요.
3. 이미지 인라인이 비활성화된 경우 [Image Captioning](./captioning.md#multimodal-source) 확장 기능이 활성화되어 있는지 확인한 다음 "Multimodal" 캡션 소스를 선택하세요.

### 코멘트 활성화 방법

1. EmulatorJS 확장 설정에서 코멘트 제공 간격을 설정했는지 확인하세요. 이 설정은 현재 게임 플레이 이미지를 사용하여 캐릭터에게 코멘트를 요청하는 빈도를 정의합니다. 값이 0이면 코멘트가 제공되지 않습니다.
2. 캐릭터 채팅을 선택하고 게임을 시작하세요. 최상의 성능을 위해 ROM 파일 이름이 올바르게 지정되어 AI가 더 많은 배경 컨텍스트를 가질 수 있도록 하세요.
3. 평소대로 플레이를 시작하세요. 비전 모델은 주기적으로 "보는" 최신 스크린샷을 기반으로 코멘트를 작성하도록 쿼리됩니다.

### 설정

1. Caption template - 게임 내 스크린샷을 설명하는 데 사용되는 프롬프트. `{{game}}`과 `{{core}}` 추가 매크로가 지원됩니다.
2. Comment template - 생성된 캡션을 기반으로 코멘트를 작성하는 데 사용되는 프롬프트. `{{game}}`, `{{core}}`, `{{caption}}` 추가 매크로가 지원됩니다. 이미지 인라인 모드의 경우 `{{caption}}`은 `see included image`로 대체됩니다.
3. Force captions - 이미지 인라인이 지원되고 활성화된 경우에도 멀티모달 캡션 사용을 강제합니다.

### 코멘트가 표시되지 않는 이유는 무엇인가요?

다음과 같은 경우 코멘트가 일시적으로 일시 중지됩니다(간격 단계 건너뜀):

1. 에뮬레이터가 일시 중지되었습니다(일시 중지 버튼으로, 게임 내가 아님).
2. 브라우저 창이 포커스를 잃었습니다.
3. 사용자 입력 영역이 비어 있지 않습니다. 이는 평화롭게 답장을 입력할 수 있도록 하기 위한 것입니다.
4. 다른 답장 생성이 현재 진행 중입니다.
5. TTS 음성이 크게 읽히고 있습니다. 코멘트는 완료될 때까지 보류되지만(최대 30초) 건너뛰지 않습니다.
6. 캐릭터 카드 또는 그룹이 현재 열려 있습니다. 환영 화면에서 게임을 시작하면 코멘트 모드가 비활성화됩니다.

기타 일반적인 문제:

1. 게임을 시작하기 전에 코멘트 간격을 설정했는지 확인하세요.
2. 멀티모달 API 키를 설정했고 ST 서버 콘솔에 오류가 없는지 확인하세요.

여전히 작동하지 않나요? 브라우저 디버그 콘솔 로그를 보내주세요(F12 키를 누르세요).

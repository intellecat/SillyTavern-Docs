# Live2D

이 가이드는 SillyTavern 경험을 위한 Live2D 확장 설정 및 사용자 정의 과정을 안내합니다. 이 확장 기능을 사용하면 캐릭터에 Live2D 애니메이션 모델을 사용할 수 있어 가상 캐릭터에 동적이고 상호 작용적인 요소를 제공합니다.

## 사전 요구 사항

시작하기 전에 다음 사전 요구 사항을 충족했는지 확인하세요:

1. **Branch 선택**: 최신 기능 및 업데이트에 액세스하려면 최신 버전의 SillyTavern을 사용하고 있는지 확인하세요.

2. **확장 설치**: Extensions 패널(쌓인 블록 아이콘)의 "Download Extensions & Assets" 메뉴에서 "Live2D" 확장 기능을 설치하세요.

3. **모델 폴더 배치**: Live2D 모델 폴더를 `/data/<user-handle>/assets/live2d` 디렉토리에 배치하세요. 적절하게 구성된 `live2d` assets 폴더는 다음과 같을 수 있습니다:

    ![Asset folder example](/static/extensions/live2d-folder.png)

    - Live2D 모델 폴더에는 표정, 모션, 텍스처, 사운드 및 설정 파일과 같은 Live2D 모델에 필요한 모든 구성 요소가 포함되어야 합니다. 특히 `***.model.json` 파일이 확장 기능이 모델을 감지하려면 Live2D 모델 폴더의 루트에 있어야 합니다. 이 예에서 `shizuku` live2d 모델 폴더는 다음과 같을 수 있습니다:

    ![Live2d model folder example](/static/extensions/live2d-model.png)

    - 참고: 모델은 캐릭터별 폴더에도 배치할 수 있습니다. 예: `/data/<user-handle>/characters/Shizuku/live2d/`. 그러나 캐릭터 폴더의 모델은 해당 특정 캐릭터에만 액세스할 수 있습니다.

## 확장 설정

Live2D 확장은 애니메이션 모델의 동작을 사용자 정의하기 위한 다양한 설정을 제공합니다. 주요 설정은 다음과 같습니다:

![UI global settings](/static/extensions/live2d-global.png)

### 전역 설정

1. **Enabled**:
   - 이 체크박스를 활성화하여 확장 기능을 활성화하면 Live2D 모델이 SillyTavern 내에서 상호 작용할 수 있습니다.
   - 일반 스프라이트만 사용하려면 확장 기능을 비활성화할 수 있습니다.
   - 그룹 채팅에서 일반 스프라이트를 이동하고 싶을 때 확장 기능을 비활성화할 수 있으며 Live2D 모델을 사용할 준비가 되면 다시 활성화할 수 있습니다.

2. **Follow Cursor**:
   - 이 체크박스를 활성화하면 모델이 이 기능을 지원하는 경우 Live2D 모델이 커서를 따라갑니다.

3. **Auto-send Interaction**:
   - 이 체크박스를 활성화하면 매핑된 메시지가 있는 영역을 클릭할 때 캐릭터 상호 작용이 자동으로 트리거됩니다(자세한 내용은 적중 영역 섹션 참조).


## 디버그 설정

이러한 설정은 디버깅 목적으로 Live2D 모델의 동작 및 가시성을 제어하는 데 도움이 됩니다.

1. **Reset Model Before Animation**:
   - 이 체크박스를 활성화하면 애니메이션 전에 모델을 다시 로드합니다. 이렇게 하면 애니메이션이 시작되도록 강제하고 필요한 경우 클릭을 스팸할 수 있습니다. 일부 모델은 애니메이션이 호환 가능한 상태에서 시작되도록 하기 위해 이것이 필요할 수 있습니다.

2. **Show Model Frames**:
   - 이 체크박스를 활성화하면 모델 프레임이 표시되어 모델을 끌어다 놓을 위치를 쉽게 식별할 수 있습니다. 또한 사용 가능한 경우 적중 영역도 표시됩니다. 적중 영역 위에 마우스를 올리면 이름이 표시됩니다.

3. **Reload 버튼**
    - 이 버튼을 클릭하여 모든 live2d 모델을 다시 로드하세요. 문제가 발생하면 사용하세요.

## 캐릭터 선택

이러한 설정을 사용하면 캐릭터를 관리하고 Live2D 모델을 할당할 수 있습니다.

1. **Refresh 버튼**:
   - refresh 버튼을 클릭하여 현재 채팅의 캐릭터 목록을 업데이트하세요.

2. **Select Character**:
   - 드롭다운 목록을 사용하여 Live2D 모델을 할당할 캐릭터를 선택하세요.

3. **Remove 버튼**:
   - 이 버튼을 클릭하여 캐릭터에 할당된 모든 모델을 삭제하세요. 삭제를 확인하는 확인 프롬프트가 나타납니다.

## 모델 선택

![UI model list](/static/extensions/live2d-list.png)

1. **Refresh 버튼**:
   - Live2D 모델이 목록에 나타나지 않으면 refresh 버튼을 클릭하세요.

2. **Select Model**:
   - 목록에서 모델을 선택하여 선택한 캐릭터에 할당하세요.
   - 모델은 asset 폴더 또는 현재 캐릭터의 폴더에 있을 수 있습니다.
   - 목록에는 모델 폴더 이름, 원본(asset 또는 character) 및 감지된 모델 설정 파일의 이름이 표시됩니다.
   - 일부 모델 폴더에는 동일한 모델의 다른 버전이 포함될 수 있습니다. 다른 모델 파일을 시도하여 가장 잘 작동하는 것을 확인할 수 있습니다.
   - none을 선택하면 스프라이트가 있는 경우 일반 스프라이트를 사용합니다.
   - 설정은 캐릭터 및 모델별로 저장됩니다.

## 모델 설정

![UI model settings](/static/extensions/live2d-settings.png)

1. **Model Scale**:
   - 슬라이더를 사용하여 모델 크기를 조정하여 더 크거나 작게 만드세요.

2. **Model Center X Offset**:
   - 슬라이더를 사용하여 창 중앙을 기준으로 모델의 가로 위치를 변경하세요.

3. **Model Center Y Offset**:
   - 슬라이더를 사용하여 창 중앙을 기준으로 모델의 세로 위치를 조정하세요.


### 참고
- 설정은 저장되고 다른 채팅으로 이어집니다.
- 마우스로 모델을 끌 수도 있으며 이러한 설정이 업데이트되고 저장됩니다.
- 모델을 화면 밖으로 만든 경우 이러한 UI 설정을 사용하여 모델을 다시 화면에 가져오세요. 또한 "Show frame" 체크박스를 선택하여 모델을 끌 수 있는 위치를 명확하게 확인하세요.

## Model Talk

![UI model talk](/static/extensions/live2d-talk.png)

1. **Param mouth open Y id**
    - 목록에서 모델의 입 Y 값에 해당하는 매개변수의 ID를 선택하세요. 모든 모델에 있는 것은 아니며 모델마다 이름이 다를 수 있습니다. 일반적으로 "PARAM_MOUTH_OPEN_Y" 또는 "ParamMouthOpenY"와 같은 것입니다. 목록에서 요소를 선택할 때 모델을 확인하세요. 말하기 애니메이션을 실행하려고 시도합니다. 입이 움직이면 찾은 것입니다!

2. **Mouth movement speed**
    - 슬라이더를 조정하여 입 애니메이션의 이동 속도를 변경하세요.

3. **Time per character**
    - 각 문자의 시간 지속 시간을 설정하세요. 말하기 애니메이션의 지속 시간은 이 시간에 메시지의 문자 수를 곱한 것입니다.

### 참고
- 이 입 애니메이션은 모든 모델과 모든 애니메이션에서 작동하지 않습니다. 모델에 입이 움직이는 애니메이션이 있더라도 이 확장 기능으로 입 애니메이션을 제어할 수 있다는 의미는 아닙니다. 매개변수 목록에 아무것도 표시되지 않으면 모델이 매개변수에 제대로 액세스하기에는 너무 오래된 버전의 Live2D로 만들어졌을 가능성이 높습니다.

## Model Animations

![UI model animations](/static/extensions/live2d-animations.png)

1. **Starter animation**
    - 캐릭터와 채팅을 시작할 때 재생할 표정과 모션을 목록에서 선택하세요. 완벽한 효과를 달성하기 위해 캐릭터를 숨겨야 하는 경우 모델이 보이지 않는 동안의 지연 시간을 추가할 수도 있습니다.

2. **Default animation**
    - 캐릭터가 메시지를 보낼 때 재생할 표정과 모션을 목록에서 선택하세요. classify expression 확장을 사용할 때 대체 애니메이션을 사용하세요.

### 참고
- 목록에서 애니메이션을 선택하면 애니메이션이 재생됩니다.
- replay 버튼을 사용하여 선택한 애니메이션을 다시 재생하세요.
- 일부 모델에는 모션으로 정의된 표정이 있습니다.
- 목록에 아무것도 표시되지 않으면 모델의 설정 파일에 표정/모션이 정의되어 있지 않을 가능성이 높습니다.

## 적중 영역 매핑

![UI model mapping](/static/extensions/live2d-mapping.png)

1. **Default click animation**
    - 모델을 클릭할 때 재생할 표정과 모션을 목록에서 선택하세요. 사용자 메시지로 전송될 메시지도 설정할 수 있습니다.

2. **Hit areas**
    - 모델에 적중 영역이 있는 경우 나열되며 각각에 애니메이션/메시지를 할당할 수 있습니다.


### 참고
- 일부 모델에는 적중 영역이 없지만 기본 클릭은 모두 감지됩니다.
- 아무것도 매핑되지 않은 적중 영역을 클릭하거나 적중 영역 밖을 클릭하면 기본 클릭이 트리거됩니다.
- 적중 영역에는 모델에 정의된 우선 순위가 있습니다. 예를 들어 "mouth"는 "head" 안에 있습니다. 제대로 작동하지 않으면 모델 파일 때문일 수 있습니다.
- 일부 모델의 경우 다른 애니메이션을 시작하기 전에 애니메이션이 완료되어야 합니다. 새로 고침을 강제하고 애니메이션을 스팸하려면 디버그 체크박스를 사용하세요.

## Classified Expressions Mapping

![UI model classify](/static/extensions/live2d-classify.png)

1. **Requirements**
    - classify expression 확장을 사용해야 합니다. 그렇지 않으면 기본 애니메이션으로 대체됩니다.

2. **Mapping**
    - classify 확장에서 감지된 각 감정에 대해 표정/모션 애니메이션을 할당할 수 있습니다.

### 참고
- 새 메시지가 수신될 때 이전 애니메이션이 완료되지 않은 경우 새 애니메이션이 재생되지 않을 수 있습니다. 이 동작은 Live2D 모델에 따라 다릅니다. 애니메이션이 재생되도록 강제하려면 디버그 체크박스를 사용하세요.

이 가이드를 따라주셔서 감사합니다! 이제 SillyTavern 경험이 애니메이션 및 상호 작용 Live2D 모델로 풍부해졌습니다.

# Objective

### 이게 뭔가요?

Objective 확장 기능을 사용하면 사용자가 AI가 채팅 중에 달성해야 할 목표를 지정할 수 있습니다. 이 목표는 단계별 작업으로 나뉩니다. 작업은 분기될 수 있으며, 하위 작업이 자동 또는 수동으로 생성될 수 있습니다. 이를 통해 복잡한 작업 트리를 만들 수 있습니다. 목록의 각 작업의 완료 상태는 특정 간격으로 확인됩니다.

이는 프롬프트에 정적 지시를 추가하는 것과 다르게, 사용자 개입 없이 AI가 따를 순차적이고 페이스가 조절된 지시를 추가합니다. AI가 자율적으로 목표를 달성하기 위해 노력하는 더 진정한 경험을 제공합니다.

### 사전 요구 사항

시작하기 전에 다음 사전 요구 사항을 충족했는지 확인하세요:

- 최신 버전의 SillyTavern을 사용하고 있는지 확인하세요.
- Extensions 패널(쌓인 블록 아이콘)의 "Download Extensions & Assets" 메뉴에서 "Objective" 확장 기능을 설치하세요.

### 일반적인 사용 사례

상상력이 한계이며, AI에게 원하는 어떤 목표든 줄 수 있고 AI는 그것을 달성하는 방법을 계획할 것입니다. 악마를 처치하거나, 사원을 약탈하거나, 호화로운 파티를 열거나, 심지어 세계를 정복하는 계획을 AI에게 요청할 수 있습니다.

![Objective Settings Panel](/static/extensions/objective-panel.png)

### 설정

- 확장 기능은 Extensions 메뉴의 Objective 아래에 있습니다.

- 상단 텍스트 상자에 목표를 입력한 다음 `Auto-Generate Tasks`를 클릭하세요. 그러면 연결된 API에 요청을 보내고 입력한 목표와 일치하는 작업 목록을 제공하도록 요청합니다.

*참고: Auto-Generate Tasks를 클릭하면 새 작업을 추가하기 전에 현재 선택된 Objective의 기존 작업이 모두 삭제됩니다.*

- AI로부터 응답을 받으면 Objective 입력 상자 아래 공간에 작업 목록이 자동으로 생성됩니다. 작업은 생성 후 편집할 수 있습니다.

- 패널 하단에는 두 개의 상자가 있습니다: `Position in Chat`과 `Task Check Frequency`
  - `Position in Chat` - 프롬프트의 채팅 섹션에서 현재 작업을 삽입할 '깊이'입니다. 숫자가 낮을수록 AI가 작업에 더 많은 주의를 기울입니다. 0으로 설정하면 작업이 AI의 마음에서 가장 중요한 것이 됩니다. 높은 값으로 설정하면 작업이 배경에 배치되어 AI가 당면한 대화에 집중할 수 있지만, 너무 높게 설정하면 AI가 작업을 전혀 '처리'하지 않을 수 있습니다.
  - `Task Check Frequency` - AI가 작업이 완료되었는지 확인하는 빈도입니다. `3`으로 설정하면 AI는 3번째 메시지마다 현재 작업이 완료되었는지 확인합니다.

-  Objectives, 작업 및 설명은 현재 채팅 세션에 실시간으로 저장됩니다. 사용자 정의 프롬프트는 전역적으로 저장됩니다.

### 사용자 정의 프롬프트
LLM으로 전송되는 프롬프트를 사용자 정의하여 작업을 생성하고, 작업 완료를 확인하고, 프롬프트 주입에 사용할 수 있습니다. 프롬프트 편집은 현재 세션에 저장됩니다. 사용자 정의 프롬프트는 지속성을 위해 저장하고 로드할 수 있습니다.

- Edit Prompts를 클릭하여 프롬프트 편집기 창을 엽니다. 원하는 대로 프롬프트를 편집할 수 있습니다.
- 프롬프트를 저장하려면 이름을 입력하고 Save Prompt를 클릭하세요.
- 프롬프트를 로드하려면 드롭다운 목록에서 프롬프트를 선택하세요.
- 저장된 프롬프트를 삭제하려면 드롭다운 목록에서 선택하고 Delete Prompt를 클릭하세요.

**경고: 작업 확인은 별도의 API 요청에서 발생합니다. Task Check Frequency를 1로 설정하면 LLM 서비스에 대한 API 호출이 두 배로 늘어납니다. 유료 서비스를 사용하는 경우 주의하세요.**

### 사용법

기본적으로 Objective 확장 기능은 모든 작업과 각각의 완료 상태를 자동으로 추적합니다.

사용자는 언제든지 수동으로 작업을 생성, 업데이트, 삭제 및 완료할 수도 있습니다.


#### 현재 작업 선택

현재 작업은 항상 목록에서 첫 번째 미완료 작업입니다. 작업에 대한 수동 업데이트는 현재 작업이 무엇이어야 하는지 확인을 트리거합니다. 따라서 완료된 작업 묶음 위에 작업을 추가하면 현재 작업으로 설정됩니다. 완료되면 이전에 완료된 작업은 건너뛰고 다음 미완료 작업이 '현재'로 선택됩니다.

작업 트리에서 부모/자식 작업을 사용할 때 작업은 깊이 우선으로 선택됩니다. 즉, 모든 하위 작업이 먼저 순서대로 선택된 다음 현재 Objective/Task의 작업 목록 아래로 계속됩니다.

#### 작업 분기

Branch Task 버튼을 클릭하여 현재 작업을 Objective로 설정하면 하위 작업을 자동 생성하거나 수동으로 생성할 수 있습니다. 모든 하위 작업을 Objective로 계속 전환하고 원하는 만큼 계속 생성할 수 있습니다.

부모 작업을 완료로 표시하면 확장 기능이 모든 하위 작업을 건너뜁니다. 모든 하위 작업이 완료되면 부모 작업이 완료로 표시됩니다.

#### 수동으로 작업 완료

작업 옆의 `체크박스를 클릭`하여 작업의 완료 상태를 수동으로 전환할 수 있습니다. 그러면 다음 미완료 작업이 선택됩니다.

#### 수동 작업 확인

AI가 작업 완료를 확인하도록 수동으로 트리거하려면 채팅 입력 표시줄 오른쪽의 Extras Extension 버튼(`마법 지팡이`)을 클릭하고 `Manual Task Check`를 선택하세요.

![Manual Task Check](/static/extensions/task-check.png)

#### 수동으로 작업 추가

작업이 없으면 `Add Task` 버튼이 표시되어 첫 번째 작업을 수동으로 생성할 수 있습니다.

다른 작업이 이미 있는 경우 작업 오른쪽의 `+` 버튼을 클릭하여 그 뒤에 새 작업을 삽입하세요.

#### 작업 삭제

빨간색 `x`를 클릭하여 기존 작업을 삭제하세요. 다음 미완료 작업이 자동으로 현재 작업으로 선택됩니다.

하위 작업이 있는 작업을 삭제하면 모든 하위 작업과 그 하위 작업도 삭제됩니다.

#### 작업 숨기기

AI가 완료하려는 작업을 인식하고 싶지 않다면 `Hide Tasks` 상자를 선택하여 작업 목록을 숨기고 AI의 의도를 미스터리로 만드세요. 100% 미스터리를 위해서는 `Auto-Generate Tasks`를 클릭하기 전에 이 작업을 수행하세요!

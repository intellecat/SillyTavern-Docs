# Blip

이 가이드는 SillyTavern 경험을 위한 blip 확장 기능을 설정하고 사용자 지정하는 방법을 안내합니다. 이 확장 기능은 가변 속도로 메시지 텍스트에 애니메이션을 적용하고 애니메이션과 함께 사운드를 재생합니다. 오디오 파일을 사용하거나 사운드를 생성할 수 있습니다.

## 필수 조건

시작하기 전에 다음 필수 조건을 충족했는지 확인하세요:

- 최신 버전의 SillyTavern을 사용하고 있는지 확인하세요.
- 확장 기능 패널(쌓인 블록 아이콘)의 "Download Extensions & Assets" 메뉴에서 "Blip" 확장 기능을 설치하세요.

## Blip 전역 설정

1. **Blip user message**:
   - 사용자 메시지에서 애니메이션을 재생하려면 체크박스를 활성화하세요.
   - 사용자에 대한 blip 애니메이션을 원하면 사용자 프로필 또는 기본 프로필을 설정하세요.

2. **Blip only for certain text**:
   - 따옴표 안의 텍스트만 blip하려면 체크박스를 활성화하세요.
   - 별표 안의 모든 것을 무시하려면 체크박스를 활성화하세요.

3. **Automatic scroll down**:
   - 텍스트 애니메이션을 따라 채팅이 아래로 이동하도록 하려면 체크박스를 활성화하고, 애니메이션 중에 자유롭게 스크롤하려면 비활성화하세요.

4. **Audio volume**
   - 텍스트 애니메이션만 원하면 오디오를 음소거하세요.
   - blip 오디오의 전역 볼륨을 조정할 수 있습니다.

## 캐릭터 애니메이션/음성 프로필

각 캐릭터에 대한 프로필을 저장할 수 있습니다:
   - 사용자와 선택적 기본 프로필 포함(캐릭터에 프로필이 없을 때 사용됨).
   - 목록에 현재 채팅 캐릭터만 표시되는 경우 체크박스를 클릭하여 모든 캐릭터를 표시하세요.

1. **Select the character to assign/update profile**:
   - 캐릭터를 선택하면 프로필이 있으면 로드됩니다.
   - 아직 프로필이 없으면 현재 매개변수가 프로필 설정이 됩니다.
   - 제거 버튼을 사용하여 모든 프로필을 삭제할 수 있습니다.
   - 목록에 캐릭터가 나타나지 않으면 새로고침 버튼을 사용하세요.

2. **Text animation settings**:
   - 텍스트 속도 설정: 각 글자가 인쇄되는 사이의 밀리초 단위 지연.
   - 속도 애니메이션의 임의성을 위해 Min/max 속도 승수를 1.0과 다르게 설정하세요.
   - 특수 문자가 인쇄될 때 일시 중지를 추가하려면 쉼표/구문 지연을 0보다 크게 설정하면 애니메이션에 더 많은 생동감을 추가할 수 있습니다. 이 경우 오디오도 일시 중지됩니다.

3. **Audio parameters**:
   - 필요한 경우 이 음성 프로필에만 영향을 미치는 볼륨 승수를 설정하세요.
   - 오디오 속도 설정: 각 blip 사운드 사이의 지연, 텍스트 속도와 독립적입니다.

4. **Blip origin: Generated sound**:
   - 재생할 blip 사운드를 사용자 지정하려면 min/max 주파수 슬라이더를 사용하세요.
   - min/max가 다르면 매번 이 범위의 임의 사운드가 재생됩니다.

5. **Blip origin: file**:
   - 목록에서 파일을 선택하세요.
   - assets extension 메뉴에서 공식 ST blip 자산을 얻을 수 있습니다.
   - 또는 파일을 직접 `\SillyTavern\data\<user-handle>\assets\blip`에 넣으세요.
   - 필요한 경우 전체 파일이 재생될 때까지 기다리도록 강제하려면 체크박스를 활성화하세요.

이 가이드를 따라 주셔서 감사합니다! SillyTavern 경험이 이제 텍스트 애니메이션과 blip 음성으로 풍부해집니다.

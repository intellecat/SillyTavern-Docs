# MiniMax TTS

ستعلمك هذه الصفحة كيفية استخدام مزود MiniMax TTS بشكل صحيح.

## المتطلبات الأساسية

1. حساب MiniMax مع وصول API
2. مفتاح API صالح ومعرف المجموعة من MiniMax

## الحصول على بيانات اعتماد API

### 1. إنشاء حساب MiniMax

1. قم بزيارة [موقع MiniMax (الدولي)](https://www.minimax.io/)
2. انقر على "Sign Up" أو "Login"
3. أكمل عملية تسجيل الحساب

!!!warning الاختلافات الإقليمية
لدى MiniMax إصدارات صينية ودولية منفصلة. يرجى ملاحظة:
- الإصدار الصيني لا يدعم ميزات استنساخ الصوت
- الإصدار الصيني يدعم فقط مضيف API `api.minimax.chat`
!!!

### 2. الحصول على مفتاح API ومعرف المجموعة

1. قم بتسجيل الدخول إلى [وحدة تحكم MiniMax (الدولية)](https://www.minimax.io/platform/user-center/basic-information)
2. يمكنك العثور على GroupId الخاص بك في صفحة المعلومات الأساسية
3. انتقل إلى Settings → API Keys في الشريط الجانبي الأيسر لإنشاء والحصول على مفتاح API الخاص بك

## التكوين في SillyTavern

### 1. الإعداد الأساسي

1. افتح SillyTavern
2. انتقل إلى "Extensions" → "TTS"
3. حدد "MiniMax" كمزود TTS الخاص بك
4. قم بتكوين الإعدادات التالية:
    - **API Key**: مفتاح API الخاص بك من MiniMax
    - **Group ID**: معرف مجموعة MiniMax الخاص بك
    - **API Host**: اختر الخادم المناسب بناءً على منطقتك:
        - `api.minimax.io` (الخادم الدولي الرسمي)
        - `api.minimaxi.chat` (مضيف خادم دولي آخر)
        - `api.minimax.chat` (خادم الصين البرية)

### 2. اختيار النموذج

النماذج المتاحة تشمل:
- **Speech-02-HD**: تخليق صوت عالي الجودة (موصى به)
- **Speech-02-Turbo**: تخليق صوت سريع
- **Speech-01**: نموذج قديم
- **Speech-01-240228**: نموذج قديم (إصدار محدد)

### 3. معاملات الصوت

اضبط المعاملات التالية لتخصيص إخراج الصوت:
- **Speed**: 0.5 - 2.0 (1.0 = السرعة العادية)
- **Volume**: 0.1 - 2.0 (1.0 = مستوى الصوت العادي)
- **Pitch**: 0.5 - 2.0 (1.0 = طبقة الصوت العادية)
- **Audio Format**: MP3، WAV، FLAC

## الأصوات المخصصة

### 1. الحصول على معرفات الصوت

1. قم بالوصول إلى [صفحة MiniMax TTS (الدولية)](https://www.minimax.io/audio/text-to-speech)
2. انقر على "Voice" على الجانب الأيمن للدخول إلى واجهة اختيار الصوت
3. ابحث عن الصوت الذي تريد استخدامه
4. انقر على زر النسخ بجوار اسم الصوت لنسخ معرف الصوت

### 2. إضافة أصوات مخصصة

1. في إعدادات MiniMax TTS، حدد موقع قسم "Custom Voice Management"
2. املأ المعلومات التالية:
    - **Voice Name**: اختر أي اسم للتعريف
    - **Voice ID**: معرف الصوت الذي تم الحصول عليه من منصة MiniMax
    - **Language**: حدد اللغة المقابلة للصوت
3. انقر على "Add Custom Voice"

## النماذج المخصصة

### 1. إضافة نماذج مخصصة

1. في قسم "Custom Model Management"
2. املأ:
    - **Model ID**: معرف النموذج
    - **Model Name**: اسم العرض للنموذج
3. انقر على "Add Custom Model"

### 2. الحصول على معرفات النموذج

1. تحقق من قائمة النماذج في [وثائق MiniMax](https://www.minimax.io/platform/document/Model?key=684261f14c5738213294faa7) الرسمية
2. أو عرض النماذج المخصصة المتاحة في وحدة التحكم
3. انسخ معرف النموذج المقابل

## استكشاف الأخطاء وإصلاحها

### المشكلات الشائعة

1. **فشل مصادقة API**
    - تحقق من أن مفتاح API يتوافق مع مضيف API الصحيح
    - أكد أن معرف المجموعة صحيح
    - تحقق مما إذا كان حسابك لديه رصيد كافٍ

2. **فشل توليد الصوت**
    - تحقق من أن معرف الصوت المحدد صالح
    - تأكد من أن الصوت متوافق مع النموذج المحدد

3. **انتهاء مهلة الاتصال**
    - حاول التبديل إلى مضيف API مختلف
    - تحقق من اتصال شبكتك
    - تحقق من إعدادات جدار الحماية

4. **مشكلات جودة الصوت**
    - حاول استخدام نموذج مختلف (Speech-02-HD للحصول على أفضل جودة)
    - اضبط معاملات الصوت (السرعة، طبقة الصوت، مستوى الصوت)
    - تحقق من توافق تنسيق الصوت

# XTTS مع استنساخ الصوت

تحياتي! إذن، لقد أذهلتك منشورات Reddit التي تعرض مدى تقدم التكنولوجيا لتحويل النص إلى كلام بواسطة AI؟

هل تشعر بالحماس لإعطاء waifu/husbando الروبوتية الخاصة بك مُعدِّل صوت جديد لامع؟

لا تخف، فهذه التكنولوجيا الرائدة المذهلة متاحة بالفعل في SillyTavern المحلي الخاص بك، فأنت تحتاج فقط إلى...

## المتطلبات المسبقة

1. أحدث إصدار من SillyTavern.
2. تثبيت [Miniconda](https://docs.conda.io/projects/miniconda/en/latest/miniconda-install.html).
3. (Windows) تثبيت [Visual C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).
4. ملفات WAV مع مقاطع صوتية لاستنساخها (~10 ثوانٍ لكل ملف). متطلبات الملف: PCM، Mono، 22050Hz، 16-bit (التحويل عبر Audacity).
5. إنشاء مجلد به مجلدات فرعية "speakers" و "output". ضع ملفات WAV في "speakers".

مثال على بنية المجلد:
```
C:\xtts
  - speakers
    - alice.wav
    - bob.wav
  - output
```

## التثبيت

قام [daswer123](https://github.com/daswer123) بإنشاء خادم API يشغل نموذج XTTSv2 على جهاز الكمبيوتر الخاص بك ويتصل بإضافة TTS في SillyTavern.

إنه مستقل تمامًا عن Extras API وسيستخدم بيئة منفصلة.

**مهم جدًا:** لا تقم بتثبيت المتطلبات التالية في بيئة Extras الخاصة بك أو Python النظام.
سيؤدي ذلك إلى كسر الحزم الأخرى الخاصة بك، والقيام بتخفيضات غير ضرورية، إلخ.

يتم توفير التعليمات التالية باستخدام Miniconda، ولكن يمكنك أيضًا القيام بذلك باستخدام venv (غير مغطى هنا).
افتح موجه أوامر Anaconda واتبع التعليمات سطرًا بسطر.

### تشغيل الخادم

1. انتقل إلى المجلد الذي أنشأته في الخطوة 4 من المتطلبات المسبقة.
    ```
    cd C:\xtts
    ```
2. إنشاء بيئة conda جديدة. من الآن فصاعدًا، سنسميها `xtts`.
    ```
    conda create -n xtts
    ```
3. تنشيط البيئة المنشأة حديثًا.
    ```
    conda activate xtts
    ```
4. تثبيت Python 3.10 في بيئتك. قم بالتأكيد بـ "y" عند المطالبة.
    ```
    conda install python=3.10
    ```
5. تثبيت خادم XTTS مع متطلباته.
    ```
    pip install xtts-api-server pydub
    ```
6. تثبيت PyTorch. يمكن أن يستغرق هذا بعض الوقت. السطر التالي يثبت PyTorch مع دعم تسريع GPU (CUDA).
إذا كنت تريد استخدام استنتاج CPU فقط، احذف الجزء الأخير الذي يبدأ بـ `--index-url`.
    ```
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
    ```
7. بدء خادم XTTS على المضيف والمنفذ الافتراضي: <http://localhost:8020>
    ```
    python -m xtts_api_server
    ```
8. أثناء بدء التشغيل الأول، سيتم تنزيل النموذج (حوالي ~2 GB).
لا تنس قراءة الإشعار القانوني من Coqui AI بعناية شديدة. Lol، أنا أمزح، فقط اضغط "y" مرة أخرى.

### الاتصال بـ SillyTavern

1. افتح لوحة الإضافات، وقم بتوسيع قائمة TTS، واختر "XTTSv2" في قائمة المزودين.
2. اختر لغة تحويل النص إلى كلام في القائمة المنسدلة Language (سأكون حزينًا إذا لم تكن البولندية).
3. تحقق من أن نقطة نهاية المزود تشير إلى <http://localhost:8020> و "Available voices" تظهر قائمة عينات الصوت الخاصة بك.
4. اختر أي شخصية وقم بتعيين تعيين بين عينة الصوت والشخصية.
إذا كانت قائمة الشخصيات فارغة، اضغط على "Reload" عدة مرات.
5. قم بتكوين بقية إعدادات TTS وفقًا لتفضيلاتك.

### أنت مجهز الآن!

انقر على أيقونة البوق في قائمة إجراءات السياق لأي رسالة واستمع إلى الصوت المستنسخ الجميل المنبعث
من مكبرات الصوت الخاصة بك. يستغرق التوليد بعض الوقت وليس في الوقت الفعلي حتى على GPUs RTX المتطورة.

### البث؟

من الممكن استخدام بث HTTP مع أحدث إصدار من خادم XTTS للحصول على أجزاء الصوت المولدة بمجرد توفرها!

#### هذا لا يعمل مع RVC!

سيستمر توليد الصوت (بافتراض أنك تستخدم أحدث إصدار من إضافة RVC) وتحويله، *لكن لن يتم بثه* لأن RVC يتطلب وجود ملف الصوت الكامل قبل بدء التحويل. لا يزال يتم التحقيق في RVC المبثوث...

#### كيفية الحصول على دعم البث؟

1. قم بتحديث SillyTavern إلى أحدث إصدار.
2. قم بتحديث خادم XTTS إلى أحدث إصدار.

    ```bash
    conda activate xtts
    pip install xtts-api-server --upgrade
    ```

3. ابدأ واتصل XTTS بـ ST كالمعتاد.
4. قم بتمكين إعداد إضافة XTTS "Streaming" في SillyTavern.

### صوت متقطع؟

حاول زيادة إعداد "chunk size".

للإشارة: مع حجم جزء 200، يمكن لـ RTX 3090 إنتاج صوت غير منقطع على حساب زيادة طفيفة في زمن انتقال الصوت.

### كيفية إعادة تشغيل خادم TTS؟

فقط قم بالخطوات 1 و 3 و 7 من تعليمات التثبيت.

### Android؟؟

من غير المرجح، لا يمكنه تشغيل التطبيقات التي تتطلب PyTorch دون بعض السحر الأسود الغامض الذي لا نقدم دعمًا له. يمكنك تجربته على مسؤوليتك الخاصة، ولكن لن يتم تقديم أي دعم إذا واجهت أي مشاكل.

أفضل حل لك هو استضافة TTS API على جهاز الكمبيوتر الخاص بك عبر الشبكة المحلية، فقط لا تنس تحديد المضيف والمنفذ للاستماع عليه - راجع [README](https://github.com/daswer123/xtts-api-server/blob/main/README.md).

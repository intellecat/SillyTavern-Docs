# مفاتيح الاختصار

**للحصول على أحدث قائمة من مفاتيح الاختصار التي ستعمل في نسخة SillyTavern الخاصة بك، استخدم أمر slash وهو `/help hotkeys` في أي دردشة.**

**مفاتيح الاختصار معطلة للأجهزة المحمولة.**

## مفاتيح اختصار الدردشة

* Up = تحرير آخر رسالة في الدردشة
* Ctrl+Up = تحرير آخر رسالة للمستخدم في الدردشة
* Left = التمرير لليسار
* Right = التمرير لليمين (ملاحظة: مفاتيح اختصار التمرير معطلة عندما يحتوي شريط الدردشة على شيء مكتوب فيه)
* Enter (مع تحديد شريط الدردشة) = إرسال رسالتك إلى الذكاء الاصطناعي
* Ctrl+Enter = إعادة توليد آخر رد للذكاء الاصطناعي
* Alt+Enter = متابعة آخر رد للذكاء الاصطناعي
* Escape
  * *(أثناء تحرير الرسالة وتفعيل الحفظ التلقائي لتحرير الرسالة)* = إغلاق صندوق التحرير.
  * *(أثناء توليد أو بث رسالة الذكاء الاصطناعي)* = إيقاف التوليد فوراً.

## مفاتيح اختصار Markdown

يجب تفعيلها تحت تبويب "إعدادات المستخدم". تعمل في شريط الدردشة ومناطق النص المميزة بأيقونة "M↓":

* Ctrl+B = \*\*bold\*\*
* Ctrl+I = \*italic\*
* Ctrl+U = \_\_underline\_\_
* Ctrl+K = \`inline code\`
* Ctrl+Shift+~ = \~\~strikethrough\~\~

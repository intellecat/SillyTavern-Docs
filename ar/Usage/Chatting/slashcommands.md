# أوامر Slash

!!!warning
**هذه ليست قائمة شاملة حيث يتم تحديثها نادراً.**

للحصول على أحدث قائمة من الأوامر التي ستعمل في نسختك، استخدم أمر الدردشة `/help slash` في أي دردشة SillyTavern.
!!!

- `/help` – يعرض رسالة المساعدة
- `/api` - يتحول إلى API مختلف
- `/sys` - يرسل رسالة محايدة كراوي نظام
- `/send` - يرسل رسالة كالمستخدم بدون تشغيل التوليد
- `/sendas` – يرسل رسالة كشخصية محددة
- `/comment` - يضيف تعليقاً إلى الدردشة غير مرئي للذكاء الاصطناعي
- `/impersonate` - اطلب من الذكاء الاصطناعي الكتابة نيابة عنك مع مطالبة اختيارية
- `/persona` - تعيين شخصية المستخدم الخاصة بك
- `/imagine` - إنشاء صورة من مطالبة نصية
- `/bg` - تعيين صورة خلفية باسم الملف

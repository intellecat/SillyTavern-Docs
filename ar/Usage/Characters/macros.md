# Macros (علامات الاستبدال)

!!! ملاحظة
قد تكون هذه القائمة غير كاملة أو قديمة. استخدم أمر slash `/help macros` في أي محادثة SillyTavern للحصول على قائمة macros التي تعمل في نسختك.
!!!

يمكن استخدام Macros في وصف الشخصية وملاحظات المؤلف و world info والعديد من الأماكن الأخرى ويتم استبدالها بالقيم المقابلة عند إنشاء استجابة. يمكن استخدامها لإدراج محتوى ديناميكي في الموجه، مثل اسم المستخدم أو وصف الشخصية أو الوقت الحالي. يتم تضمين Macros في أقواس معقوفة مزدوجة، على سبيل المثال `{{user}}` وعادة ما تكون غير حساسة لحالة الأحرف. **يرجى مراعاة أن تداخل macro غير مدعوم حاليًا.**

ملاحظة: قد تضيف بعض الامتدادات أيضًا macros خاصة بالسياق تعمل فقط في مناطق معينة (أي placeholders خاصة لموجهات الامتداد). لن يتم توثيق هذه هنا ما لم يكن macro غير مرتبط بوظيفة محددة.

## Macros العامة

| Macro | الوصف |
|-------|-------------|
| `{{pipe}}` | فقط لمعالجة أوامر slash بشكل دفعي. يتم استبداله بالنتيجة المُرجَعة من الأمر السابق. |
| `{{newline}}` | إدراج سطر جديد. |
| `{{trim}}` | يقص الأسطر الجديدة المحيطة بهذا macro. |
| `{{noop}}` | لا يوجد عملية، مجرد سلسلة فارغة. |
| `{{user}}` أو `<USER>` | اسم المستخدم. |
| `{{charPrompt}}` | تجاوز Main Prompt للشخصية. |
| `{{charJailbreak}}` | تجاوز Post-History Instructions Prompt للشخصية. |
| `{{group}}` أو `{{charIfNotGroup}}` | قائمة مفصولة بفواصل لأسماء أعضاء المجموعة أو اسم الشخصية في المحادثات الفردية. |
| `{{groupNotMuted}}` | نفس `{{group}}` ولكن يستثني الأعضاء المكتومين. |
| `{{notChar}}` | قائمة مفصولة بفواصل لجميع المشاركين في المحادثة باستثناء المتحدث الحالي (`{{char}}`). في المحادثات الجماعية، لا يزال هذا يتضمن الشخصيات المكتومة، وعندما لا يتم إنشاء رسالة، فإنه يسرد كل شخصية في القائمة. |
| `{{char}}` أو `<BOT>` | اسم الشخصية. |
| `{{description}}` | وصف الشخصية. |
| `{{scenario}}` | سيناريو الشخصية أو تجاوز سيناريو المحادثة (إذا تم تعيينه). |
| `{{personality}}` | شخصية الشخصية. |
| `{{persona}}` | وصف شخصية المستخدم. |
| `{{mesExamples}}` | أمثلة حوار الشخصية (منسقة بـ instruct). |
| `{{mesExamplesRaw}}`  | أمثلة حوار الشخصية (غير معدلة وغير مقسمة). |
| `{{charVersion}}` | رقم إصدار الشخصية. |
| `{{charDepthPrompt}}` | موجه الشخصية على العمق. |
| `{{model}}` | اسم نموذج توليد النص لـ API المحدد حاليًا. **قد يكون غير دقيق!** |
| `{{lastMessageId}}` | معرف آخر رسالة محادثة. |
| `{{lastMessage}}` | نص آخر رسالة محادثة. |
| `{{firstIncludedMessageId}}` | معرف أول رسالة مضمنة في السياق. يتطلب تشغيل التوليد مرة واحدة على الأقل في الجلسة الحالية. |
| `{{lastCharMessage}}` | آخر رسالة محادثة أرسلتها الشخصية. |
| `{{lastUserMessage}}` | آخر رسالة محادثة أرسلها المستخدم. |
| `{{currentSwipeId}}` | معرف بناءً على 1 لـ swipe الرسالة الأخيرة المعروض حاليًا. |
| `{{lastSwipeId}}` | عدد swipes في آخر رسالة محادثة. |
| `{{lastGenerationType}}` | نوع طلب التوليد الأخير في قائمة الانتظار. القيم: "normal"، "impersonate"، "regenerate"، "quiet"، "swipe"، "continue". |
| `{{original}}` | يمكن استخدامه في حقول تجاوزات الموجه لتضمين الموجه الافتراضي من إعدادات النظام. يتم تطبيقه على APIs إكمال المحادثة ووضع Instruct فقط. |
| `{{time}}` | وقت النظام الحالي. |
| `{{time_UTC±X}}` | الوقت الحالي في إزاحة UTC المحددة (المنطقة الزمنية)، على سبيل المثال لـ UTC+02:00 استخدم `{{time_UTC+2}}`. |
| `{{timeDiff::(time1)::(time2)}}` | الفرق الزمني بين time1 و time2. يقبل macros الوقت والتاريخ. |
| `{{date}}` | تاريخ النظام الحالي. |
| `{{input}}` | محتويات شريط إدخال المستخدم. |
| `{{weekday}}` | يوم الأسبوع الحالي. |
| `{{isotime}}` | الوقت الحالي بتنسيق ISO (ساعة 24). |
| `{{isodate}}` | التاريخ الحالي بتنسيق ISO (YYYY-MM-DD). |
| `{{datetimeformat ...}}` | التاريخ/الوقت الحالي بالتنسيق المحدد (على سبيل المثال `{{datetimeformat DD.MM.YYYY HH:mm}}`). |
| `{{idle_duration}}` | يدرج سلسلة مؤنسنة للنطاق الزمني منذ إرسال آخر رسالة مستخدم (أمثلة: 4 ساعات، يوم واحد). |
| `{{random:(args)}}` | يرجع عنصرًا عشوائيًا من القائمة (على سبيل المثال `{{random:1,2,3,4}}` سيعيد واحدًا من الأرقام الأربعة عشوائيًا). |
| `{{random::arg1::arg2}}` | بناء جملة بديل لـ random يدعم الفواصل في وسائطه. |
| `{{pick::(args)}}` | بديل لـ random، لكن الوسيطة المحددة مستقرة في التقييمات اللاحقة في المحادثة الحالية إذا ظلت السلسلة المصدرية دون تغيير. |
| `{{roll:(formula)}}` | يولد قيمة عشوائية باستخدام بناء جملة نرد D&D: XdY+Z (على سبيل المثال `{{roll:d6}}` يولد قيمة 1-6). |
| `{{bias "text here"}}` | يحدد تحيزًا سلوكيًا للذكاء الاصطناعي حتى إدخال المستخدم التالي. علامات الاقتباس حول النص مطلوبة. |
| `{{// (note)}}` | يسمح بترك ملاحظة سيتم استبدالها بمحتوى فارغ. غير مرئي للذكاء الاصطناعي. |
| `{{banned "text here"}}` | يضيف ديناميكيًا النص المقتبس إلى تسلسلات الكلمات المحظورة لـ backend Text Generation WebUI. لا يفعل شيئًا لـ backends الأخرى. علامات الاقتباس مطلوبة. |
| `{{reverse:(content)}}` | يعكس محتوى macro. |
| `{{outlet::(name)}}` | يتم استبداله بمحتوى [World Info outlet](/Usage/worldinfo.md#outlet-name) المسمى، سيحتوي على إدخالات منشطة مفصولة بأسطر جديدة. |

## Macros وضع Instruct و Context Template

(ممكّن في إعدادات Advanced Formatting)

| Macro | الوصف |
|-------|-------------|
| `{{exampleSeparator}}` | فاصل حوارات الأمثلة لقالب السياق. |
| `{{chatStart}}` | سطر بداية المحادثة لقالب السياق. |
| `{{instructSystemPrompt}}` | موجه النظام Instruct. |
| `{{instructSystemPromptPrefix}}` | تسلسل بادئة موجه النظام. |
| `{{instructSystemPromptSuffix}}` | تسلسل لاحقة موجه النظام. |
| `{{instructUserPrefix}}` | تسلسل بادئة رسالة المستخدم. |
| `{{instructAssistantPrefix}}` | تسلسل بادئة رسالة المساعد. |
| `{{instructSystemPrefix}}` | تسلسل بادئة رسالة النظام. |
| `{{instructUserSuffix}}` | تسلسل لاحقة رسالة المستخدم. |
| `{{instructAssistantSuffix}}` | تسلسل لاحقة رسالة المساعد. |
| `{{instructSystemSuffix}}` | تسلسل لاحقة رسالة النظام. |
| `{{instructFirstAssistantPrefix}}` | تسلسل إخراج المساعد الأول. |
| `{{instructLastAssistantPrefix}}` | تسلسل إخراج المساعد الأخير. |
| `{{instructFirstUserPrefix}}` | تسلسل إدخال المستخدم الأول Instruct. |
| `{{instructLastUserPrefix}}` | تسلسل إدخال المستخدم الأخير Instruct. |
| `{{instructSystemInstructionPrefix}}` | تسلسل بادئة تعليمات النظام. |
| `{{instructUserFiller}}` | نص رسالة التعبئة للمستخدم. |
| `{{instructStop}}` | تسلسل التوقف Instruct. |
| `{{maxPrompt}}` | الحجم الأقصى للموجه بالـ tokens (طول السياق مخفضًا بطول الاستجابة). |
| `{{systemPrompt}}` | محتوى موجه النظام، بما في ذلك تجاوز موجه الشخصية إذا كان مسموحًا ومتاحًا. |
| `{{defaultSystemPrompt}}` | محتوى موجه النظام (باستثناء تجاوز موجه الشخصية). |

## Macros متغيرات المحادثة

- المتغيرات المحلية = فريدة للمحادثة الحالية
- المتغيرات العامة = تعمل في أي محادثة لأي شخصية

| Macro | الوصف |
|-------|-------------|
| `{{getvar::name}}` | يتم استبداله بقيمة المتغير المحلي "name". |
| `{{setvar::name::value}}` | يتم استبداله بسلسلة فارغة، يعين المتغير المحلي "name" إلى "value". يسمح بالقيم الفارغة. |
| `{{addvar::name::increment}}` | يتم استبداله بسلسلة فارغة، يضيف قيمة رقمية "increment" إلى المتغير المحلي "name". |
| `{{incvar::name}}` | يتم استبداله بنتيجة زيادة قيمة المتغير "name" بمقدار 1. |
| `{{decvar::name}}` | يتم استبداله بنتيجة تخفيض قيمة المتغير "name" بمقدار 1. |
| `{{getglobalvar::name}}` | يتم استبداله بقيمة المتغير العام "name". |
| `{{setglobalvar::name::value}}` | يتم استبداله بسلسلة فارغة، يعين المتغير العام "name" إلى "value". يسمح بالقيم الفارغة. |
| `{{addglobalvar::name::value}}` | يتم استبداله بسلسلة فارغة، يضيف قيمة رقمية "increment" إلى المتغير العام "name". |
| `{{incglobalvar::name}}` | يتم استبداله بنتيجة زيادة قيمة المتغير العام "name" بمقدار 1. |
| `{{decglobalvar::name}}` | يتم استبداله بنتيجة تخفيض قيمة المتغير العام "name" بمقدار 1. |
| `{{var::name}}` | يتم استبداله بقيمة المتغير المحدد النطاق "name" (STscript فقط). |
| `{{var::name::index}}` | يتم استبداله بالقيمة عند فهرس المتغير المحدد النطاق "name" (للمصفوفات/الكائنات في STscript). |

## Macros خاصة بالامتدادات

تمت إضافتها بواسطة الامتدادات وتعمل فقط في ظروف معينة.

| Macro | الوصف |
|-------|-------------|
| `{{summary}}` | يتم استبداله بملخص جلسة المحادثة الحالية (إذا كان متاحًا). |
| `{{authorsNote}}` | يتم استبداله بمحتويات Author's Note. |
| `{{charAuthorsNote}}` | يتم استبداله بمحتويات Author's Note الخاصة بالشخصية. |
| `{{defaultAuthorsNote}}` | يتم استبداله بمحتويات Author's Note الافتراضية. |
| `{{charPrefix}}` | يتم استبداله ببادئة موجه Image Generation إيجابية خاصة بالشخصية (إذا كانت متاحة). |
| `{{charNegativePrefix}}` | يتم استبداله ببادئة موجه Image Generation سلبية خاصة بالشخصية (إذا كانت متاحة). |

# Chat Completions

## تعليمات خاصة بالمصدر

!!!warning **مهم!**
تسمح معظم منصات API لك بعرض مفتاح API المولد مرة واحدة فقط، في وقت إنشائه. إذا فقدته، ستحتاج إلى إنشاء مفتاح جديد. تأكد من الاحتفاظ به آمناً!
!!!

### OpenAI

استخدم منصة مطورين OpenAI للوصول إلى نماذج OpenAI المختلفة، بما في ذلك gpt-4o و gpt-4.1 و o3، إلخ.

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [OpenAI](https://platform.openai.com/) وقم بتسجيل الدخول.
2. استخدم خيار "[View API keys](https://platform.openai.com/account/api-keys)" لإنشاء مفتاح API جديد.

### Claude

Claude هي عائلة من نماذج الذكاء الاصطناعي طورتها Anthropic. يمكنك الوصول إلى نماذج Claude من خلال Anthropic console.

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [Anthropic Console](https://console.anthropic.com/) وقم بتسجيل الدخول.
2. استخدم قسم "[Get API Key](https://console.anthropic.com/settings/keys)" لإنشاء مفتاح API جديد.

### Mistral AI

Mistral AI هو فريق يطور نماذج مفتوحة وخاصة على حد سواء بمعايير علمية عالية وتركيز على الانفتاح. يمكنك تشغيل نماذجهم محلياً أو من خلال خدمة API الخاصة بهم، La Plateforme.

**كيفية الحصول على مفتاح API:**

1. الخطوة الأولى هي إنشاء حساب على [La Plateforme](https://console.mistral.ai/).
2. بمجرد الانتهاء من ذلك، يمكنك اختيار [خطة](https://console.mistral.ai/billing/plans) وإعداد معلومات الدفع الخاصة بك أو اختيار الطبقة المجانية.
3. بعد ذلك، يمكنك إنشاء [مفتاح API](https://console.mistral.ai/api-keys) الخاص بك. قد تحتاج إلى الانتظار بضع دقائق قبل أن يصبح المفتاح صالحاً!

### DeepSeek

توفر منصة DeepSeek الوصول إلى أحدث نماذج DeepSeek من خلال API. يقدمون مجموعة من النماذج، بما في ذلك DeepSeek V3 و DeepSeek R1.

**كيفية الحصول على مفتاح API:**

1. سجل على [منصة DeepSeek](https://platform.deepseek.com/).
2. بعد التسجيل وتعبئة حسابك، يمكنك إنشاء مفتاح API في قسم "[مفاتيح API](https://platform.deepseek.com/api_keys)".

### AI21

يقدم AI21 Labs مجموعة من نماذج الذكاء الاصطناعي، بما في ذلك سلسلة Jamba الرئيسية. يمكنك الوصول إلى نماذجهم من خلال AI21 Studio API.

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [AI21 Studio](https://studio.ai21.com/) وقم بتسجيل الدخول.
2. انتقل إلى قسم "Settings => API Keys" لإنشاء مفتاح API جديد.

### Cohere

يوفر Cohere مجموعة من نماذج الذكاء الاصطناعي لمهام مختلفة، بما في ذلك توليد النصوص والتضمينات. يمكنك الوصول إلى نماذجهم من خلال Cohere API.

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [Cohere](https://cohere.com/) وقم بتسجيل الدخول.
2. انتقل إلى قسم "[مفاتيح API](https://dashboard.cohere.com/api-keys)" في إعدادات حسابك لإنشاء مفتاح API جديد.

### Perplexity

يوفر Perplexity AI الوصول إلى نماذج Sonar الممكّنة عبر الإنترنت من خلال API الخاص بهم للبحث واسترجاع المعلومات في الوقت الفعلي.

دليل البدء الرسمي: [Perplexity Quickstart](https://docs.perplexity.ai/getting-started/quickstart)

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [Perplexity](https://perplexity.ai/) وقم بتسجيل الدخول.
2. انتقل إلى قسم "[فوترة API](https://www.perplexity.ai/account/api/billing)" لشراء رصيد لاستخدام API.
3. انتقل إلى قسم "[مفاتيح API](https://www.perplexity.ai/account/api/keys)" في الإعدادات لإنشاء مفتاح API جديد.

### Fireworks AI

Fireworks AI هي منصة عالية الأداء توفر وصولاً سريعاً وفعالاً من حيث التكلفة إلى نماذج اللغة مفتوحة المصدر المتقدمة. توفر المنصة نشراً بدون خادم مع واجهات APIs متوافقة مع OpenAI وتدعم نوافذ سياق تصل إلى 256,000 رمز.

**كيفية الحصول على مفتاح API:**

1. انتقل إلى [Fireworks AI](https://fireworks.ai/) وأنشئ حساباً أو قم بتسجيل الدخول.
2. انتقل إلى [صفحة مفاتيح API](https://app.fireworks.ai/settings/users/api-keys) في إعدادات حسابك.
3. انقر على "Create API key" وقدم اسماً وصفياً (على سبيل المثال، "SillyTavern").

## Electron Hub

Electron Hub هي منصة موحدة متوافقة مع OpenAI توفر الوصول إلى نماذج من موفرين متعددين من خلال مفتاح API واحد.

**كيفية الحصول على مفتاح API:**

1. أنشئ حساباً على [Electron Hub](https://playground.electronhub.ai/console).
2. قم بإنشاء مفتاح API من صفحة **Console → API Keys**.

## نقطة نهاية مخصصة متوافقة مع OpenAI

!!!warning
من المهم ملاحظة أننا لا نقدم الدعم للمشاكل المحتملة التي قد تواجهها!
لا نضمن التوافق مع كل نقطة نهاية API محتملة!
!!!

!!!
إذا كنت تنوي استخدام هذه الميزة لاستخدام نقطة نهاية محلية، مثل TabbyAPI أو Oobabooga أو Aphrodite، أو أي شيء مثل تلك، فقد ترغب في التحقق من [التوافق المدمج لتلك](/Usage/API_Connections/index.md) بدلاً من ذلك. تم تصميم ميزة نقطة النهاية المخصصة بشكل أساسي للاستخدام مع خدمات وبرامج أخرى تعرض نقطة نهاية Chat Completion API متوافقة مع OpenAI.

معظم واجهات Text Completion APIs تدعم خيارات تخصيص أكبر بكثير مما تسمح به معايير OpenAI. قد تكون خيارات التخصيص الأكبر هذه، مثل أداة أخذ العينات Min-P، جديرة بالاهتمام لمستخدمي SillyTavern للتحقق منها، والتي يمكن أن تحسن بشكل كبير جودة التوليدات.
!!!

يمكنك تكوين نقطة نهاية بديلة لواجهة Chat Completions الخلفية. يمكن لهذه النقطة النهاية المخصصة الاتصال بأي خادم يدعم مخطط OpenAI API العام.

أمثلة على الواجهات الخلفية المتوافقة تشمل:

* [LM Studio](https://lmstudio.ai/)
* [LiteLLM](https://www.litellm.ai/)
* [LocalAI](https://localai.io/)

### الاتصال

للوصول إلى هذه الميزة:

1. قم بالتبديل إلى نوع API 'Chat Completion'
2. حدد 'Custom (OpenAI-compatible)' لـ 'Chat Completion Source'

أدخل عنوان URL لنقطة النهاية المخصصة ومفتاح API إذا لزم الأمر. على سبيل المثال، يتطلب TabbyAPI مفتاح API للمصادقة.

!!!tip
**تلميح:** إذا واجهت مشاكل في الاتصال، حاول إضافة `/v1` إلى نهاية عنوان URL لنقطة النهاية. لا تضف اللاحقة `/chat/completions`.
!!!

### اختيار نموذج

إذا كانت واجهة API المخصصة تنفذ نقطة النهاية `/v1/models` لتوفير قائمة بالنماذج المتاحة، يمكنك الاختيار من قائمة منسدلة. وإلا، استخدم حقل النص لإدخال معرّف النموذج يدوياً.

حدد 'Bypass API status check' لمنع SillyTavern من تنبيهك حول نقطة نهاية API غير عاملة. قم بتمكين هذا الخيار إذا كانت نقطة نهاية API الخاصة بك تعمل بشكل صحيح لكن SillyTavern تستمر في عرض التحذيرات.

انقر على "Test Message" للتحقق من الاتصال عن طريق إرسال مطالبة بسيطة إلى النموذج.

## معالجة ما بعد المطالبة

!!!warning
**ملاحظة:** استدعاء الأدوات غير مدعوم عند استخدام خيار معالجة ما بعد مع "no tools"!
!!!

قد تفرض بعض نقاط النهاية قيوداً محددة على تنسيق المطالبات الواردة، مثل طلب رسالة نظام واحدة فقط أو أدوار متناوبة بشكل صارم.

توفر SillyTavern محولات مطالبة مدمجة للمساعدة في تلبية هذه المتطلبات (من الأقل إلى الأكثر تقييداً):

1. None - لا يتم تطبيق معالجة صريحة ما لم تكن مطلوبة بشكل صارم من قبل API
2. Merge consecutive messages from the same role
3. Semi-strict - دمج الأدوار والسماح برسالة نظام واحدة اختيارية فقط
4. Strict - دمج الأدوار، والسماح برسالة نظام واحدة اختيارية فقط، وطلب رسالة مستخدم لتكون أولاً
5. Single user message - دمج جميع الرسائل من جميع الأدوار في رسالة مستخدم واحدة

Merge و semi-strict و strict بالإضافة إلى ذلك تزيل أي استدعاءات أدوات من المطالبة، ما لم يتم تحديد متغير "with tools". هذا مفيد لواجهات APIs التي لا تدعم استدعاء الأدوات ومطالباتك الموجودة تحتوي على استدعاءات أدوات.

الخيارات الأقل تقييداً ليس لها تأثير على نقاط النهاية الأكثر تقييداً المطبقة في SillyTavern بخلاف "Custom OpenAI-compatible"؛ قد يحدث خطأ في Custom عند طلب غير صالح.

في الوضع الصارم، إذا لم توجد رسالة مستخدم قبل رسالة المساعد الأولى، فسيتم إدراج `promptPlaceholder` من `config.yaml`، والذي يكون افتراضياً "\[Start a new chat]".

# اتصالات API

يمكن لـ SillyTavern الاتصال بمجموعة واسعة من واجهات LLM API.
فيما يلي وصف لنقاط القوة والضعف وحالات الاستخدام الخاصة بكل منها.

## ELI5: Chat Completions مقابل Text Completions

عندما تنتقل لأول مرة إلى صفحة "API Connections" في ST، ستلاحظ خيار قائمة منسدلة للاختيار بين خيارات تستخدم مصطلحات مثل "Chat Completion" و "Text Completion". من المفيد فهم ما يعنيه هذا.

ما ليس كذلك: من السهل التفكير في "Text Completion" على أنها نماذج محلية و "Chat Completion" على أنها LLMs سحابية، لكن هذا ليس صحيحاً. كذلك ليس مثلاً "Novel AI" أو "Kobold" نوعاً منفصلاً من النماذج تماماً، حتى لو كانت خيارات منفصلة في قائمة API المنسدلة في ST. يمكنك إجبار النماذج على هياكل API مختلفة باستخدام الواجهة الخلفية المناسبة، لكن هذا ليس موضوع هذا القسم.

عندما ترسل رسالة باستخدام ST، يتم إنشاء محادثتك ووصف الشخصية والمطالبات الأخرى مثل كتب المعرفة أو ملاحظات المؤلف في "مطالبة" واحدة لإرسالها إلى النموذج. "نوع" API للنموذج الذي تستخدمه يحدد بالضبط كيف سيتم إنشاء هذه المطالبة (شيء تتولى ST القيام به تلقائياً في الخلفية - يمكنك فتح طرفية ST الخاصة بك ورؤية بالضبط كيف تبدو المطالبة التي يتم إرسالها إلى الذكاء الاصطناعي).

### Chat Completions

نموذج Chat Completion، كما يوحي اسمه، سيشكل مطالبتك في سلسلة من الرسائل بين المستخدم (أنت) والمساعد (الذكاء الاصطناعي) أو النظام (محايد). النماذج التي تم تدريبها لـ Chat Completion تساعد في خلق شعور "الدردشة"، مع "استجابة" الذكاء الاصطناعي للرسالة الأخيرة. عندما تستخدم موقع ChatGPT، فأنت تتعامل مع Chat Completions API في الخلفية.

### Text Completions (أو فقط "Completions")

من ناحية أخرى، Text Completion، ومرة أخرى كما يوحي اسمها، ستحول مطالبتك إلى سلسلة واحدة طويلة، وسيحاول النموذج ببساطة متابعة هذا (مثل، تخيل حرفياً كل نصك، مئات الرسائل الخاصة بك، كل التنسيق الخاص بك، الأسطر الجديدة، إلخ. مضغوطة في جملة واحدة طويلة جداً).

إذا كانت رسائلك في ST تُنسق كسلسلة من الرسائل بين YourPersona: و Character:، فسيحاول نموذج Text Completion متابعة هذا النمط وسيعرضه ST كرسالة دردشة جديدة لك، لكن في الواقع النموذج يحاول فقط متابعة النص. إذا قدمت إدخالاً "The Sun rises in the"، فمن المحتمل أن ينهي نموذج إكمال النص تلك الرسالة لك بـ "East".

معظم نماذج Text Completion لديها "قالب تعليمات موصى به" (Instruct Template) (يُذكر عادة في توثيق النموذج أو صفحة التنزيل) يساعدها على "الاستجابة" للرسائل والتعليمات، تماماً مثل نموذج Chat Completion. عادةً ما يكون لدى ST معظم (إن لم يكن كل) قوالب التعليمات متاحة لك للاختيار من بينها في صفحة "Advanced Formatting".

## واجهات APIs المحلية

- يمكن تشغيل واجهات LLM APIs هذه على جهاز الكمبيوتر الخاص بك.
- هي مجانية للاستخدام وليس لديها فلتر محتوى.
- قد تكون عملية التثبيت معقدة (**فريق تطوير SillyTavern لا يقدم الدعم لهذا**).
- يتطلب تنزيلاً منفصلاً لنماذج LLM من [HuggingFace](https://huggingface.co/models?other=LLM) والتي يمكن أن تكون 5-50 جيجابايت لكل منها.
- معظم النماذج ليست قوية مثل واجهات LLM APIs السحابية.

### KoboldCpp

- واجهة API سهلة الاستخدام مع نقل CPU (مفيد لمستخدمي VRAM المنخفض) والبث المباشر
- يعمل من ملف ثنائي واحد على Windows و Mac و Linux
- يدعم نماذج GGUF
- أبطأ من محملات GPU فقط مثل AutoGPTQ و Exllama/v2
- [GitHub](https://github.com/LostRuins/koboldcpp)، [تعليمات الإعداد](/Usage/API_Connections/koboldcpp.md)

### llama.cpp

- المصدر الأصلي الذي تم منه تفريع KoboldCpp و Ollama
- يوفر ملفات ثنائية مجمعة مسبقاً وخيار للتجميع من المصدر
- يدعم نماذج GGUF
- واجهة CLI خفيفة الوزن لـ llama-server
- [GitHub](https://github.com/ggml-org/llama.cpp)

### Ollama

- الأسهل في الإعداد والاستخدام من بين جميع واجهات APIs المستندة إلى llama.cpp
- [كتالوج](https://ollama.com/library) رائع من النماذج متاح للتنزيل بنقرة واحدة
- يدعم نماذج GGUF الملفوفة بتنسيق Ollama الخاص
- [GitHub](https://github.com/ollama/ollama)، [الموقع الإلكتروني](https://ollama.com/)

### Oobabooga TextGeneration WebUI

- واجهة Gradio الكل في واحد مع البث المباشر
- أوسع دعم للنماذج الكمومية (AWQ، Exl2، GGML، GGUF، GPTQ) و FP16
- برامج تثبيت بنقرة واحدة متاحة
- تحديثات منتظمة، والتي يمكن أن تعطل أحياناً التوافق مع SillyTavern
- [GitHub](https://github.com/oobabooga/text-generation-webui#one-click-installers)

**الطريقة الصحيحة لربط SillyTavern بـ OpenAI API الجديد من Ooba:**

1. تأكد من أنك على أحدث تحديث لـ TextGen من Oobabooga (اعتباراً من 14 نوفمبر 2023).
2. قم بتحرير ملف CMD_FLAGS.txt، وأضف علامة `--api` هناك. ثم أعد تشغيل خادم Ooba.
3. قم بتوصيل ST بـ `http://localhost:5000/` (افتراضياً) دون تحديد مربع 'Legacy API'. يمكنك إزالة اللاحقة `/v1` من عنوان URL الذي توفره لك وحدة التحكم في Ooba.

*يمكنك تغيير منفذ استضافة API باستخدام علامة `--api-port 5001`، حيث 5001 هو منفذك المخصص.*

### TabbyAPI

- واجهة API خفيفة الوزن مبنية على [Exllamav2](https://github.com/turboderp/exllamav2) مع البث المباشر
- يدعم نماذج Exl2 و GPTQ و FP16
- [الامتداد الرسمي](https://github.com/theroyallab/ST-tabbyAPI-loader) يسمح بتحميل/إلغاء تحميل النماذج مباشرة من SillyTavern
- غير موصى به للمستخدمين ذوي VRAM المنخفض (بدون نقل CPU)
- [GitHub](https://github.com/theroyallab/tabbyAPI)، [تعليمات الإعداد](/Usage/API_Connections/tabbyapi.md)

### KoboldAI Classic (مهجور، متروك)

- يعمل على جهاز الكمبيوتر الخاص بك، خاص 100٪، مجموعة واسعة من النماذج المتاحة
- يعطي السيطرة الأكثر مباشرة على إعدادات توليد الذكاء الاصطناعي
- يتطلب كميات كبيرة من VRAM في GPU الخاص بك (6-24 جيجابايت، اعتماداً على نموذج LLM)
- النماذج محدودة إلى سياق 2k
- لا يوجد بث مباشر
- إصدارات KoboldAI الشائعة:
  - [Henky's United](https://github.com/henk717/KoboldAI)
  - [0cc4m's 4bit-supporting United](https://github.com/0cc4m/KoboldAI)

## واجهات LLM APIs السحابية

- يتم تشغيل واجهات LLM APIs هذه كخدمات سحابية ولا تتطلب موارد على جهاز الكمبيوتر الخاص بك
- هي أقوى/أذكى من معظم LLMs المحلية
- ومع ذلك، جميعها لديها تصفية محتوى بدرجات متفاوتة، ومعظمها يتطلب الدفع

### AI Horde

- يمكن لـ SillyTavern الوصول إلى هذه الواجهة API مباشرة دون أي إعدادات إضافية مطلوبة
- يستخدم GPU من المتطوعين الأفراد (Horde Workers) لمعالجة الردود على إدخالات الدردشة الخاصة بك
- تحت رحمة العامل من حيث أوقات انتظار التوليد، وإعدادات الذكاء الاصطناعي، والنماذج المتاحة
- [الموقع الإلكتروني](https://aihorde.net/)، [تعليمات الإعداد](./horde.md)

### OpenAI (ChatGPT)

- سهل الإعداد والحصول على مفتاح API
- يتطلب دفعاً مسبقاً للرصيد ويفرض رسوماً لكل مطالبة
- منطقي جداً. يمكن أن يكون الأسلوب الإبداعي متكرراً ويمكن التنبؤ به
- معظم النماذج الأحدث (gpt-4-turbo، gpt-4o) تدعم تعدد الوسائط
- [الموقع الإلكتروني](https://platform.openai.com/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#openai)

### Claude (من Anthropic)

- موصى به للمستخدمين الذين يريدون أن تكون لدردشات الذكاء الاصطناعي الخاصة بهم أسلوب كتابة إبداعي وفريد
- يتطلب دفعاً مسبقاً للرصيد ويفرض رسوماً لكل مطالبة
- النماذج الأحدث (Claude 3) تدعم تعدد الوسائط
- يتطلب أسلوب مطالبة محدداً واستخدام [prefills](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/prefill-claudes-response) لتوجيه الرد
- [الموقع الإلكتروني](https://console.anthropic.com/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#claude)

### Google AI Studio و Vertex AI

- لديه طبقة مجانية مع حدود معدل (Gemini Flash)، قد يتطلب معلومات الفوترة
- [AI Studio](https://aistudio.google.com/) عادة ما يكون لديه أحدث النماذج والميزات
- [Vertex AI](https://console.cloud.google.com/vertex-ai/studio) أصعب في الإعداد، لكنه أكثر استقراراً
- [تعليمات الإعداد](/Usage/API_Connections/google.md)

### Mistral (من Mistral AI)

- نماذج فعالة بأحجام وحالات استخدام مختلفة. يمكنك إنشاء حساب ومفتاح API على [منصتهم](https://console.mistral.ai/api-keys/).
- من 32k إلى 128k أحجام سياق للاستخدام العام، ومن 32k إلى 256k أحجام سياق للبرمجة.
- طبقة مجانية مع حدود معدل.
- إشراف معقول، مع مبادئ Mistral الرئيسية أن تكون محايدة وتمكين المستخدمين، مزيد من المعلومات [هنا](https://mistral.ai/terms/).
- [الموقع الإلكتروني](https://console.mistral.ai/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#mistral-ai)

### OpenRouter

- يوفر واجهة API موحدة للوصول إلى جميع LLMs الرئيسية في السوق
- نظام رصيد الدفع لكل رمز، بالإضافة إلى نماذج مجانية مع طلبات يومية محدودة
- لا يوجد إشراف مفروض، ما لم يكن مطلوباً من قبل موفر LLM
- [الموقع الإلكتروني](https://openrouter.ai)، [تعليمات الإعداد](/Usage/API_Connections/OpenRouter.md)

### DeepSeek

- يوفر الوصول إلى أحدث إصدارات نماذج DeepSeek V3 (`deepseek-chat`) و DeepSeek R1 (`deepseek-reasoner`) الشهيرة جداً
- يتطلب دفعاً للرصيد (2 دولار كحد أدنى)، لكن النماذج رخيصة إلى حد ما مقارنة بجودتها
- لا يوجد إشراف على API، لكن النماذج قد ترفض بعض المطالبات
- [الموقع الإلكتروني](https://platform.deepseek.com/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#deepseek)

### AI21

- يوفر الوصول إلى نماذج Jamba Family المفتوحة
- لديه نسخة تجريبية مجانية (10 دولارات لثلاثة أشهر)، ثم يتطلب الدفع شهرياً لكل رمز
- [الموقع الإلكتروني](https://ai21.com/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#ai21)

### Cohere

- يوفر الوصول إلى أحدث النماذج من Cohere (command-r، command-a، c4ai-aya، إلخ.)
- لديه طبقة مجانية (Trial Keys) مع حدود معدل كافية للاستخدام العادي
- [الموقع الإلكتروني](https://cohere.com/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#cohere)

### Perplexity

- يوفر الوصول إلى نماذج Perplexity Sonar الفريدة الممكّنة عبر الإنترنت عبر API الخاص بهم
- يتطلب تكوين الفوترة وشراء الرصيد
- [الموقع الإلكتروني](https://perplexity.ai/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#perplexity)

### Mancer AI

- خدمة تستضيف نماذج غير مقيدة من عائلات مختلفة
- تستخدم "الرصيد" للدفع مقابل الرموز على نماذج مختلفة
- لا تسجل المطالبات افتراضياً، لكن يمكنك تمكينها للحصول على خصومات رصيد على الرموز.
- تستخدم واجهة API مشابهة لـ `Oobabooga TextGeneration WebUI`، راجع [توثيق Mancer](https://mancer.tech/docs/clients/#sampling-parameters) للتفاصيل.
- [الموقع الإلكتروني](https://mancer.tech/)، [تعليمات الإعداد](/Usage/API_Connections/mancer.md)

### DreamGen

- نماذج غير خاضعة للرقابة مضبوطة للكتابة الإبداعية القابلة للتوجيه
- رصيد شهري مجاني، بالإضافة إلى اشتراك مدفوع
- نماذج تتراوح من 7B إلى 70B
- [تعليمات الإعداد](DreamGen.md)

### Pollinations

- لا يتطلب أي إعداد، يمكن استخدامه مباشرة
- يوفر الوصول إلى مجموعة واسعة من النماذج مجاناً
- قد تتضمن المخرجات أحياناً إعلانات مع روابط لخدمات خارجية

### NovelAI

- لا يوجد فلتر محتوى، النموذج الأحدث مبني على Llama 3
- اشتراك مدفوع مطلوب، الطبقة تحدد الحد الأقصى لطول السياق
- [الموقع الإلكتروني](https://novelai.net/)، [تعليمات الإعداد](/Usage/API_Connections/novelai.md)

### Electron Hub

- يفتح مفتاح API واحد النماذج من موفرين متعددين (OpenAI، Anthropic، DeepSeek، إلخ.) لتوليد النصوص والصور
- 0.25 دولار من الرصيد المجاني كل يوم، خطط مدفوعة متاحة
- [الموقع الإلكتروني](https://www.electronhub.ai/)، [تعليمات الإعداد](/Usage/API_Connections/openai.md#electron-hub)

### AI/ML API

- واجهة API موحدة لأكثر من 300 نموذج بما في ذلك Claude و GPT-4o و Gemini و LLaMA 3 و Mistral وغيرها
- لديه طبقة مجانية مع حدود معدل، وخطط اشتراك، وخيارات الدفع حسب الاستخدام
- [الموقع الإلكتروني](https://aimlapi.com)، [التوثيق](https://docs.aimlapi.com)، [النماذج](https://aimlapi.com/models)

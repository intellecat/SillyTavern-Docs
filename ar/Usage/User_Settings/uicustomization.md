# تخصيص واجهة المستخدم

## سمة واجهة المستخدم

### إدارة السمات

تتيح لك ملفات السمات حفظ ومشاركة وإعادة استخدام تخصيصات واجهة المستخدم الخاصة بك. يمكنك الاحتفاظ بسمات متعددة لأمزجة أو أغراض مختلفة، والتبديل بينها على الفور.

* استيراد/تصدير ملفات السمات
* حذف السمات الموجودة
* حفظ التغييرات على السمة الحالية
* حفظ كسمة جديدة

يتم حفظ جميع الإعدادات في هذا القسم إلى السمة الحالية. إذا قمت بتبديل السمات، سيتم استبدال الإعدادات بإعدادات السمة الجديدة.

### إعدادات العرض

تؤثر خيارات العرض هذه على كيفية عرض الشخصيات والرسائل في واجهة الدردشة.

#### نمط الصورة الشخصية

اختر بين دائرة، مربع، مستطيل، أو مربع مستدير الزوايا. ينطبق هذا الإعداد على كل من صور المستخدم والذكاء الاصطناعي الشخصية.

#### نمط الدردشة

| النمط        | الوصف                                                                                                                                                    | [أمر Slash](/For_Contributors/st-script.md#ui-styling) |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------|
| **مسطح**     | نمط "سجل دردشة" نظيف ومستمر، لوحة مسطحة لتفاعلات الذكاء الاصطناعي الخاصة بك لتنبض بالحياة.                                                                 | `/flat`<br>`/default`                                      |
| **فقاعات**  | نمط "مراسلة فورية" مع فقاعات متميزة لكل رسالة، زوايا مستديرة بهيجة، وتأثير ثلاثي الأبعاد خفيف.                                          | `/bubble`<br>`/bubbles`                                    |
| **وثيقة** | مظهر مضغوط يشبه الوثيقة مع تخطيط يركز على النص. يخفي الصور الشخصية والطوابع الزمنية وأزرار التحكم في الرسائل للرسائل السابقة. | `/single`<br>`/story`                                      |

### الإشعارات

حدد موضعًا حيث ستظهر الإشعارات المنبثقة (رسائل toast) على الشاشة.

* أعلى اليسار
* أعلى الوسط (افتراضي)
* أعلى اليمين
* أسفل اليسار
* أسفل الوسط
* أسفل اليمين

### ألوان السمة

قم بتخصيص نظام الألوان لكل عنصر في واجهة المستخدم لإنشاء سمتك المثالية. يمكن تحديد الألوان باستخدام منتقي الألوان، وتتضمن خيارات الشفافية حيثما كان ذلك قابلاً للتطبيق.

* النص الرئيسي
* النص المائل
* النص المسطر
* نص الاقتباس
* ظل النص
* خلفية الدردشة
* خلفية واجهة المستخدم
* حدود واجهة المستخدم
* رسالة المستخدم
* رسالة الذكاء الاصطناعي

### إعدادات التخطيط والمظهر

ضبط دقيق للعرض المرئي للواجهة باستخدام أشرطة التمرير هذه.

* **عرض الدردشة**: ضبط عرض نافذة الدردشة (25-100% من الشاشة)
* **مقياس الخط**: تخصيص حجم النص (0.5-1.5x)
* **قوة التمويه**: التحكم في تمويه لوحة واجهة المستخدم (0-30)
* **عرض الظل**: ضبط كثافة ظل النص (0-5)

### مفاتيح تبديل السمة

تتحكم هذه المفاتيح في ميزات وسلوكيات واجهة المستخدم المختلفة. يمكن لبعض الخيارات تحسين الأداء على الأجهزة ذات المواصفات المنخفضة، بينما تضيف خيارات أخرى معلومات أو وظائف مفيدة إلى واجهة الدردشة.

* **حركة مخفضة**: تعطيل الرسوم المتحركة والانتقالات
* **بدون تأثير التمويه**: إزالة تمويه الخلفية لأداء أفضل
* **بدون ظلال نص**: تعطيل تأثيرات ظل النص
* **[وضع Visual Novel](Visual-Novel.md)**: دردشة مضغوطة مع صورة خلفية متحركة
* **توسيع إجراءات الرسالة**: عرض قائمة السياق الكاملة للرسالة دائمًا
* **أشرطة تمرير Zen**: عناصر تحكم مبسطة للمعاملات
* **وضع Mad Lab**: نطاقات معاملات غير مقيدة
* **مؤقت الرسالة**: عرض وقت إنشاء استجابة الذكاء الاصطناعي
* **طوابع زمنية للدردشة**: عرض طوابع زمنية للرسائل
* **أيقونات النموذج**: عرض أيقونات نموذج الذكاء الاصطناعي للرسائل
* **معرفات الرسائل**: عرض أرقام الرسائل المتسلسلة
* **إخفاء صور الدردشة الشخصية**: إزالة الصور الشخصية من الدردشة
* **عدد رموز الرسالة**: عرض أعداد الرموز لكل رسالة
* **منطقة إدخال مضغوطة**: إدخال بصف واحد (الهاتف المحمول فقط)
* **رقم السحب لجميع الرسائل**: عرض أرقام السحب على جميع الرسائل
* **التبديل السريع للشخصيات**: أزرار اختيار سريع للشخصيات المفضلة
* **تكبير عند تحويم الصورة الشخصية**: تأثير التكبير عند تحويم الصورة الشخصية
* **العلامات كمجلدات**: تنظيم الشخصيات باستخدام العلامات كمجلدات
* **انقر للتحرير**: انقر على الرسائل لفتح محرر الرسائل بسرعة

### CSS مخصص

يسمح لك بتطبيق أنماط CSS مخصصة لمزيد من التخصيص لمظهر واجهة الدردشة.

استخدم <i class="fa-fw fa-solid fa-maximize" title="Expand icon"></i> **توسيع** لتوسيع نافذة المحرر لرؤية وتحرير أفضل.

إذا قمت بتبديل السمات، سيتم استبدال CSS المخصص الخاص بك بـ CSS المخصص للسمة الجديدة. تأكد من حفظ CSS المخصص الخاص بك إلى سمة إذا كنت تريد الاحتفاظ به عند تبديل السمات.

إذا كنت تستخدم الكثير من CSS المخصص، أو تريد استخدام نفس CSS المخصص مع عدة سمات، فإن [إضافة CSS Snippets](https://github.com/LenAnderson/SillyTavern-CssSnippets) غير الرسمية يمكن أن تساعدك على إدارة وتنظيم CSS المخصص الخاص بك.

## صوت الرسالة

لتشغيل صوتك المخصص عند تلقي رسالة جديدة من البوت، استبدل ملف MP3 التالي في مجلد SillyTavern الخاص بك:

`public/sounds/message.mp3`

يتم التشغيل بحجم 80%.

إذا تم تمكين خيار "[صوت الخلفية فقط](index.md#miscellaneous)"، يتم تشغيل الصوت فقط إذا كانت نافذة SillyTavern **غير مركزة**.

## عرض الصيغ الرياضية

لتمكين عرض الصيغ الرياضية، استخدم [إضافة LaTeX](https://github.com/SillyTavern/Extension-LaTeX). للحصول على الإضافة، تحتاج إلى تثبيتها عبر قائمة "Download Extensions & Assets" في SillyTavern.

اكتب صيغك في كتل الكود مع معرفات لغة `latex` أو `asciimath` لـ LaTeX و AsciiMath على التوالي. تستخدم الإضافة [KaTeX](https://katex.org/) للعرض.

<pre><code>```latex
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
```

```asciimath
int_{-oo}^{oo} e^{-x^2} dx = sqrt{pi}
```</code></pre>

بناء جملة الغلاف القديم `$` و `$$` لم يعد مدعومًا. يرجى استخدام نصوص regex التالية لاستكمال البناء القديم:

* [$$ - LaTeX](https://github.com/SillyTavern/Extension-LaTeX/raw/refs/heads/main/assets/$$_-_latex.json)
* [$ - AsciiMath](https://github.com/SillyTavern/Extension-LaTeX/raw/refs/heads/main/assets/$_-_asciimath.json)

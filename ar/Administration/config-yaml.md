# ملف التكوين

!!!warning إخلاء مسؤولية

قد تكون هذه الوثائق قديمة أو غير كاملة أو غير صحيحة. يرجى الرجوع إلى [config.yaml الافتراضي](https://github.com/SillyTavern/SillyTavern/blob/release/default/config.yaml) في التثبيت الخاص بك للحصول على أحدث قائمة بالإعدادات.

**تحذير: لا تقم بتحرير التكوين الافتراضي مباشرة. لن يكون لهذا أي تأثير إيجابي. قم بتحرير نسخته في جذر المستودع بدلاً من ذلك.**
!!!

`config.yaml` هو ملف التكوين الرئيسي لخادم SillyTavern الذي يمكنك العثور عليه في دليل جذر المستودع بعد [إكمال التثبيت](/Installation/index.md). إنه ملف YAML يحتوي على إعدادات متنوعة، مثل خيارات الشبكة والأمان والخيارات الخاصة بالخلفية. **ستسري التغييرات التي تم إجراؤها على هذا الملف بعد إعادة تشغيل الخادم.**

يتم ملء الإعدادات الجديدة التي تمت إضافتها في المنبع تلقائيًا بالقيم الافتراضية عند تشغيل `npm install` (على وجه التحديد، البرنامج النصي `post-install.js`) بعد [تحديث المستودع](/Installation/Updating/index.md). يمكنك بعد ذلك تعديل هذه الإعدادات حسب الحاجة.

بالنسبة للإعدادات المتداخلة، يتم استخدام تدوين النقطة للإشارة إلى التسلسل الهرمي. على سبيل المثال، `protocol.ipv6: false` يشير إلى إعداد `ipv6` تحت قسم `protocol` بقيمة `false`.

```yaml
protocol:
  ipv6: false
```

## وسائط سطر الأوامر

يمكنك تمرير وسائط سطر الأوامر عند بدء تشغيل خادم SillyTavern لتجاوز بعض الإعدادات في [config.yaml](../Administration/config-yaml.md).

### أمثلة

```shell
node server.js --port 8000 --listen false
# or
npm run start -- --port 8000 --listen false
# or (Windows only)
Start.bat --port 8000 --listen false
```

### الوسائط المدعومة

!!!tip
لا يلزم أي من الوسائط. إذا لم توفرها، فسيستخدم SillyTavern الإعدادات في `config.yaml`.
!!!

| الخيار | الوصف | النوع |
|---------------------------------|----------------------------------------------------------------------|----------|
| `--version` | يعرض رقم الإصدار | boolean |
| `--global` | يفرض استخدام مسارات على مستوى النظام لبيانات التطبيق | boolean |
| `--configPath` | يتجاوز المسار إلى ملف config.yaml (الوضع المستقل فقط) | string |
| `--dataRoot` | يحدد الدليل الجذر لتخزين البيانات (الوضع المستقل فقط) | string |
| `--port` | يحدد المنفذ الذي سيعمل عليه SillyTavern | number |
| `--listen` | يجعل SillyTavern يستمع على جميع واجهات الشبكة | boolean |
| `--whitelist` | يمكّن وضع القائمة البيضاء | boolean |
| `--basicAuthMode` | يمكّن المصادقة الأساسية | boolean |
| `--enableIPv4` | يمكّن بروتوكول IPv4 | boolean |
| `--enableIPv6` | يمكّن بروتوكول IPv6 | boolean |
| `--listenAddressIPv4` | يحدد عنوان IPv4 للاستماع عليه | string |
| `--listenAddressIPv6` | يحدد عنوان IPv6 للاستماع عليه | string |
| `--dnsPreferIPv6` | يفضل IPv6 لـ DNS | boolean |
| `--ssl` | يمكّن SSL | boolean |
| `--certPath` | يحدد المسار إلى ملف الشهادة الخاص بك | string |
| `--keyPath` | يحدد المسار إلى ملف المفتاح الخاص بك | string |
| `--browserLaunchEnabled` | يشغل SillyTavern تلقائيًا في المتصفح | boolean |
| `--browserLaunchHostname` | يحدد اسم المضيف لتشغيل المتصفح | string |
| `--browserLaunchPort` | يتجاوز المنفذ لتشغيل المتصفح | string |
| `--browserLaunchAvoidLocalhost` | يتجنب استخدام 'localhost' لتشغيل المتصفح في الوضع التلقائي | boolean |
| `--corsProxy` | يمكّن وكيل CORS | boolean |
| `--requestProxyEnabled` | يمكّن استخدام وكيل للطلبات الصادرة | boolean |
| `--requestProxyUrl` | يحدد عنوان URL لوكيل الطلب (بروتوكولات HTTP أو SOCKS) | string |
| `--requestProxyBypass` | يحدد قائمة تجاوز وكيل الطلب (قائمة مفصولة بمسافات من المضيفين) | array |
| `--disableCsrf` | يعطل حماية CSRF (غير موصى به) | boolean |

## متغيرات البيئة

يمكن أيضًا تعيين التكوين عبر متغيرات البيئة، والتي ستتجاوز القيم في ملف `config.yaml`.

يجب أن تكون متغيرات البيئة مسبوقة بـ `SILLYTAVERN_` واستخدام أحرف كبيرة لأسماء الإعدادات. على سبيل المثال، يمكن تجاوز إعداد `dataRoot` بمتغير البيئة `SILLYTAVERN_DATAROOT`.

يجب فصل الإعدادات المتداخلة بشرطات سفلية. على سبيل المثال، يمكن تجاوز `protocol.ipv6` بمتغير البيئة `SILLYTAVERN_PROTOCOL_IPV6`.

!!!warning
يجب أن تكون التكوينات التي تتوقع مصفوفات أو كائنات بتنسيق JSON. على سبيل المثال، لتجاوز إعداد `whitelist` بمتغير البيئة `SILLYTAVERN_WHITELIST`، يجب تعيينه كسلسلة JSON: `SILLYTAVERN_WHITELIST='["127.0.0.1", "::1"]'`.
!!!

إذا كنت تستخدم Node.js v20 أو أحدث، يمكنك أيضًا تخزين متغيرات البيئة في ملف `.env` وتمريره إلى الخادم باستخدام علامة `--env-file`. على سبيل المثال، لاستخدام ملف `.env` الموجود في جذر المستودع، يمكنك بدء الخادم بالأمر التالي:

```bash
node --env-file=.env server.js
```

بدلاً من ذلك، قم بتمرير متغيرات البيئة مباشرة عبر سطر الأوامر:

```bash
SILLYTAVERN_LISTEN=true SILLYTAVERN_PORT=8000 node server.js
```

راجع المزيد حول استخدام متغيرات البيئة في [وثائق Node.js](https://nodejs.org/en/learn/command-line/how-to-read-environment-variables-from-nodejs).

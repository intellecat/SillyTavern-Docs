# التطوير والأتمتة

الحزمة الافتراضية لـ SillyTavern توفر فقط منصة أساسية يمكن توسيعها بعدة طرق.

:::callout
**[STscript](st-script)**

STscript هي لغة برمجة نصية قوية تعتمد على أوامر الدردشة المجمعة والتي يمكن التعامل معها دون أي معرفة برمجية مسبقة.
:::

:::callout
**[Function Calling](Function-Calling)**

أضف قدرات ديناميكية أكثر من خلال السماح لنموذج اللغة الكبير باستخدام مصادر بيانات خارجية أو تفعيل وظائف معينة في الإضافة.
:::

:::callout
**[UI Extensions](Writing-Extensions)**

إضافات واجهة المستخدم تعمل في بيئة المتصفح وتوسع وظائف SillyTavern من خلال الربط بأحداثه و API الخاص به.
:::

:::callout
**[Server Plugins](Server-Plugins)**

الإضافات الخاصة بالخادم تسمح بإضافة وظائف مثل نقاط نهاية API جديدة من خلال تشغيل الكود في بيئة NodeJS.
:::

:::callout
**[Internationalization (i18n)](i18n)**

تعلم كيفية ترجمة واجهة مستخدم SillyTavern إلى لغتك.
:::

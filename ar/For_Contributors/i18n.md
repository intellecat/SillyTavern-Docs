# التدويل (i18n)

SillyTavern يدعم لغات متعددة. يشرح هذا الدليل كيفية إضافة وإدارة الترجمات.

ربما أنت هنا لأن بعض النصوص غير مترجمة في لغتك، وهذا يزعجك. أولاً سأريك كيف أصلحت بعض الترجمات المفقودة في اللغة الصينية (التقليدية). كل واحدة كانت مفقودة لسبب مختلف، لذا ستحصل على فكرة جيدة عن كيفية إصلاح ترجماتك المفقودة.

في النصف الثاني، سننظر في

- [كيفية عمل الترجمات](#how-translations-work) في SillyTavern،
- [كتابة الترجمات](#language-files) والكود لاستخدامها،
- وظائف التصحيح [للعثور على الترجمات المفقودة](#finding-missing-translations)،
- إضافة [لغة جديدة](#adding-a-new-language)،
- و [المساهمة بتغييراتك](#contributing).

إذا كنت تطور إضافة أو تعدل الكود الأساسي، اكتب HTML و JavaScript الخاص بك مع وضع i18n في الاعتبار. بهذه الطريقة يكون عملك جاهزاً لترجمته من قبل أشخاص آخرين إلى لغتهم.

لا أحد يعرف 15 لغة بنفسه. نحن نعمل معاً لجعل SillyTavern متاحاً للجميع.

**يجب أن يكون الجميع في العالم قادرين على استخدام لغتهم الخاصة على الهواتف والحواسيب.**

---

## لنقم بإصلاح بعض الترجمات المفقودة!

!!!info
جميع هذه المشكلات الثلاث تطلبت تغييرات في الكود لإصلاحها. إذا كنت تضيف ترجمة جديدة، فقد لا تحتاج إلى لمس الكود على الإطلاق. فقط أضف الترجمة إلى ملف JSON. يحدث أن شخصاً ما أضاف مؤخراً عدداً كبيراً من الترجمات المفقودة إلى ملف JSON الصيني (التقليدي)، لذا كانت المشكلات المتبقية كلها في الكود. في اللغات الأخرى هناك الكثير من الترجمات المفقودة التي يمكنك إصلاحها دون لمس الكود.
!!!

### `Generate Image`

النص "Generate Image" غير مترجم في اللغة الصينية (التقليدية). لماذا؟

![generate-image-pre.png](../static/i18n/generate-image-pre.png)

انقر بزر الماوس الأيمن على العنصر وافحصه. سترى HTML:

```html
<!--rendered HTML-->
<div class="list-group-item flex-container flexGap5 interactable" id="sd_gen" tabindex="0">
    <div data-i18n="[title]Trigger Stable Diffusion" title="觸發 Stable Diffusion"
         class="fa-solid fa-paintbrush extensionsMenuExtensionButton"></div>
    <span>Generate Image</span>
</div>
```

أين خاصية `data-i18n` الخاصة به؟ إنها مفقودة! لنضفها. نجدها في الكود المصدري:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span>Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

لحسن الحظ، تلك السلسلة `Generate Image` موجودة في العديد من ملفات اللغات، بما في ذلك الصينية (التقليدية).

![generate-image-lang.png](../static/i18n/generate-image-lang.png)

```json
{
    "Generate Image": "生成图片"
}
```

لماذا لا تظهر؟ علينا توصيل العنصر بشكل صحيح:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span>Stop Image Generation</span>
</div>
```

الآن إنها تعمل! أعد تحميل الصفحة وشاهد.

![generate-image-post.png](../static/i18n/generate-image-post.png)

ولكن بينما لدينا HTML مفتوحاً، ما الأمر مع `Stop Image Generation` تحتها مباشرة؟ HTML لا يبدو صحيحاً.

إذا أنشأنا صورة ثم فتحنا قائمة العصا أثناء إنشائها، نرى نصاً غير مترجم.

![stop-generating-image-pre.png](../static/i18n/stop-generating-image-pre.png)

أولاً أصلح HTML:

```html
<!--public/scripts/extensions/stable-diffusion/button.html-->
<div id="sd_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-paintbrush extensionsMenuExtensionButton" title="Trigger Stable Diffusion"
         data-i18n="[title]Trigger Stable Diffusion"></div>
    <span data-i18n="Generate Image">Generate Image</span>
</div>
<div id="sd_stop_gen" class="list-group-item flex-container flexGap5">
    <div class="fa-solid fa-circle-stop extensionsMenuExtensionButton" title="Abort current image generation task"
         data-i18n="[title]Abort current image generation task"></div>
    <span data-i18n="Stop Image Generation">Stop Image Generation</span>
</div>
```

هذا ليس كافياً لإصلاح المشكلة. لا توجد ترجمات لـ "Stop Image Generation" في ملف الصيني (التقليدي). يمكننا إضافتها! إليك ترجمة محتملة:

```json
{
    "Stop Image Generation": "停止生成图片"
}
```

... والتي يمكننا إضافتها إلى ملف JSON مباشرة بعد ترجمة "Generate Image".

```json
{
    "Generate Image": "生成图片",
    "Stop Image Generation": "停止生成图片"
}
```

بعد بعض النقاش مع Claude، سنستخدم الترجمات التالية:

- الصينية التقليدية: "Stop Image Generation": "終止圖片生成"
- الصينية المبسطة: "Stop Image Generation": "中止图像生成"
- اليابانية: "Stop Image Generation": "画像生成を停止"

![stop-generating-post-2.png](../static/i18n/stop-generating-post-2.png)

### `Generate Caption`

"Generate Caption" غير مترجمة في اللغة الصينية (التقليدية). لنصلحها!

![generate-image-post.png](../static/i18n/generate-image-post.png)

أين هي؟ افحص العنصر.

```html
<!--rendered HTML-->
<div id="send_picture" class="list-group-item flex-container flexGap5 interactable" tabindex="0">
    <div class="fa-solid fa-image extensionsMenuExtensionButton"></div>
```

اتضح أن هذا HTML يتم إنتاجه بواسطة JavaScript. لنجد الكود المصدري.

```js
// public/scripts/extensions/caption/index.js
const sendButton = $(`
```

سنحتاج أولاً إلى إصلاح الكود:

```js
// public/scripts/extensions/caption/index.js
const sendButton = $(`
```

### `Inspect Prompts`

النص "Inspect Prompts" غير مترجم في اللغة الصينية (التقليدية). لماذا؟
هذا أكثر تعقيداً قليلاً. يتم إنشاء النص بواسطة JavaScript، والترجمة مفقودة.

```js
// Extension-PromptInspector/index.js
const enabledText = 'Stop Inspecting';
const disabledText = 'Inspect Prompts';
```

حسناً ألا تعلم ذلك... لا توجد أي من العبارتين في ملفات i18n. لنضفهما.

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示"
}
```

الآن علينا إصلاح كود JavaScript. يجب أن يستخدم دالة `t` للحصول على الترجمة.

```js
// Extension-PromptInspector/index.js
import {t} from '../../../i18n.js';

const enabledText = t`Stop Inspecting`;
const disabledText = t`Inspect Prompts`;
```

حصلنا على هذه الاقتراحات من Claude. احتفظ بالسلاسل، تجاهل الكود. يجب إضافتها إلى ملفات JSON.

```js
// 1. الصينية المبسطة (zh-cn):
const enabledText = t`停止检查`;
const disabledText = t`检查提示词`;
// 2. الصينية التقليدية (zh-tw):
const enabledText = t`停止檢查`;
const disabledText = t`檢查提示詞`;
// 3. اليابانية (ja-jp):
const enabledText = t`検査を停止`;
const disabledText = t`プロンプトを検査`;
```

سندمجها في ملفات JSON.

```json
{
    "Stop Inspecting": "停止检查",
    "Inspect Prompts": "检查提示词"
}
```

```json
{
    "Stop Inspecting": "停止檢查",
    "Inspect Prompts": "檢查提示詞"
}
```

```json
{
    "Stop Inspecting": "検査を停止",
    "Inspect Prompts": "プロンプトを検査"
}
```

![toggle-prompt-inspection-post-tt.png](../static/i18n/toggle-prompt-inspection-post-tt.png)

من المؤسف بشأن تلميح الأداة. المشكلة أن الكود لا يستخدم دالة `t`.

```js
launchButton.title = 'Toggle prompt inspection';
```

سنحتاج إلى إصلاح ذلك في كود الإضافة.

```js
launchButton.title = t`Toggle prompt inspection`;
```

نحتاج أيضاً إلى إضافة الترجمات إلى ملفات JSON.

```json
{
    "Toggle prompt inspection": "切换提示检查"
}
```

```json
{
    "Toggle prompt inspection": "切换提示词检查"
}
```

```json
{
    "Toggle prompt inspection": "プロンプト検査の切り替え"
}
```

Prompt inspector هي إضافة منفصلة، لذا سنرسل إصلاحات الكود إلى ذلك المستودع: https://github.com/SillyTavern/Extension-PromptInspector/pull/1

سيتم إضافة الترجمات إلى مستودع SillyTavern الرئيسي. https://github.com/SillyTavern/SillyTavern/pull/3198

## ملفات اللغات

لكل لغة ملف JSON في `public/locales/` مسمى برمز لغتها (على سبيل المثال، `ru-ru.json`).

يحتوي الملف على أزواج مفتاح-قيمة حيث:

- المفاتيح هي إما النص الإنجليزي الأصلي أو معرفات فريدة
- القيم هي النص المترجم

مثال:

```json
{
    "Save": "Сохранить",
    "Cancel": "Отмена",
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

## كيفية عمل الترجمات

هناك طريقتان لاستخدام الترجمات في التطبيق:

1. **عناصر HTML**: استخدام خصائص `data-i18n`
   ```html
   <div data-i18n="some_key">Default Text</div>
   ```
   سيتم استبدال النص الافتراضي في HTML بالنص المترجم إذا كان متاحاً.

2. **سلاسل القوالب**: في كود JavaScript باستخدام دالة `t`
   ```javascript
   t`Some text with ${variable}`
   ```
   يجب ترجمة هذه السلاسل مع الحفاظ على عناصر نائبة `${0}`، `${1}`، إلخ كما هي.

SillyTavern يستخدم عناصر HTML مع خصائص `data-i18n` لتمييز المحتوى القابل للترجمة. هناك عدة طرق لاستخدام هذا:

### 1. ترجمة نص العنصر

للمحتوى النصي البسيط:

```html
<span data-i18n="Role:">Role:</span>
```

```json
{
    "Role:": "Роль:"
}
```

هذا يستبدل محتوى نص العنصر بترجمة "Role:".

### 2. ترجمة الخصائص

لترجمة خاصية مثل عنوان أو عنصر نائب:

```html
<a class="menu_button fa-chain fa-solid fa-fw"
   title="Insert prompt"
   data-i18n="[title]Insert prompt"></a>
```

```json
{
    "Insert prompt": "Вставить промпт"
}
```

البادئة `[title]` تشير إلى الخاصية المراد ترجمتها. باقي قيمة الخاصية هو النص الذي سيتم استخدامه كمفتاح بحث في ملف JSON. من الشائع أن يستخدم المبرمجون النص الإنجليزي كمفتاح، ولكنه غير مطلوب. يمكن أن يكون المفتاح أي معرف فريد.

يجب أن يكون النص الإنجليزي الأصلي موجوداً في الخاصية المقابلة (`title="Insert prompt"`). يُستخدم كبديل احتياطي إذا كانت الترجمة مفقودة. الأهم من ذلك، لا يوجد ملف ترجمة للإنجليزية.

هذا مثال على استخدام معرف فريد `no_items_text` كمفتاح، بدلاً من النص الإنجليزي:

```html
<!--suppress HtmlUnknownAttribute -->
<div class="openai_logit_bias_list" no_items_text="No items"
     data-i18n="[no_items_text]openai_logit_bias_no_items"></div>
```

```json
{
    "openai_logit_bias_no_items": "没有相关产品"
}
```

### 3. ترجمات متعددة لكل عنصر

بعض العناصر تحتاج إلى ترجمات للمحتوى والخصائص، مفصولة بفاصلة منقوطة. النمط الأكثر شيوعاً هو ترجمة كل من محتوى نص العنصر وخاصية العنوان الخاصة به:

```html
<div data-source="openrouter" class="menu_button menu_button_icon openrouter_authorize"
     title="Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai"
     data-i18n="Authorize;[title]Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai">
    Authorize
</div>
```

```json
{
    "Authorize": "Авторизоваться",
    "Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai": "Получите свой OpenRouter API токен используя OAuth. У вас будет открыта вкладка openrouter.ai"
}
```

هذا يترجم:

- محتوى نص العنصر باستخدام المفتاح "Authorize"
- خاصية العنوان باستخدام المفتاح "Get your OpenRouter API token using OAuth flow. You will be redirected to openrouter.ai"

لاحظ أن كلاً من خاصية `title` ومحتوى نص العنصر مقدمة بالإنجليزية كبدائل احتياطية.

يمكنك أيضاً ترجمة خصائص متعددة:

```html
<!--suppress HtmlUnknownAttribute -->
<textarea id="send_textarea" name="text" class="mdHotkeys"
          data-i18n="[no_connection_text]Not connected to API!;[connected_text]Type a message, or /? for help"
          placeholder="Not connected to API!"
          no_connection_text="Not connected to API!"
          connected_text="Type a message, or /? for help"></textarea>
```

الترجمات المقابلة في ملف لغتك ستبدو كالتالي:

```json
{
    "Not connected to API!": "Нет соединения с API!",
    "Type a message, or /? for help": "Введите сообщение или /? для помощи"
}
```

عند تحميل الصفحة، يقوم النظام بـ:

1. العثور على جميع العناصر التي لها خصائص `data-i18n`
2. تحليل أي بادئات خصائص مثل `[title]` أو `[placeholder]`
3. البحث عن كل مفتاح في ملف JSON الخاص بلغتك
4. استبدال محتوى العنصر أو خصائصه بالنص المترجم

### النص الديناميكي

للنص الديناميكي في كود JavaScript، تستخدم الترجمات إما:

1. قوالب حرفية مع دالة `t`:
    ```javascript
    toastr.warn(t`Tag ${tagName} not found.`);
    ```
2. دالة ترجمة مباشرة:
    ```javascript
    translate("Some text", "optional_key")
    ```

### عناصر نائبة للمتغيرات

بعض السلاسل تحتوي على عناصر نائبة للقيم الديناميكية باستخدام `${0}`، `${1}`، إلخ:

```js
toastr.error(t`Could not find proxy with name '${presetName}'`);
```

```json
{
    "Could not find proxy with name '${0}'": "Не удалось найти прокси с названием '${0}'"
}
```

احتفظ بالعناصر النائبة نفسها للمفتاح والترجمة. سيستبدل النظام `${0}` بقيمة `presetName`، إلخ.

## العثور على الترجمات المفقودة

لنفترض أنك لا تريد فقط إصلاح ترجمة مفقودة واحدة مزعجة، بل تريد العثور عليها جميعاً.

هذا طموح كبير! حتى إصلاح ترجمة واحدة يستحق العناء. ولكن إذا كنت تريد اصطيادها جميعاً، فأنت بحاجة إلى أداة.

### SillyTavern-i18n

https://github.com/SillyTavern/SillyTavern-i18n

أدوات للعمل مع ملفات الترجمة للواجهة الأمامية.

المميزات:

- إضافة مفاتيح جديدة تلقائياً للترجمة من ملفات HTML.
- تنظيف المفاتيح المفقودة من ملفات الترجمة.
- استخدام الترجمة التلقائية من Google لملء القيم المفقودة تلقائياً.
- فرز ملفات JSON حسب المفاتيح.

### وظائف التصحيح المدمجة

هذه موجودة تحت <i class="fa-fw fa-solid fa-user-cog"></i> **User Settings** > **Debug Menu**.

#### الحصول على الترجمات المفقودة

يكتشف بيانات الترجمة المفقودة في اللغة الحالية ويفرغ البيانات في وحدة التحكم بالمتصفح. إذا كانت اللغة الحالية هي الإنجليزية، يبحث في جميع اللغات الأخرى.

ستعرض وحدة التحكم جدولاً بالترجمات المفقودة مع:

- key: النص أو المعرف الذي يحتاج إلى ترجمة
- language: رمز لغتك الحالية
- value: النص الإنجليزي المراد ترجمته

#### تطبيق اللغة

يعيد تطبيق اللغة المحددة حالياً على الصفحة

!!!warning لا توجد أداة من هذه الأدوات مثالية

- لا تكتشف الترجمات المفقودة في كود JavaScript
- لا تكتشف خصائص data-i18n المفقودة في HTML، بل تكتشف فقط المفاتيح غير المترجمة
- هناك أخطاء في كود `getMissingTranslations`: لا ينبغي أن تكون المفاتيح مسبوقة بـ `[title]` أو `[placeholder]`
  !!!

## إضافة لغة جديدة

لإضافة دعم للغة جديدة:

1. أضف لغتك إلى `public/locales/lang.json`:

   ```json
   {
     "lang": "xx-xx",
     "display": "Language Name (English Name)"
   }
   ```

2. أنشئ `public/locales/xx-xx.json` مع ترجماتك

## المساهمة

عندما تصبح ترجماتك جاهزة:

1. تحقق من صحة ملف JSON الخاص بك
2. اختبر بشكل شامل في التطبيق
3. أرسلها عبر طلب سحب GitHub

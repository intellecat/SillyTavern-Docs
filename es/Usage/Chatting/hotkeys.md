# Teclas de Atajo

**Para la lista más actualizada de Teclas de Atajo que funcionarán en tu instancia de SillyTavern, usa el comando slash `/help hotkeys` en cualquier chat.**

**Las teclas de atajo están deshabilitadas para dispositivos móviles.**

## Teclas de Atajo de Chat

* Arriba = Editar último mensaje en el chat
* Ctrl+Arriba = Editar último mensaje del USUARIO en el chat
* Izquierda = deslizar a la izquierda
* Derecha = deslizar a la derecha (NOTA: las teclas de atajo de deslizamiento están deshabilitadas cuando la barra de chat tiene algo escrito)
* Enter (con la barra de chat seleccionada) = enviar tu mensaje a AI
* Ctrl+Enter = Regenerar la última respuesta de AI
* Alt+Enter = Continuar la última respuesta de AI
* Escape
  * *(mientras editas un mensaje Y Message Edit AutoSave está habilitado)* = cierra la caja de edición.
  * *(mientras un mensaje de AI se está generando o transmitiendo)* = detiene la generación inmediatamente.

## Teclas de Atajo de Markdown

Debe estar habilitada en la pestaña "User Settings". Funciona en la barra de chat y en áreas de texto marcadas con el icono "M↓":

* Ctrl+B = \*\*negrita\*\*
* Ctrl+I = \*cursiva\*
* Ctrl+U = \_\_subrayado\_\_
* Ctrl+K = \`código en línea\`
* Ctrl+Shift+~ = \~\~tachado\~\~

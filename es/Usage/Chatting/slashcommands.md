# Comandos de barra inclinada

!!!warning
**Esta no es una lista exhaustiva ya que se actualiza raramente.**

Para obtener la lista más actualizada de comandos que funcionarán en tu instancia, usa el comando de chat `/help slash` en cualquier chat de SillyTavern.
!!!

- `/help` – muestra el mensaje de ayuda
- `/api` - cambia a una API diferente
- `/sys` - envía un mensaje neutral como narrador del sistema
- `/send` - envía un mensaje como el usuario sin activar la generación
- `/sendas` – envía un mensaje como un personaje específico
- `/comment` - añade un comentario al chat invisible para la IA
- `/impersonate` - pide a la IA que escriba como tú con un indicador opcional
- `/persona` - establece tu persona de usuario
- `/imagine` - genera una imagen a partir de un indicador de texto
- `/bg` - establece una imagen de fondo por nombre de archivo

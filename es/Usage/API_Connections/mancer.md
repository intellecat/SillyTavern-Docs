# Mancer

Mancer es un servicio de inferencia de modelos de lenguaje grande que te permite ejecutar cualquier indicación que desees y no censura las respuestas. La mayoría de los modelos requieren un saldo precargado para comenzar a chatear, pero hay un modelo gratuito a partir de la fecha de escritura (2024-11-28).

- [Models](https://mancer.tech/models)
- [Pricing](https://mancer.tech/pricing)

## Cómo Comenzar

1. Regístrate para obtener una cuenta en [mancer.tech](https://mancer.tech/).
2. Haz clic en Dashboard y copia tu clave API.

    ![Mancer dashboard as of 2/27/2024](/static/mancer-dashboard.png)

3. En SillyTavern, selecciona API de finalización de texto y luego selecciona Mancer bajo tipo de API.
4. Ingresa tu clave API de Mancer y haz clic en Conectar.

![API Key](/static/mancer-key.png)

Ahora deberías poder chatear con cualquier modelo Mancer de tu elección.

## Registro Anónimo

Si no te importa que tus chats se utilicen potencialmente para entrenar modelos, mejorar el servicio de Mancer, publicar conjuntos de datos, o *cualquier otra cosa* que decidan hacer con ellos, puedes optar por el registro anónimo para obtener un descuento del 25% en tokens en modelos seleccionados. Simplemente ve a tu [panel de control de Mancer](https://mancer.tech/dashboard.html) y marca `Habilitar Registro Anón.`.

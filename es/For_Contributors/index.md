# Desarrollo y Automatización

El paquete predeterminado de SillyTavern solo proporciona una plataforma barebones que se puede extender de múltiples formas.

:::callout
**[STscript](st-script)**

STscript es un lenguaje de scripting poderoso basado en comandos de chat por lotes que puede abordarse sin ningún conocimiento de programación previo.
:::

:::callout
**[Function Calling](Function-Calling)**

Agregue capacidades más dinámicas permitiendo que el modelo de lenguaje use fuentes de datos externas o desencadene funcionalidades específicas de la extensión.
:::

:::callout
**[UI Extensions](Writing-Extensions)**

Las extensiones de UI se ejecutan en un entorno de navegador y expanden la funcionalidad de SillyTavern al conectarse a sus eventos y API.
:::

:::callout
**[Server Plugins](Server-Plugins)**

Los complementos del servidor permiten agregar funcionalidad como nuevos puntos finales de API ejecutando código en el entorno de NodeJS.
:::

:::callout
**[Internationalization (i18n)](i18n)**

Aprenda cómo traducir la interfaz de usuario de SillyTavern a su idioma.
:::

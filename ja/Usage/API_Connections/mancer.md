# Mancer

Mancerは、好きなプロンプトを実行でき、応答を検閲しない大規模言語モデル推論サービスです。ほとんどのモデルはチャットを始めるために事前にバランスをロードする必要がありますが、執筆時点(2024-11-28)で無料モデルがあります。

- [Models](https://mancer.tech/models)
- [Pricing](https://mancer.tech/pricing)

## 始め方

1. [mancer.tech](https://mancer.tech/)でアカウントにサインアップします。
2. Dashboardをクリックし、API Keyをコピーします。

    ![Mancer dashboard as of 2/27/2024](/static/mancer-dashboard.png)

3. SillyTavernで、Text Completion APIを選択し、次にAPI TypeでMancerを選択します。
4. Mancer API Keyを入力し、Connectをクリックします。

![API Key](/static/mancer-key.png)

これで、選択したMancerモデルとチャットできるようになりました。

## Anonymous Logging

チャットがモデルのトレーニング、Mancerのサービスの改善、データセットの公開、または*その他*彼らが決定することに使用される可能性があっても構わない場合、選択したモデルで25%のトークン割引のために匿名ロギングをオプトインできます。[Mancer dashboard](https://mancer.tech/dashboard.html)に移動し、`Enable Anon. Logging`にチェックを入れるだけです。

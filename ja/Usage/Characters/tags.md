# タグ

キャラクター カードとグループには 0 個以上のタグを割り当てることができます。これらは、テーマ、品質、来源などによって、急速に成長するコレクションを迅速に整理するのに役立ちます。

## タグ付け

キャラクター カードにタグを追加または削除する方法はいくつかあります：

- インポート時に埋め込まれたタグをインポートします。
- キャラクター管理パネルからカードを開きます。そこからキャラクター カードにタグを割り当てることができます。
- 一括タグ付け。

一括タグ付けするには、「Bulk edit characters」ボタン（鉛筆アイコン）をクリックして、タグ付けするカードを選択してから、右クリックして、コンテキスト メニューの「Tag」をクリックします。

!!!info Note
グループには一括タグ付けできないことに注意してください。
!!!

この画面から以下を実行できます：

- コンボ ボックスを使用してタグを追加または削除します。
- 選択したカードからすべてのタグを削除します（「All」）。
- 選択したすべてのカード間で相互に存在するタグの交差点をこれらのカードから削除します（「Mutual」）。
- キャラクター カードに保存されているすべてのタグをインポート（ローカルに作成）します。インポート済みの場合（「Import All」）。
- キャラクター カードに保存され、一致する名前でローカルに存在するタグをインポート（ローカルに作成）します（「Import Existing」）。

## 管理

すべての既存のタグを表示および管理するには、キャラクター管理パネルを開いて、「Manage tags」ボタン（歯車アイコン）をクリックします。

ここでは、トップ右のボタンを使用して、すべての情報（タグ リスト、カードへのタグ割り当て、色、フォルダー設定など）をバックアップおよび復元できます。

左側のグリップ ボタンを使用してタグを並べ替え、キャラクター管理のタグ フィルターに表示されるようにできます。

!!!warning Warning
タグ バックアップ JSON ファイルは、内部エンティティ名などのインスタンスに固有の情報が含まれているため、他のユーザーと共有することを意図していません！
!!!

## キャラクターカードインポート時のタグのインポート

ダウンロードした画像からの外部キャラクター カードをインポートするとき（または「Import content from external URL」ボタンから）、それに含まれるタグをオプションでインポートするよう求められます。これらはカードが機能するために必須ではありません。タグは単に組織的です。

埋め込まれたカード タグはキャラクター エディターの「Advanced Definitions」メニューの「Creator's Metadata」セクションに保存されます。カードをインポートする他のユーザーにタグを提案したい場合は、「Tags to Embed」フィールドにタグのカンマ区切りリストを入力します。

!!!info Note
このポップアップは、ユーザー設定オプション「Import Card Tags」が「Ask」に設定されている場合にのみ表示されます。
!!!

「Import tags for CHARACTER NAME」ポップアップが開いたら、既存のタグ（既にローカルで一致する名前を持つ）と新しいタグ（ローカルで持っていない）のリストが表示されます。

次のいずれかの操作を実行できます：

- 必要に応じてリストを修正してから「Import」をクリック します。残りの既存タグはインポートされたキャラクター カードに追加され、残りの新しいタグはローカルに作成されてからカードに追加されます。
- または、単に「Import none」をクリックしてキャラクター カードに含まれるタグを無視し、カードのみをインポートします。
- または、「Import All」を使用して、キャラクター カードで見つかったすべてのタグをインポートするためのショートカット（注：上記のリストから修正したものを含む。修正したタグをインポートしないようにするには、「Import」ボタンを使用します）。
- または、「Import Existing」をいくつかのショートカットのみインポート ローカルに一致する名前で存在するタグ。

## キャラクターカードのフィルタリング

タグを作成すると、キャラクター管理パネルの行に表示されます。これらをクリックしてタグ フィルタリング状態を切り替えることができます。順序は次のとおりです：

- 1 回クリックするとこのタグでタグ付けされたカードが表示されます。
- もう 1 回クリックして、このタグでタグ付けされていないカードのみを表示します。
- もう 1 回クリックして、このタグによるフィルタリングをリセットします。

同時に任意の数のタグでフィルタリングできます。

## フォルダとしてのタグ

!!!info Note
この機能を使用するには、ユーザー設定で最初に有効にする必要があります。UI テーマの列の下です。このトグルの状態は UI テーマとともに保存されます。
!!!

「Manage tags」ボタン（歯車アイコン）から、各タグ エントリにはこれらのタグをフォルダー モード（コード内で「bogus folder」と呼ばれます）の間で循環するマルチステート トグル ボタンがあります：

- 1 回クリックすると、このタグを「開いたフォルダー」に変えます。カード リストに仮想エントリとして表示されます。それをクリックするとそのタグでタグ付けされたカードのみが表示されます。
- もう 1 回クリックして、このタグを「閉じたフォルダー」に変えます。上記と同様ですが、このタグでタグ付けされたカードはデフォルトでは表示されません。フォルダーをクリックして表示する必要があります。
- もう 1 回クリックしてこのタグのタグ-フォルダー状態をリセットします。

# Slash commands

!!!warning
**これは網羅的なリストではなく、めったに更新されません。**

インスタンスで機能するコマンドの最新リストについては、SillyTavern チャットで `/help slash` チャット コマンドを使用してください。
!!!

- `/help` – ヘルプ メッセージを表示
- `/api` - 別の API に切り替え
- `/sys` - システム ナレーターとして中立的なメッセージを送信
- `/send` - 生成をトリガーせずにユーザーとしてメッセージを送信
- `/sendas` – 特定のキャラクターとしてメッセージを送信
- `/comment` - AI に見えない注釈をチャットに追加
- `/impersonate` - オプションのプロンプトを使用してあなたとして書くように AI に依頼
- `/persona` - ユーザー ペルソナを設定
- `/imagine` - テキスト プロンプトから画像を生成
- `/bg` - ファイル名で背景画像を設定

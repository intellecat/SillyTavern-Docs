# 使用方法

AIとやり取りしてください。あなたの世界、あなたの仕事、またはあなたの夢を作成してください。

:::callout
## はじめに

**[クイックスタート](/Usage/quick-start.md)**

AIに最初のメッセージを送信して応答を取得します

**[チャット](/Usage/Chatting/index.md)**

AIとチャットする方法とチャットインターフェースの使用方法

**[FAQ](/Usage/Common-Settings.md)**

SillyTavern、AIモデル、キャラクター作成、より良い応答、その他についてよくある質問
:::

:::callout
## 基本

**[API接続](/Usage/API_Connections/index.md)**

テキスト、画像、その他を生成するためのAIモデルに接続

**[キャラクター](/Usage/Characters/index.md)** と **[ペルソナ](/Usage/personas.md)**

AIの役割を形作るキャラクターを作成して使用し、ペルソナはあなたのアイデンティティを定義

**[応答構成](/Usage/Common-Settings.md)** と **[プロンプト](/Usage/Prompts/index.md)**

AIに送信するリクエストを制御し、それがどのように応答するかを制御

**[Welcome Page Assistants](/Usage/welcome-assistants.md)**

Welcome Screenで指定したキャラクターであなたをグリーテッドするためのWelcome Page Assistantsをセットアップして使用する方法を学びます。
:::

:::callout
## SillyTavernで構築

**[World Info](/Usage/worldinfo.md)**

情報を管理し、プロンプトに挿入する時期を管理

**[Data Bank](/Usage/Characters/data-bank.md)**

AIの応答で使用するための情報を保存および取得

**[拡張機能](/extensions/index.md)**

AIまたはインターフェースに新しい機能と機能を追加

**[開発と自動化](/For_Contributors/index.md)**

タスクを自動化し、AIが世界と相互作用し、独自の拡張機能を作成
:::

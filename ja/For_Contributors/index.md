# 開発と自動化

SillyTavernのデフォルトパッケージは、さまざまな方法で拡張できるベアボーンプラットフォームを提供します。

:::callout
**[STscript](st-script)**

STscriptは、事前のコーディング知識なしで取り組める、バッチチャットコマンドベースの強力なスクリプト言語です。
:::

:::callout
**[Function Calling](Function-Calling)**

LLMに外部データソースを使用させたり、エクステンションの特定の機能をトリガーさせることで、より動的な機能を追加します。
:::

:::callout
**[UI Extensions](Writing-Extensions)**

UIエクステンションは、ブラウザ環境で実行され、イベントとAPIにフックすることでSillyTavernの機能を拡張します。
:::

:::callout
**[Server Plugins](Server-Plugins)**

サーバープラグインを使用すると、NodeJS環境でコードを実行することで、新しいAPIエンドポイントなどの機能を追加できます。
:::

:::callout
**[Internationalization (i18n)](i18n)**

SillyTavernのUIを自分の言語に翻訳する方法を学びます。
:::

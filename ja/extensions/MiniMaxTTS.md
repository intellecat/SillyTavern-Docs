# MiniMax TTS

このページでは、MiniMax TTSプロバイダーの適切な使用方法を説明します。

## 前提条件

1. API アクセス権を持つMiniMaxアカウント
2. MiniMaxからの有効なAPI KeyおよびGroup ID

## API認証情報の取得

### 1. MiniMaxアカウントを作成

1. [MiniMaxウェブサイト（国際版）](https://www.minimax.io/)にアクセス
2. 「サインアップ」または「ログイン」をクリック
3. アカウント登録プロセスを完了

!!!warning 地域の違い
MiniMaxには中国版と国際版があります。次の点に注意してください：
- 中国版は音声クローニング機能をサポートしていません
- 中国版は`api.minimax.chat` APIホストのみをサポート
!!!

### 2. APIキーとグループIDを取得

1. [MiniMaxコンソール（国際版）](https://www.minimax.io/platform/user-center/basic-information)にログイン
2. 基本情報ページでGroupIdが見つかります
3. 左側のサイドバーで設定→APIキーに移動してAPIキーを作成および取得

## SillyTavernでの設定

### 1. 基本セットアップ

1. SillyTavernを開く
2. 「拡張機能」→「TTS」に移動
3. TTSプロバイダーとして「MiniMax」を選択
4. 次の設定を構成：
    - **API Key**：MiniMax APIキー
    - **Group ID**：MiniMaxグループID
    - **API Host**：地域に基づいて適切なサーバーを選択：
        - `api.minimax.io`（公式国際サーバー）
        - `api.minimaxi.chat`（別の国際サーバーホスト）
        - `api.minimax.chat`（中国本土サーバー）

### 2. モデル選択

利用可能なモデルは次のとおり：
- **Speech-02-HD**：高品質音声合成（推奨）
- **Speech-02-Turbo**：高速音声合成
- **Speech-01**：レガシーモデル
- **Speech-01-240228**：レガシーモデル（特定バージョン）

### 3. 音声パラメータ

音声出力をカスタマイズするために、次のパラメータを調整：
- **Speed**：0.5～2.0（1.0 = 標準速度）
- **Volume**：0.1～2.0（1.0 = 標準ボリューム）
- **Pitch**：0.5～2.0（1.0 = 標準ピッチ）
- **Audio Format**：MP3、WAV、FLAC

## カスタム音声

### 1. 音声IDの取得

1. [MiniMax TTSページ（国際版）](https://www.minimax.io/audio/text-to-speech)にアクセス
2. 右側の「音声」をクリックして、音声選択インターフェースに入ります
3. 使用したい音声を見つける
4. 音声名の横にあるコピーボタンをクリックして、音声IDをコピー

### 2. カスタム音声を追加

1. MiniMax TTS設定で「カスタム音声管理」セクションを見つけます
2. 次の情報を入力：
    - **Voice Name**：識別用に任意の名前
    - **Voice ID**：MiniMaxプラットフォームから取得した音声ID
    - **Language**：音声に対応する言語を選択
3. 「カスタム音声を追加」をクリック

## カスタムモデル

### 1. カスタムモデルを追加

1. 「カスタムモデル管理」セクション内
2. 入力：
    - **Model ID**：モデル識別子
    - **Model Name**：モデルの表示名
3. 「カスタムモデルを追加」をクリック

### 2. モデルIDを取得

1. 公式[MiniMaxドキュメント](https://www.minimax.io/platform/document/Model?key=684261f14c5738213294faa7)でモデルリストを確認
2. またはコンソールで利用可能なカスタムモデルを表示
3. 対応するModel IDをコピー

## トラブルシューティング

### 一般的な問題

1. **API認証に失敗**
    - APIキーが正しいAPIホストに対応していることを確認
    - GroupIDが正しいことを確認
    - アカウントに十分な残高があるかを確認

2. **音声生成に失敗**
    - 選択した音声IDが有効であることを確認
    - 音声がお使いのモデルと互換性があることを確認

3. **接続タイムアウト**
    - 別のAPIホストに切り替えてみる
    - ネットワーク接続を確認
    - ファイアウォール設定を確認

4. **オーディオ品質の問題**
    - 別のモデルを試す（最高品質はSpeech-02-HD）
    - 音声パラメータを調整（速度、ピッチ、ボリューム）
    - オーディオフォーマット互換性を確認

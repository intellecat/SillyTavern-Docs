# Blip

このガイドでは、SillyTavernエクスペリエンス向けのblip拡張機能の設定とカスタマイズについて説明します。この拡張機能はメッセージのテキストを可変速度でアニメーション化し、アニメーション中に音を再生します。オーディオファイルを使用するか、音を生成できます。

## 前提条件

開始する前に、以下の前提条件が満たされていることを確認してください：

- SillyTavernの最新バージョンを使用していることを確認してください。
- 拡張機能パネルの「拡張機能とアセットをダウンロード」メニューから「Blip」拡張機能をインストールします（積み重ねられたブロックアイコン）。

## Blipグローバル設定

1. **ユーザーメッセージのBlip**：
   - チェックボックスを有効にして、ユーザーメッセージでアニメーションを再生します。
   - ユーザーのblipアニメーション用にユーザープロファイルまたはデフォルトプロファイルを設定します。

2. **特定のテキストのみBlip**：
   - チェックボックスを有効にして、引用符内のテキストのみをblipします。
   - アスタリスク内のすべてを無視するチェックボックスを有効にします。

3. **自動スクロールダウン**：
   - テキストアニメーションに従うようにチャットを下に移動するチェックボックスを有効にします。アニメーション中に自由にスクロールしたい場合は無効にします。

4. **オーディオボリューム**
   - テキストアニメーションのみが必要な場合はオーディオをミュートします。
   - blipオーディオのグローバルボリュームを調整できます。

## キャラクターアニメーション/音声プロファイル

各キャラクターのプロファイルを保存できます：
   - ユーザーを含む、またはキャラクターが使用するプロファイルがない場合に使用するオプションのデフォルトプロファイルを含みます。
   - 現在のチャットキャラクターのみがリストに表示されている場合は、チェックボックスをクリックしてすべてのキャラクターを表示します。

1. **プロファイルを割り当て/更新するキャラクターを選択**：
   - キャラクターを選択します。プロファイルがある場合は読み込まれます。
   - まだプロファイルがない場合、現在のパラメーターは彼のプロファイル設定になります。
   - 削除ボタンを使用して、プロファイルを削除できます。
   - キャラクターがリストに表示されない場合は、更新ボタンを使用します。

2. **テキストアニメーション設定**：
   - テキストスピードを設定します：各文字が印刷される間のミリ秒単位の遅延。
   - 最小/最大スピード乗数を1.0以外に設定して、スピードアニメーションのランダム性を設定します。
   - 特殊文字が印刷されるときに一時停止を追加するために、コンマ/フレーズ遅延を0より大きく設定します。これはアニメーションに活力を追加できます。この場合、オーディオも一時停止します。

3. **オーディオパラメーター**：
   - 必要に応じて、このボイスプロファイルのみに影響する音量乗数を設定します。
   - オーディオスピードを設定します：blip音の間の遅延、テキストスピードと独立しています。

4. **Blip Origin：生成された音**：
   - スライダーを使用してblip音をカスタマイズします。
   - 最小/最大が異なる場合、毎回この範囲内のランダムな音が再生されます。

5. **Blip Origin：ファイル**：
   - リストからファイルを選択します。
   - 公式ST blipアセットはアセット拡張機能メニューから取得できます。
   - または、ファイルを直接配置します：`\SillyTavern\data\<user-handle>\assets\blip`。
   - 必要に応じてファイル全体が再生されてから再度再生されるのを待つチェックボックスを有効にします。
